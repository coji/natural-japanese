# 読みやすさの評価軸(S30 の前後比較用)

各軸は、スキルの references と公開資料の原則にさかのぼれるようにした。評価者(LLM)には、この定義だけを渡す。好みではなく、定義に照らしてどちらがよいかを判断させる。

| 軸 | 見ること | 出典 |
|---|---|---|
| A1 結論と用件の位置 | 冒頭(最初の数文と見出し)だけで、結論・依頼・決定事項がわかるか | 文体憲法1条・2条、公用文作成の考え方「結論は早めに示す」、`reading-environment-2026.md`(冒頭で答える) |
| A2 構成の見通し | 見出しと段落の先頭を追うだけで、全体の流れがつかめるか。見出しが内容を言い当てているか | 文体憲法2条、公用文作成の考え方「見出しを追えば全体の内容がつかめる」 |
| A3 一文一義と文の長さ | 一つの文に論点が一つか。長すぎる文(目安50〜60字超)が読みにくくなっていないか | `readability-principles.md`「一文一義と文長」、公用文作成の考え方 |
| A4 語順・読点・主述の近さ | 長い修飾を先に置く、読点が係り受けを助ける、主語と述語が離れすぎない | `readability-principles.md`「語順の原則(本多)」「読点の原則」「主語述語の近接」 |
| A5 段落とつながり | 段落ごとに要点が一つで、トピックセンテンスがある。接続詞や文の順で論理のつながりが追える | `readability-principles.md`「パラグラフとトピックセンテンス(木下)」「接続詞の使い方(石黒)」 |
| A6 具体性 | 実名・実数・具体例で書かれているか。抽象的な言い換えや中身のない一般論に逃げていないか | 文体憲法5条、`readability-principles.md`「事実と意見の峻別」 |
| A7 情報の密度 | 同じことの繰り返し、前置き、要約の繰り返し、クッション言葉で間延びしていないか。逆に、必要な説明を削りすぎていないか | 文体憲法1条・7条・12条、`readability-antipatterns.md`「D1 冗長表現」、`reading-environment-2026.md`(長さではなく密度) |
| A8 書式の使い方 | 箇条書きは本当に並列なときだけか。太字は核の1か所程度か。表や見出しが内容に見合っているか | 文体憲法3条・6条 |
| A9 現行の AI の癖 | ぼやけた比喩の語彙(効く・壊れる・土台・境界など)、ダッシュの挿入、「〜ではなく」の対比、丁寧すぎる言い回し、決め台詞がないか | 文体憲法9条、`forbidden-patterns.md`、`corpus/ROADMAP.md` F8・F18・F24 |
| A10 条件と限定の位置 | 主張にかかる条件・前提・例外が、その主張のすぐ近くにあるか(流し読みや AI の要約で落ちないか) | `reading-environment-2026.md`(条件を主張の近くに置く) |
| A11 内容の保持 | 元の事実・数値・固有名詞・判断が保たれているか。元にない内容を足していないか(後の版についてだけ見る) | `revision-guide.md`(直しすぎの戒め) |

## 判定のしかた

- 2つの版(A・B)を見せ、軸ごとに「A がよい / B がよい / 差がない」を選ばせる。理由を1文で書かせ、根拠になる箇所を短く引用させる
- 版の並び順の影響を消すため、同じ対を順番を入れ替えて2回判定する。2回で答えが食い違ったら「差がない」に寄せる
- 推敲に使ったモデル(Claude)と別系統の2モデル(GPT・Gemini)で判定し、一致の度合いを出す
- A11 は「後の版が元の内容を保っているか」を、保っている / 一部崩れている / 大きく崩れている の3段階で判定させる
