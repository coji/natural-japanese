AI の文書に、クリティカルシンキングを

AI が書いた稟議書や企画書、提案書は、丁寧に見えて、決める人の問いに答えていないことがあります。根拠のない言い切り、よく見ると辻褄の合わない数字、そして論点がはっきりしないダラダラした文章。natural-japanese に同梱した新しいスキル critical-thinking は、提出する前に決裁者の目で読み、文書の中で直せることは直し、書き手にしか答えられないことだけを3つ聞いて本文に入れ、決裁に要る根拠だけを残して短くします。

下は、架空の文書4本にかけた実演です。1回目は4本とも「このままでは差し戻されます」の判定と、出す前に調べておくことの一覧が返りました。このページではその一覧を宿題と呼びます。宿題を済ませると、3本が「このまま出せます」になりました。

想定した読み手は、別のセッションの Claude Opus 5.5 に役を与えたもので、文書ごとに経営者、提案を受け取る会社の役員、報告を受け取る上司です。元の文書と直した後を、どちらが直した後かを知らせずに別々に渡し、返事と指摘を3回ずつ返させました。返事は OK、条件つきOK、判断の前に質問あり、却下の4つから選びます。指摘と確認事項の照合は Claude Sonnet 5.5 が行い、判定が甘くないかは、ある文書への指摘を無関係な文書の確認事項と組み合わせた42組で、全部「ない」と出ることを確かめました。

テスト用の文書は、スキルの作者が欠陥を仕込んだ架空の文書5本と、ない欠陥を指摘しないかを見る欠陥のない4本です。仕込んだ欠陥は、表と本文で食い違う数字、根拠のない見込み、診断の後で決めるはずなのにもう書いてある製品名、報告日より後の「実施済み」などです。問いが欠陥を捉えたか、直しが欠陥を解いたか、書き手の答えを改変せずに入れたかは Claude Sonnet 5.5 が判定しました。書かせたのも直したのも Claude Opus 5.5 で、人による確認はしていません。「構成から組み直して」は、欠陥を仕込んだ文書のうち4本を3回ずつ組み直した 12 本すべてで決裁事項を小さくする案が出て、主結論と決裁事項は 12 本すべてで元のままでした。組み直した本編が元より長くなった回が制度企画で2本ありました。どちらも元の 2% 以内です。「もっと端的に」「もっと丁寧に」は、主結論・決裁事項・数値が保たれ、本編の各文が元の文書に対応することを条件とし、15 回中 14 回で満たしました。満たさなかった1回は、丁寧にした本編が元の 110% を超えたものです。回ごとの結果は dev/ct-eval/RESULTS.md にあります。

使い方

ふだんは /critical-thinking 稟議書.md だけで足ります。検査から組み直しまで6つの工程を通します。文書は Markdown かテキストのファイルで渡します。工程を分けて実行するときだけ、/critical-thinking short 稟議書.md のようにサブコマンドを挟みます。

サブコマンド同じ意味の指示何をするか
なし、または full「稟議書.md を決裁者の目で見て直して」全工程を通す。検査し、書き手にしか答えられない問いを3つまで聞いて答えを本文に入れ、直した文書から端的にした版と組み直した版も作る
logic「筋が通っているか検査して」文書の中だけで、矛盾・根拠のない主張・食い違いを行番号つきの問いにする
somosomo「決裁者目線で、前提から疑って」文書の外から、前提、他の選択肢、結論が覆る条件、誰が得をして誰が動くのか、を問う
fix「指摘を反映して直して」検査の報告を本文に反映し、残りの問いを確認事項に出す
short / detail「もっと端的に」「もっと丁寧に」決裁に要る根拠だけを本編に残す / 裏づけと論拠を本編に戻す
rebuild「構成から組み直して」事実と決裁事項は保ち、構成案を3つ出す。1つは決裁事項を小さくする案
/critical-thinking 稟議書.md

インストール

Claude Code、Codex、Cursor、OpenCode、Gemini CLI、GitHub Copilot など、Agent Skills に対応したコーディングエージェントで使えます。

npx skills add coji/natural-japanese

このコマンドで natural-japanese と critical-thinking の両方が入ります。natural-japanese の検査ツールには uv と Python が要りますが、critical-thinking には要りません。入れた直後は、セッションを開き直すか /reload-plugins で読み込みます。

  1. critical-thinking.skill をダウンロードする
  2. 「カスタマイズ」→「スキル」→「+」→「スキルをアップロード」で、ダウンロードした zip ファイルを選ぶ
  3. 文書を貼るか添付して、「この稟議書を決裁者の目で見て直して」と指示する

ChatGPT Business、Enterprise、Edu で使えます。管理者がスキルのアップロードを許可している必要があります。

  1. critical-thinking.skill をダウンロードする
  2. 「スキル」→「作成」→「コンピューターからアップロード」で、ダウンロードした zip ファイルを選ぶ
  3. 文書を添付して頼む

Gemini アプリで使えます。2026年11月の時点では個人アカウントでも使えます。

  1. critical-thinking.skill をダウンロードして展開する
  2. 「カスタマイズ」→「スキル」→「作成」から、SKILL.md を含むフォルダをアップロードする
  3. 文書を添付して頼む

Microsoft 365 Copilot の宣言型エージェントにスキルを足す機能は、2026年11月の時点でプレビューです。

  1. Agent Builder でエージェントを作り、スキルとして critical-thinking.skill を追加する
  2. そのエージェントに文書を渡して頼む
