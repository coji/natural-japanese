# 在宅勤務制度（週1日）導入の企画

人事部 人事企画担当
経営会議 付議資料

---

## 本日お諮りしたいこと

1. 内勤の従業員180名を対象に、週1日の在宅勤務制度を **2027年4月から** 始めること
2. 準備として、就業規則の改定、情報システム部との接続環境の調整、一部部署での試行に着手すること

制度の詳細（規程の条文、費用の確定額）は、本日の承認を受けて詰め、2月の経営会議で最終案としてお諮りします。

---

## 1. 背景と目的

当社の離職率は業界平均より4ポイント高く、在宅勤務がないことがその一因になっているおそれがあります。

| 項目 | 当社 | 比較対象 |
|---|---|---|
| 昨年の離職率 | 12%（250名規模で年間およそ30名） | 業界平均 8%（当社の規模に当てはめると年間およそ20名） |
| 在宅勤務制度 | なし | 競合2社は週1〜2日を導入済み |
| 退職者アンケート | 「働き方の柔軟性のなさ」が退職理由の上位 | — |

業界平均との差は、人数にすると年間でおよそ10名です。退職理由の上位に柔軟性のなさが挙がり、競合2社は在宅勤務を導入済みです。このため、在宅勤務がないことは「辞める理由」にも「選ばれない理由」にもなっていると考えます。

### 目的

- **離職の抑制**：柔軟性のなさを理由とした退職を減らす
- **採用力の向上**：在宅勤務制度があることを求人で示し、応募や内定承諾で競合に見劣りしないようにする

在宅勤務だけで離職率が業界平均まで下がるとは考えていません。退職理由のうち、働き方の柔軟性に関わる部分に手を打つ施策と位置づけています。

---

## 2. 制度の内容

週1日まで、部署ごとに割り当てた曜日に自宅で働く制度です。対象者や申請の方法などは付録1にまとめました。

競合は週1〜2日ですが、当社はまず週1日から始めます。最初から大きく始めず、確実に回る形を優先します。日数は、運用が安定したら見直しを検討します。

### 曜日の割り当て

曜日を部署ごとに割り当てるのは、VPNの同時接続の上限を超えないためです。情報システム部によると、上限は **100件** です。

180名が5日に均等に分かれれば、在宅勤務者は1日36名です。ただ、本人の希望に任せると月曜や金曜に偏るおそれがあります。そこで部署ごとに曜日を割り当て、どの曜日も在宅勤務者の数が上限を大きく下回るようにします。

上限と比べるべき数には、外勤の方などがふだんVPNを使っている分も入ります。この利用状況は情報システム部に確認中で、その分を足しても上限に収まるかは、まだ分かりません。

### 公平性への配慮

対象外の70名（内勤以外の従業員）には、在宅勤務が難しい理由を説明し、別の施策を検討することを提案します。不公平だという声が出る可能性があるためです。施策には、たとえば時差出勤や休暇の取りやすさの改善が考えられます。

---

## 3. 期待効果

期待する効果は、離職の抑制と採用力の向上です。金額で示すには退職者1名あたりの採用・育成コストが必要で、これは人事部で集計中です。効果の測り方は付録2にまとめました。

仮にこのコストを1名あたり X 円とすると、離職者が年に1名減るごとに X 円の削減になります。業界平均との差（年間およそ10名）のうち何名分を在宅勤務で埋められるかは、導入後の実績で確かめます。

---

## 4. 懸念と対策

VPNの上限、就業規則の改定、労働時間の管理、情報セキュリティなどの懸念には、対策の案があります（付録3）。まだ決まっていないのは費用です。在宅勤務手当（通信費・光熱費の補助）の要否と通勤手当の扱いを決め、金額は2月の最終案で示します。

事前に確認が必要なことは次の3つです。

- 内勤180名のうち、持ち出せるPC（ノートPC）を持っていない人の数と、追加購入の費用
- 外勤の方などによる、現在のVPNの利用状況
- 在宅勤務手当を設ける場合の金額と、年間の総額

---

## 5. 進め方

1〜2月に一部部署で試行し、2月に最終案をお諮りしたうえで、2027年4月に始める予定です。

| 時期 | 内容 |
|---|---|
| 2026年11月 | 経営会議で方針を承認（本日） |
| 2026年11月〜12月 | 規程の原案を作成。情報システム部とVPN・PC・セキュリティのルールを調整。社会保険労務士に相談 |
| 2027年1月〜2月 | 1〜2部署（30名程度）で試行。VPNの接続数、業務への影響、利用者の声を確認 |
| 2027年2月 | 試行の結果を受けて最終案を経営会議に付議（規程・費用・運用ルール） |
| 2027年2月〜3月 | 従業員代表への意見聴取、労働基準監督署への届出。管理職向け説明会、全従業員向け説明会 |
| 2027年4月 | 内勤180名で開始 |
| 2027年10月 | 半年の時点で、利用状況・離職率・採用の指標を経営会議に報告し、日数などの見直しを判断 |

試行期間中の扱い（暫定的なルールが必要かどうか）は、社会保険労務士に確認したうえで決めます。

## まとめ

- 当社の離職率は業界平均より4ポイント高く、退職理由の上位に働き方の柔軟性のなさが挙がっています
- 競合2社はすでに在宅勤務を導入しており、採用で見劣りするおそれがあります
- 週1日・曜日の割り当て制なら、在宅勤務者の数はVPNの上限を大きく下回ります。外勤の方などの利用を足して収まるかは確認中です
- 本日は方針の承認をいただき、試行の結果を踏まえて2月に最終案をお諮りします

## 確認事項

- 本日の承認は何を縛るか。2月の会議で「始めない」「延期する」と決める余地は残るか。残るなら、2月に判断を分ける基準（費用の上限、試行で確かめる項目など）は何か
- 退職者アンケートの「働き方の柔軟性のなさ」のうち、在宅勤務を指すものはどれだけあるか（設問の文言と自由記述の内訳）
- 「退職理由の上位」は何位で、退職者30名のうち何人、何割にあたるか
- 昨年の退職者は内勤と内勤以外でそれぞれ何名か。柔軟性を理由に挙げた人はどちらに多いか。内勤以外に多い場合、内勤だけに制度を入れると対象外の不満を強めることにならないか
- 採用で実際に見劣りしているか。直近の応募数、内定承諾率、内定辞退・面接辞退の理由（在宅勤務が挙がっているか）
- 競合2社の制度の条件（日数、曜日の決め方、承認の要否）と当社案を比べると、求人で並べたときにどう見えるか。週2日、曜日の自由選択など範囲の違う案と比べて今の形を選んだ記録はあるか
- 在宅勤務以外の打ち手（時差出勤、休暇の取りやすさなど）や、何もしない案と比べたか。比べていないなら、その理由
- 外勤の方などの現在のVPN利用（曜日・時間帯別）を足して、どこまでなら上限に収まると言えるか。部署の人数によって曜日ごとの偏りは出ないか（部署別の内勤人数と曜日への割り振り）
- 30名程度の試行で測る接続数の最大値から、180名で始めたときの接続数をどう読むか。外勤の方などの利用を測るのが目的なら、そう書くか
- 上長が出社のために日を変えたとき、変更先の曜日にも割り当てと同じ制約がかかるか。日の変更が続いて制度が使えなくなることへの歯止めはあるか。上長の負担について管理職に聞き取りをしたか
- 対象外の70名向けの施策は、誰がいつまでに検討するか
- 試行が2月まで続く中で、2月の経営会議の時点で試行の結果はどこまで出ているか
- 試行期間中の暫定ルールの要否は、試行が始まる1月より前（11〜12月のうち）に決まる前提か
- 工程が1つ遅れたとき（PCの調達、届出、暫定ルールなど）、4月開始を動かすのか、規模を縮めて始めるのか。各工程の所要期間の見込み
- 情報システム部は、VPNの利用状況の確認、運用ルールづくり、PCの手配を、この日程で引き受けているか（担当者、作業範囲、期限）
- ノートPCの追加購入費は、2月の最終案で示す費用に入るか
- 効果の3つ目「定着と満足度」は、「離職の抑制」と同じものを数えていないか。目的に入れるか
- 半年後の離職率が動いたとき、在宅勤務の効果とそれ以外の要因をどう分けるか。年間の離職率と半年の数字をどう比べるか。10月の会議では、どの数字がどうなっていたら拡大・維持・縮小・取りやめにするか
- 退職者1名あたりの採用・育成コスト（X）の集計結果と、導入前の各指標（定着と満足度を含む）の基準値
- 対象者の180名は、試用期間中の者を除いたあとの数か、除く前の数か。試用期間中の者を除くことは、採用での訴求と両立するか
- 「月曜や金曜に偏るおそれ」と、「育児や介護との両立がしやすくなる」の出どころ
- 勤務場所の「自宅に限る」に、実家やサテライトオフィスは含むか

## 付録1 制度の基本の設計

| 項目 | 案 |
|---|---|
| 対象者 | 内勤の従業員180名（試用期間中の者は除く） |
| 日数 | 週1日まで。翌週への繰り越しはしない |
| 曜日 | 部署ごとに割り当てる（2章「曜日の割り当て」を参照） |
| 申請 | 前週までに上長へ申請し、上長が承認する |
| 勤務時間 | 通常の勤務時間と同じ。始業・終業は勤怠システムで打刻する |
| 勤務場所 | 自宅に限る（カフェ等は情報管理の観点から認めない） |
| 業務上の必要 | 会議や来客などで出社が必要な日は、上長が日を変更できる |

## 付録2 期待効果と測り方

| 効果 | 内容 | 測り方 |
|---|---|---|
| 離職の抑制 | 柔軟性のなさを理由とした退職が減る | 離職率、退職者アンケートでの理由の順位と割合 |
| 採用力の向上 | 在宅勤務制度があることを求人で示せる | 応募数、内定承諾率、面接辞退の理由 |
| 定着と満足度 | 通勤負担が減り、育児や介護と両立しやすくなると見込む | 従業員アンケート |

## 付録3 懸念と対策

| 懸念 | 対策 |
|---|---|
| **VPNの同時接続数の上限（100）** | 部署ごとに曜日を割り当て、1日あたりの在宅勤務者を上限よりも十分少なく保つ。試行期間中に、実際の接続数の最大値を測る |
| **就業規則の改定が必要** | 在宅勤務規程を新設し、就業規則に位置づける。従業員代表の意見を聴いたうえで、労働基準監督署に届け出る。社会保険労務士に条文を確認してもらう |
| **労働時間の管理** | 勤怠システムでの打刻を必須とする。在宅勤務日の時間外労働は事前申請制にする |
| **情報セキュリティ** | 会社貸与のPCのみ使用可とし、VPN経由で接続する。紙の書類の持ち出しは原則禁止とする。運用ルールは情報システム部と作る |
| **業務の滞りやコミュニケーションの低下** | 在宅勤務日でも連絡がつく手段（チャット、オンライン会議）を決めておく。部署ごとに、在宅でできる業務とできない業務を整理する |
| **評価への不安** | 在宅勤務の利用の有無を評価に影響させないことを、規程と管理職向けの説明で明確にする |
| **対象外の従業員の不公平感** | 2章「公平性への配慮」のとおり、説明と別施策の検討で対応する |
