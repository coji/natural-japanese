# 在宅勤務制度（週1日）導入の企画

人事部 人事企画担当
経営会議 付議資料

---

## 本日お諮りしたいこと

1. 内勤の従業員180名を対象に、週1日の在宅勤務制度を、**2027年4月** の開始を目標に作ること
2. 準備として、就業規則の改定、情報システム部との接続環境の調整、一部部署での試行に着手すること

開始日を含む制度の詳細（規程の条文、費用の確定額）は、本日の承認を受けて詰め、2月の経営会議で最終案としてお諮りします。試行で業務に支障が出た場合は、開始を延期します。

---

## 1. 背景と目的

在宅勤務がないことは、辞める理由の一つになっていると考えます。

| 項目 | 当社 | 比較対象 |
|---|---|---|
| 昨年の離職率 | 12%（退職者31名のうち内勤19名、内勤以外12名） | 業界平均 8%（当社の規模では年間およそ20名） |
| 在宅勤務制度 | なし | 競合2社は週1〜2日を導入済み |
| 退職者アンケート | 回答した22名のうち9名が「働き方の柔軟性のなさ」を挙げた（内勤7名、内勤以外2名）。自由記述で在宅勤務に触れたのは4名 | — |

業界平均との差は、年間でおよそ10名です。柔軟性のなさを挙げた退職者の多くは今回の対象である内勤で、在宅勤務に触れた人もいます。採用でも、競合2社が制度を持っているので、在宅勤務がないことが選ばれない理由になるおそれがあります。

目的は次のとおりです。

- **離職の抑制**：柔軟性のなさを理由とした退職を減らす
- **採用力の向上**：求人に在宅勤務制度があると示せるようにし、応募や内定承諾で見劣りしないようにする

在宅勤務だけで離職率が業界平均まで下がるとは考えていません。退職理由のうち、働き方の柔軟性に関わる部分に手を打つ施策と位置づけています。

---

## 2. 制度の内容

内勤の180名が、部署ごとに割り当てた曜日に、週1日まで自宅で勤務する制度です。詳しい設計は付録Aにまとめました。競合は週1〜2日ですが、当社はまず週1日から始め、運用が安定したら日数の見直しを検討します。

### 曜日の割り当て

部署ごとに在宅勤務の曜日を割り当て、どの曜日も在宅勤務者の数がVPNの同時接続の上限（情報システム部によると100件）を大きく下回るようにします。180名が週1日ずつなら、5日に均等に分かれて1日あたり36名ですが、本人の希望に任せると月曜や金曜に偏るおそれがあるためです。

外勤の方などがふだんVPNを使っている分も、上限に含めて考える必要があります。この利用状況は情報システム部に確認中で、分かるまでは上限に収まるとは言い切れません。

### 公平性への配慮

対象外となる70名（内勤以外の従業員）からは、不公平だという声が出る可能性があります。業務の性質上、在宅勤務が難しい職種であることを丁寧に説明するとともに、対象外の職種に向けた施策（たとえば時差出勤や休暇の取りやすさの改善）を、別途検討することを提案します。

---

## 3. 期待効果

期待する効果は、離職の抑制、採用力の向上、定着と満足度の3つです。内容と測り方は付録Cにまとめました。

効果を金額で示すには、退職者1名あたりの採用・育成コストが必要で、これは人事部で集計中です。仮にこのコストを1名あたり X 円とすると、離職者が年に1名減るごとに X 円の削減になります。業界平均との差（年間およそ10名）のうち何名分を在宅勤務で埋められるかは、導入後の実績で確かめます。

---

## 4. 懸念と対策

本日の判断に関わる懸念は、VPNの上限、就業規則の改定、費用の3つです。ほかの懸念と対策は付録Bにまとめました。

- VPNの上限：曜日の割り当てで、1日あたりの在宅勤務者を上限より十分少なく保つ。外勤の方などの利用は確認中
- 就業規則の改定：在宅勤務規程を新設する。従業員代表の意見を聴いたうえで労働基準監督署に届け出て、条文は社会保険労務士に確認してもらう
- 費用：在宅勤務手当の要否、通勤手当の扱い、ノートPCの追加購入を決め、金額は2月の最終案で示す

次の3点は、まだ確認できていません。

- 内勤180名のうち、持ち出せるPC（ノートPC）を持っていない人の数と、追加購入の費用
- 外勤の方などによる、現在のVPNの利用状況
- 在宅勤務手当を設ける場合の金額と、年間の総額

---

## 5. 進め方

2027年4月の開始を目標に、次の予定で進めます。

| 時期 | 内容 |
|---|---|
| 2026年11月 | 経営会議で方針を承認（本日） |
| 2026年11月〜12月 | 規程の原案を作成。情報システム部とVPN・PC・セキュリティのルールを調整。社会保険労務士に相談 |
| 2027年1月〜2月 | 1〜2部署（30名程度）で試行。VPNの接続数、業務への影響、利用者の声を確認 |
| 2027年2月 | それまでの試行の結果を受けて、最終案を経営会議に付議（開始日・規程・費用・運用ルール） |
| 2027年2月〜3月 | 従業員代表への意見聴取、労働基準監督署への届出。管理職向け説明会、全従業員向け説明会 |
| 2027年4月 | 内勤180名で開始（目標） |
| 2027年10月 | 半年の時点で、利用状況・離職率・採用の指標を経営会議に報告し、日数などの見直しを判断 |

試行期間中の扱い（暫定的なルールが必要かどうか）は、社会保険労務士に確認したうえで決めます。

## まとめ

- 当社の離職率は業界平均より4ポイント高く、退職者アンケートでは回答した22名のうち9名が働き方の柔軟性のなさを挙げました（うち内勤7名）
- 競合2社はすでに在宅勤務を導入しており、採用でも見劣りするおそれがあります
- 曜日を割り当てれば、在宅勤務者の数はVPNの上限を大きく下回ります。外勤の方などの利用を足した数は確認中です
- 本日は方針と準備への着手をご承認いただき、開始日を含む最終案は試行の結果を踏まえて2月にお諮りします

## 付録A 基本の設計

| 項目 | 案 |
|---|---|
| 対象者 | 内勤の従業員180名（試用期間中の者は除く） |
| 日数 | 週1日まで。翌週への繰り越しはしない |
| 曜日 | 部署ごとに割り当てる（2章「曜日の割り当て」） |
| 申請 | 前週までに上長へ申請し、上長が承認する |
| 勤務時間 | 通常の勤務時間と同じ。始業・終業は勤怠システムで打刻する |
| 勤務場所 | 自宅に限る（カフェ等は情報管理の観点から認めない） |
| 業務上の必要 | 会議や来客などで出社が必要な日は、上長が日を変更できる |

## 付録B 懸念と対策

| 懸念 | 対策 |
|---|---|
| VPNの同時接続数の上限（100） | 部署ごとに曜日を割り当て、1日あたりの在宅勤務者を上限よりも十分少なく保つ。試行期間中に、実際の接続数の最大値を測る |
| 就業規則の改定が必要 | 在宅勤務規程を新設し、就業規則に位置づける。従業員代表の意見を聴いたうえで、労働基準監督署に届け出る。社会保険労務士に条文を確認してもらう |
| 労働時間の管理 | 勤怠システムでの打刻を必須とする。在宅勤務日の時間外労働は事前申請制にする |
| 情報セキュリティ | 会社貸与のPCのみ使用可とし、VPN経由で接続する。紙の書類の持ち出しは原則禁止とする。運用ルールは情報システム部と作る |
| 業務の滞りやコミュニケーションの低下 | 在宅勤務日でも連絡がつく手段（チャット、オンライン会議）を決めておく。部署ごとに、在宅でできる業務とできない業務を整理する |
| 評価への不安 | 在宅勤務の利用の有無を評価に影響させないことを、規程と管理職向けの説明で明確にする |
| 対象外の従業員の不公平感 | 2章の「公平性への配慮」のとおり、説明と別施策の検討で対応する |
| 費用 | 通信費・光熱費の補助（在宅勤務手当）の要否、通勤手当の扱い、ノートPCの追加購入を決める。金額は2月の最終案で示す |

## 付録C 効果の測り方

| 効果 | 内容 | 測り方 |
|---|---|---|
| 離職の抑制 | 柔軟性のなさを理由とした退職が減る | 離職率、退職者アンケートでの理由の順位と割合 |
| 採用力の向上 | 求人に在宅勤務制度を示せる | 応募数、内定承諾率、面接辞退の理由 |
| 定着と満足度 | 通勤負担が減り、育児や介護との両立がしやすくなる | 従業員アンケート |
