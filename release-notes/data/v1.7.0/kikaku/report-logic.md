## 指摘

### 1. 矛盾

- **行127「VPNの上限の範囲内で運用できる見込みです」と、行60「現在の利用状況は情報システム部に確認中です」、行100**
  外勤の方などのVPN利用を上限に含める必要がある、と行60で書いていて、その数はまだ分かっていません。それでも、まとめでは範囲内に収まる見込みと言い切っています。文書の中の数字だけで見ても、対象外の70名(行64)が全員ふだんからVPNを使うとすると、1日36名(行58)と合わせて106件になり、100件を超えます。外勤の方の利用がどこまでなら「見込み」と言えるのか、その線を書き手は持っているでしょうか。
- **行32「求人で競合と同じ条件を示せるようにし」、行73「求人の条件で競合と並ぶ」と、行24・行52「競合は週1〜2日です。当社はまず週1日から始め」**
  競合には週2日の会社もあるのに、当社は週1日です。それでも「同じ条件」「並ぶ」と言えるのはなぜですか。どちらの言い方を残しますか。
- **行50「出社が必要な日は、上長が日を変更できる」と、行58「部署ごとに在宅勤務の曜日を割り当て」**
  曜日を割り当てるのは、1日の在宅勤務者を上限より少なく保つためです。上長が日を変えられるなら、変えた先の曜日に人が集まることはありませんか。変更後の曜日にも割り当てと同じ制約がかかるのでしょうか。
- **行113〜114「2027年1月〜2月 試行」「2027年2月 試行の結果を受けて最終案を経営会議に付議」、行128**
  試行が2月まで続き、同じ2月に、その結果を受けた最終案を付議する予定です。2月の経営会議の時点で、試行の結果はどこまで出ている見込みですか。また、行119では試行期間中の扱いがまだ決まっていません。規程の原案を作る11〜12月(行112)のうちに決まる前提でしょうか。
- 些末なもの2件:行116「全社(内勤180名)」は、行23の250名規模と「全社」の範囲が食い違います。行44「180名(試用期間中の者は除く)」は、180名が除いたあとの数なのか、除く前の数なのかが読み取れません。

### 2. 根拠のない主張

- **行25→行27「在宅勤務がないことは『辞める理由』(中略)になっている」**(異質なものの同質化)
  退職者アンケートにある理由は「働き方の柔軟性のなさ」で、在宅勤務がないこととは書かれていません。文書自身も行64で、時差出勤や休暇の取りやすさを柔軟性の施策に挙げています。アンケートの「柔軟性のなさ」のうち、在宅勤務を指すものがどれだけあるか、書き手は確かめていますか。
- **行23・行25と行44**(前提条件のちがい)
  離職率と退職者アンケートは250名全体の数字です。一方、制度の対象は内勤の180名だけです。柔軟性のなさを理由に辞めた人は内勤と外勤のどちらに多いのでしょうか。外勤が多いなら、行34の「働き方の柔軟性に関わる部分に手を打つ」はどこまで成り立ちますか。
- **行27「『選ばれない理由』の両方になっている」**(前提条件のちがい)
  採用の側の根拠は、競合2社が制度を持っていること(行24)だけです。応募数、内定承諾率、面接辞退の理由は、行73で効果の測り方に挙がっています。では、いまの値で見劣りが出ているのでしょうか。
- **行88「試行期間中に、実際の接続数の最大値を測る」と、行113「1〜2部署(30名程度)で試行」**
  30名の試行で測る最大値から、180名で始めたときの接続数をどう読み取るつもりですか。外勤の方の利用量を測る目的なら、そう書くつもりはありますか。
- **行72・行117「離職率」で効果を測る**
  行34で書き手自身が、在宅勤務以外の要因もあると書いています。半年後の離職率が動いたとき、在宅勤務の効果とそれ以外の要因をどう分けるつもりですか。また、比べる相手は年間の数字(行23)です。半年の数字とどう並べるのでしょうか。
- 些末なもの3件:行58「月曜や金曜に偏るおそれ」の出どころ、行74「育児や介護との両立がしやすくなる」の根拠、行126「競合は」が2社(行24)からの一般化になっていること。

### 3. 事実と推論の混在

- **行126「競合はすでに在宅勤務を導入しており、採用でも見劣りしています」**
  本文の行27では「考えます」と推論の形で書いていたことが、まとめでは事実の形になっています。行32でも、見劣りは「しないようにする」目標として書かれています。見劣りは確かめた事実ですか、それとも見立てですか。
- **行125「退職者は働き方の柔軟性のなさを理由に挙げています」**
  行25の根拠は、柔軟性のなさが退職理由の「上位」に入っていることです。まとめでは、退職者全体がそう言っているようにも読めます。上位というのは何人中の何人、どれだけの割合ですか。
- **行58「どの曜日も1日あたりの在宅勤務者が上限を大きく下回るようにします」**
  在宅勤務者の数だけを見れば下回ります。ただ、上限と比べるべき数には外勤の方の利用も入ります(行60)。「大きく下回る」は、在宅勤務者だけの数について言っているのか、VPN全体について言っているのか、どちらでしょうか。
