# doc.md の somosomo 検査

## 文書の性格

決めてもらう文書。経営会議の出席者に、内勤180名を対象に週1日の在宅勤務制度を2027年4月から始める方針と、その準備に着手することの承認を求めている。

## 主結論

「内勤の従業員180名を対象に、週1日の在宅勤務制度を2027年4月から始めること、その準備(就業規則の改定、接続環境の調整、一部部署での試行)に着手することを承認してほしい」(行10、11、128)。

ただし、費用・VPN・PCの確認はまだ終わっておらず、2月に最終案を改めて付議する予定になっている(行13、114)。本日承認を求めているのが「4月に始めること」なのか「始める前提で準備と試行に入ること」なのかで、決裁者が負う責任は変わる。書き手の意図は後者かもしれない。

## 指摘

### 1. 前提

**1-1. 「働き方の柔軟性のなさ」は、在宅勤務がないことを指しているのか**

- 問い:退職者アンケートの「働き方の柔軟性のなさ」(行25)を、文書は「在宅勤務がない」と読んで論を立てている(行27)。回答者が思い浮かべていたのは在宅勤務なのか、それとも勤務時間、休暇、残業、異動など別の柔軟性なのか。書き手はそれを確かめたか
- 倒れる場所:行27の「在宅勤務がないことは『辞める理由』に……なっている」、行31の目的「離職の抑制」、行72の効果、行125のまとめ
- 要る材料:退職者アンケートの設問の文言と自由記述の内訳。「柔軟性」を挙げた人数と、そのうち在宅勤務に触れた人数

**1-2. 柔軟性を理由に辞めたのは、今回の対象である内勤の人か**

- 問い:年間およそ30名の退職者(行23)のうち、内勤と内勤以外(70名、行64)はそれぞれ何名か。柔軟性を理由に挙げた人は、どちらに多いか。理由を挙げた人の多くが対象外の70名にいるなら、今回の制度は離職の中心に届かないが、書き手はその内訳を見たか
- 倒れる場所:行31の目的、行34の「働き方の柔軟性に関わる部分に手を打つ施策」という位置づけ、行80の「業界平均との差のうち何名分を在宅勤務で埋められるか」
- 要る材料:昨年の退職者の職種別(内勤/内勤以外)人数と、職種別の退職理由

**1-3. 「上位」とは、何人中の何人か**

- 問い:「退職理由の上位」(行25)は何位で、退職者の何割にあたるのか。仮に30名のうち数名なら、在宅勤務で埋められるのは業界平均との差10名(行27)のごく一部にとどまる。決裁者はこの規模感を、行25からは読み取れない
- 倒れる場所:行27の推論、行80の効果の見通し、行125のまとめ
- 要る材料:退職理由の順位と、理由ごとの人数または割合

### 2. 問いそのもの

**2-1. 本日決めてほしいのは「4月開始」なのか、「試行と準備への着手」なのか**

- 問い:行10は「2027年4月から始めること」の承認を求めている。一方で、費用の確定額(行13、95)、ノートPCの不足数と購入費用(行99)、VPNの現状利用(行100)はまだ分からず、2月に最終案を付議するとしている(行114)。2月の会議で「始めない」「延期する」と決める余地は残っているのか。残っているなら、本日の承認は何を縛り、何を縛らないのか
- 倒れる場所:行8〜13の「本日お諮りしたいこと」、行111の「方針を承認(本日)」、行128のまとめ
- 要る材料:2月の付議で判断を分ける基準(費用の上限、試行で確かめる項目など)が、書き手と決裁者の間で共有されているかどうか

**2-2. 「採用でも見劣りしている」は、確かめられた課題か**

- 問い:まとめは「採用でも見劣りしています」(行126)と言い切っている。しかし本文の根拠は「競合2社が導入済み」(行24)だけで、応募数、内定承諾率、辞退理由といった当社の実績は出てこない。これらは導入後の測り方(行73)には並んでいる。導入前の数字は手元にあるのか。採用に実際の問題があると、書き手は確かめたか
- 倒れる場所:行27の「選ばれない理由」、行32の目的「採用力の向上」、行126のまとめ
- 要る材料:直近の応募数、内定承諾率、内定辞退・面接辞退の理由。辞退理由に在宅勤務が挙がっているか

### 3. 他の選択肢

**3-1. 在宅勤務以外の打ち手や、何もしない案と比べたか**

- 問い:文書は「離職率が業界平均より高い」(行23、125)という課題から、打ち手を在宅勤務の一つに絞っている。文書には、対象外の職種向けに「時差出勤や休暇の取りやすさの改善」(行64)という案が出てくる。これらを内勤の離職対策として在宅勤務と比べたか。何もしない場合に離職がどうなるかの見通しも含めて、比べた記録はあるか
- 倒れる場所:行27〜34の「背景と目的」から「在宅勤務を入れる」への結びつき、行10の承認事項
- 要る材料:打ち手の候補ごとの費用・準備期間・期待効果を並べた比較。比べていないなら、比べなかった理由

**3-2. 範囲の決め方(週1日・曜日固定・上長承認)は、目的に照らして比べたか**

- 問い:競合は週1〜2日(行24、52)。当社案は週1日、曜日は部署ごとに固定(行46)、前週までに上長が承認(行47)し、上長が日を変えることもできる(行50)。この条件で、求人に「競合と同じ条件」(行32、73)と書けるのか。週2日、曜日の自由選択、試行の範囲を広げる、といった範囲の違う案と比べて、今の形を選んだ記録はあるか
- 倒れる場所:行32の「採用力の向上」、行52の「確実に回る形で始める」、行73の効果
- 要る材料:競合2社の制度条件(日数、曜日の決め方、承認の要否)と当社案の対照。範囲の違う案ごとの VPN・費用の見通し

### 4. 覆る条件

**4-1. VPN の上限100件に収まる、という見込みは何に支えられているか**

- 問い:行127は「VPNの上限の範囲内で運用できる見込み」としている。しかし外勤の方などの現在の利用状況は確認中(行60、100)で、1日36名(行58)は5日に均等に分かれた場合の数字にすぎない。部署ごとに曜日を割り当てると、部署の人数によっては曜日ごとの偏りが出るのではないか。また、1月〜2月の試行は30名程度(行113)なので、試行で測る「接続数の最大値」(行88)は全社で始めたときのピークにならない。どこまで既存の利用が多いと、この見込みは崩れるのか
- 倒れる場所:行58の「どの曜日も上限を大きく下回る」、行88の対策、行127のまとめ、行116の4月全社開始
- 要る材料:曜日・時間帯別の現在の VPN 同時接続数。部署別の内勤人数と、それを曜日に割り振ったときの最大人数

**4-2. 日程が1か所遅れたら、4月開始はどうなるか**

- 問い:2月に最終案を付議し(行114)、2月〜3月に従業員代表への意見聴取、労基署への届出、説明会を行う(行115)。試行の暫定ルールが要るかは「社労士に確認したうえで決める」(行119)となっているが、試行は1月に始まる(行113)。ノートPCの追加購入(行99)が必要になれば、調達にも時間がかかる。どれか一つが遅れたとき、4月開始を動かすのか、規模を縮めて始めるのか。書き手はその分かれ目を想定しているか
- 倒れる場所:行10の「2027年4月から」、行107〜116の予定表
- 要る材料:各工程の所要期間の見込み(PCの調達期間、届出に要する期間など)と、遅れたときの扱いについての方針

**4-3. 半年の報告で、何が出たら見直すのか**

- 問い:2027年10月に利用状況・離職率・採用の指標を報告し、見直しを判断する(行117)。離職率は年単位の数字で、半年では動きが見えにくい可能性がある。どの数字がどうなっていたら、拡大・維持・縮小・取りやめのどれにするのか。効果を金額にする係数 X(行78、80)も集計中なので、費用と効果を比べる軸がまだない。10月の会議は何を基準に判断するのか
- 倒れる場所:行117の見直し判断、行70〜80の期待効果
- 要る材料:退職者1名あたりの採用・育成コストの集計結果、導入前の各指標の基準値、判断の基準として使う数字

### 5. 利害と実行

**5-1. 上長と対象外の70名にとって、この制度はどう見えるか**

- 問い:申請の承認(行47)、出社日への変更(行50)、在宅でできる業務の整理(行92)は、いずれも上長の仕事になる。上長は文書を読んで、自分がこれを担うと分かるか。上長が日を変えることが続けば、制度があっても使えない状態になるが、その歯止めはあるか。また対象外の70名向けの施策は「別途検討」(行64、94)とあるだけで、誰がいつまでに検討するかが書かれていない。1-2 で離職者の多くが70名側にいた場合、この「別途」は後回しにしてよいものか
- 倒れる場所:行50、64、92、94の対策、行31の「離職の抑制」
- 要る材料:管理職への事前の聞き取りの有無、日の変更の件数を記録する仕組みの有無、対象外施策の担当部署と検討時期

**5-2. 情報システム部は、この日程と作業量に合意しているか**

- 問い:11月〜12月に、VPN・PC・セキュリティのルールを情報システム部と調整する(行112)。現在の利用状況の確認(行60)、運用ルールづくり(行91)、PCの手配(行99)も同部の作業になる。同部はこの日程と作業を、自分たちの仕事として引き受けているか
- 倒れる場所:行112〜113の予定、行88、91の対策
- 要る材料:情報システム部との合意の記録(担当者、作業範囲、期限)

## 反論(仮の立場)

検査のための仮の立場で、書き手の主張ではない。採用するかは書き手が決める。

**反論A:対象外の70名から、かえって離職が増えるという読み**

離職率12%(行23)の内訳が示されていない以上、退職者が内勤以外(行64の70名)に多いという読みも成り立つ。その場合、内勤だけに在宅勤務を入れると、行64の「不公平だという声」が現実になり、離職の多い層の不満をさらに強めることになる。行94の対策は「説明と別施策の検討」にとどまっているので、この読みに対しては、施策が差を広げる側に働くとも読める。

**反論B:この条件では「競合と並ぶ」とは言えないという読み**

競合は週1〜2日(行24)。当社案は週1日、曜日は部署で固定、前週までの上長承認つきで、上長が日を変えることもできる(行45〜50)。求職者から見れば、行32の「競合と同じ条件」ではなく、競合のうち条件の弱い側に近い制度という読みが成り立つ。そう読むと、行73の「求人の条件で競合と並ぶ」効果は、行52の「確実に回る形で始める」という判断と引き換えになっている。
