# 稟議書:議事録作成支援ツール「ミナトノート」の試験導入について

| 項目 | 内容 |
| --- | --- |
| 起案日 | 2026年【 】月【 】日 |
| 起案者 | 営業部長 【氏名】 |
| 提出先 | 経営会議 |
| 件名 | 議事録作成支援ツール「ミナトノート」の試験導入(6か月) |

## 1. 申請内容

顧客打ち合わせの議事録作成にかかる時間を減らすため、音声の文字起こしと要約を行うクラウドツール「ミナトノート」を、営業部の営業担当12名で6か月間試験導入したい。効果はまだ1名・1件の試行でしか確かめていないため、この6か月で次の3点を確かめ、本導入・規模縮小・中止のいずれにするかを経営会議で改めて判断する。

1. 議事録の作成時間が、費用に見合うだけ減るか
2. 顧客が録音に同意し、ツールを使える打ち合わせが十分にあるか
3. 顧客情報と録音データを、社内規程に合った形で管理できるか

- **期間**:承認後の【2026年12月】から6か月
- **費用**:月額の上限は10万円、6か月の総額は60万円以内(見込みは475,200円)

## 2. 背景

営業部では、顧客打ち合わせが週に平均8件(月に約35件)ある。担当者は打ち合わせのあと、手書きメモと記憶をもとに議事録を作っているため、議事録の正確さは担当者のメモの取り方に左右されやすいと考えている。先月ツールを試した担当者の場合、普段は1件あたり約60分かかっている。部全体での平均作成時間はまだ測っていない。

## 3. 効果の見込み

1件あたり30分減れば、削減1時間あたりの費用は約4,600円になる。営業担当者の時間単価がこれを上回り、浮いた時間がほかの仕事に使われれば、費用は回収できる。

30分は、先月、営業2課の担当者1名が無料版を1件の打ち合わせで試し、60分が30分に減ったときの値で、参考値にとどまる。約4,600円は、月約35件の打ち合わせすべてでツールを使った場合の値で、月の削減時間約17時間(6か月で約104時間)で月額費用79,200円を割って出した。削減が15分なら約9,100円、45分なら約3,000円になる(付録2)。顧客の同意が得られずツールを使えない打ち合わせがあれば、削減時間はこれより小さくなる。

## 4. 確かめ方と判断の基準

作成時間は、開始前の2週間に測る今の値と比べて評価する。

- **開始前(2週間)**:現在の議事録作成時間を、担当者ごとに打ち合わせ1件単位で記録する
- **試験期間中**:打ち合わせごとに、議事録の作成時間と、録音の同意を得られたかどうかを記録シートに記入する
- **3か月目末**:中間評価の結果を経営会議に報告する。効果が見合わない場合は、規模縮小か中止かを経営会議で判断する
- **6か月目末**:最終評価を行い、本導入・規模縮小・中止の判断案を経営会議に提出する

判断の基準は次のとおり。評価の指標と目安は付録3にまとめた。

- **本導入へ進む**:作成時間の削減が費用に見合い、情報管理上の問題がない場合
- **規模を縮小して続ける**:効果は出ているが、利用率が低い場合(ライセンス数を減らすなど)
- **中止する**:削減効果が費用に見合わない場合、または情報管理上の重大な問題が起きた場合(この場合は期間の途中でも利用を止める)

## 5. 情報管理と顧客の同意

契約前の確認で社内規程に合わない点があれば導入せず、録音は顧客の同意を得た打ち合わせに限る。

- 契約の前に、情報管理担当者がデータの保存場所、AIの学習に使われるかどうか、保存期間と削除の方法、アクセス権の設定を確認する。社内規程に合っているかどうかを情報システム部門と確認する
- 録音の前に、必ず顧客の同意を得る。同意を求める手順と文面を統一し、同意を得たことを記録に残す。同意が得られない打ち合わせでは録音せず、従来どおり手書きで議事録を作る
- 同意を得られた割合は毎月集計し、利用が少ない場合は中間評価で人数の縮小を検討する
- ツールの出力をそのまま議事録にせず、担当者が必ず確認・修正してから確定する

## 6. 費用

月額の見込みは79,200円(6,600円 × 12名)、6か月で475,200円。申請する上限は月額10万円、6か月合計60万円で、上限を超える支出は行わない。

- 単価6,600円が税込か税抜かは、契約前に確認する。税抜の場合でも月額は87,120円で、上限の範囲に収まる
- 上限と見込みの差額は、税区分や契約条件の確認結果に備えるためのものである。機材などほかの費用は想定しておらず、必要になって上限を超える場合は改めて申請する
- ライセンス数は12名分を上限とする。6か月で解約できるかなど、契約期間と中途解約の条件は契約前に確認する

## 7. 決裁をお願いする事項

1. 「ミナトノート」を営業部の営業担当12名で6か月間試験導入すること
2. 費用の上限を月額10万円、6か月合計60万円とすること

## 付録3 評価の指標

| 指標 | 測定方法 | 目安(案) |
| --- | --- | --- |
| 1件あたりの議事録作成時間 | 記録シート(開始前と比較) | 開始前より平均30分短い。最低でも、3章の費用対効果が見合う水準 |
| ツールの利用率 | 記録シート(利用した件数 ÷ 打ち合わせ件数) | 未定 |
| 議事録の品質 | 利用者アンケート、上長による確認 | 開始前と同等以上 |
| 情報管理 | 情報管理担当者による点検 | 情報漏えい・同意なしの録音が0件 |
| 費用 | 請求額 | 月額10万円以内 |

次の効果も見込まれるが、まだ確かめていないため、試験期間中に利用者アンケートで確認する。

- 発言が記録に残るため、聞き漏らしや顧客との認識違いを後から確認できる
- 議事録が早くできあがり、顧客へのフォローや社内共有を早く始められる
- 担当者が交代するとき、過去の打ち合わせ内容を引き継ぎやすい
