# doc-review.md の確認事項

提出前に書き手が確かめること。決裁者に渡す文書ではない。

## 先に答える問い

1. 今回の承認は、「契約前の確認(データの扱い、社内規程との適合)で問題がなければ導入する」という条件つきのものとして出すか。5章では「問題があれば導入しない」と書いているが、7章の決裁事項には条件がない。データの扱いの資料はまだ取り寄せておらず、情報システム部門とも確認を始めていない。
2. すべての打ち合わせで使っても、30分の削減では費用が人件費(標準単価1時間3,500円)を上回り、下回るには1件あたり約39分の削減が要る(3章、付録A)。打ち合わせは部全体で月約35件、1人あたり月3件ほどで、それでも12名・6か月で試す理由は何か。作成時間の目安は「費用に見合う水準(平均約39分短い)」に揃えたが、元の「平均30分短い」を残したいか。
3. 顧客から録音の同意を得られる割合の見通しはあるか。利用率の目安が【 】%のまま空いていて、試算は全件で同意が得られる前提になっている。

## そのほか

- 支払いの方法(月払いか、一括払いか)
- 浮いた時間は何に使われる想定か(残業が減るのか、商談が増えるのか)。人件費に換算した比較が、そのまま回収と言えるかに関わる
- 先月の試行の30分に、ツールの出力を確認・修正する時間は入っていたか
- 試した無料版と、導入する月額6,600円のプランで、機能は同じか
- 何もしない、無料版のまま使う、人数や課を絞る、といった案と比べたか。ミナトノートを選んだ理由は何か。A社の例は、どの主張を支えるために置いているか
- 上限と見込みの差額(月約2万円)は、税区分のほかに何を想定した額か
- 確かめたいのは作成時間か、議事録の正確さか。背景では正確さも課題に挙げているが、目的と判断の基準は時間だけで決まる
- 品質の目安は「開始前と同等以上」だが、開始前に記録するのは作成時間だけ。開始前の品質は何で測るか
- 品質が開始前を下回ったら、本導入・規模縮小・中止のどれにするか(判断の基準に品質が入っていない)
- 縮小の条件は利用率、中止の条件は費用対効果で、物差しが違う。利用率が低く費用にも見合わない場合や、効果は出ているが費用に見合わない場合は、どちらにするか
- 3か月目に縮小や中止を決めるのは経営会議か、責任者か(本文は「経営会議に報告し、検討する」にとどめた)
- 情報管理担当者は誰にするか。契約とデータの扱いの確認、同意取得の手順づくり、2週間の測定、説明会を、【2026年12月】の開始までに終えられるか。情報システム部門と法務担当は、相談先として名前が載ることと、確認にかかる期間を了承しているか
- 6か月後に判断する「本導入」の範囲は営業部全体か、全社か。その場合の費用はどのくらいか
- 評価は起案者が報告し、作成時間は利用者が自分で記録する。決裁者はこの評価をそのまま受け取れるか
- 顧客や担当者は、録音の同意を求めること・求められることを負担と感じないか
- 開始前の測定、記録シートへの記入、点検、説明会にかかる時間を、費用対効果の比較に含めるか
- 議事録の正確さが「メモの取り方に左右される」は、確かめたことか(本文は「考えている」にした)
