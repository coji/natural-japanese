# 稟議書:議事録作成支援ツール「ミナトノート」の試験導入について

| 項目 | 内容 |
| --- | --- |
| 起案日 | 2026年【 】月【 】日 |
| 起案者 | 営業部長 【氏名】 |
| 提出先 | 経営会議 |
| 件名 | 議事録作成支援ツール「ミナトノート」の試験導入(6か月) |

## 1. 申請内容

顧客打ち合わせの議事録を作る時間を減らすため、音声の文字起こしと要約を行うクラウドツール「ミナトノート」を、営業部の営業担当12名で6か月間試験導入したい。

- **期間**:承認後、2026年12月(予定)から6か月
- **費用**:上限は月額10万円、6か月で60万円(見込みは475,200円)
- **条件**:契約前の確認で、データの扱いが社内規程に合っていること。合わなければ導入しない
- **進め方**:3か月目に中間評価、6か月目に最終評価を行い、本導入・規模縮小・中止を経営会議で判断する。中間評価で効果が見合わなければ、その時点で規模縮小か中止を判断する

## 2. 背景と課題

議事録の作成に、1件あたり約60分かかっている例がある。営業部全体の顧客打ち合わせは週に平均8件(月に約35件)で、担当者は打ち合わせのあとに手書きメモから議事録を作っている。60分は、先月ツールを試した担当者の普段の時間である。部全体の平均はまだ測っておらず、開始前に測る。

手書きメモと記憶から作るため、議事録の正確さは担当者のメモの取り方に左右されるおそれもある。

## 3. 期待効果

### 3.1 議事録作成時間の削減

参考値では、1件あたり30分減る。先月、営業2課の担当者1名が無料版を1件の打ち合わせで試したところ、作成時間が普段の60分から30分になった。1名・1件だけの結果なので、部全体で同じ効果が出るかは、この試験導入で確かめる。

仮に月約35件のすべてで30分ずつ減れば、削減は月に約17時間、6か月で約104時間になる(付録B)。ただし、ツールを使えるのは録音の同意を得られた打ち合わせだけなので、実際の削減はこれより小さくなる。

### 3.2 費用対効果の目安

30分減った場合、削減1時間あたりの費用は約4,600円になる。月額79,200円を月の削減時間で割った値で、15分の削減なら約9,100円、45分なら約3,000円になる(付録B)。削減した時間をほかの仕事に充てられるとすれば、営業担当者の時間単価がこの金額を上回るとき、費用に見合う。

### 3.3 金額にしにくい効果

次の効果も見込めるが、まだ確かめていないため、試験期間中に利用者アンケートで確かめる。

- 発言が記録に残り、聞き漏らしや顧客との認識違いを後から確かめられる
- 議事録が早くでき、顧客へのフォローや社内共有を早く始められる
- 担当者が交代するとき、過去の打ち合わせの内容を引き継ぎやすい

## 4. 費用

見込みは月額79,200円、6か月で475,200円である。上限は月額10万円、6か月で60万円として申請する。

| 項目 | 金額 |
| --- | --- |
| 月額(見込み) | 79,200円(6,600円/人・月 × 12名) |
| 6か月合計(見込み) | 475,200円 |
| **申請する上限** | **月額10万円、6か月合計60万円** |

- 単価が税込か税抜かは、契約前に確かめる。税抜でも月額は87,120円で、上限に収まる
- 上限と見込みの差額は、税区分や契約条件の確認結果と、機材など想定外の費用に備えるためのもの。上限を超える場合は改めて申請する
- 期間の途中で中止・縮小したときに費用も止められるかは、契約前に確かめる中途解約の条件による

## 5. リスクと対策

リスクごとに、次の対策をとる。

| リスク | 対策 |
| --- | --- |
| 顧客の同意なしに録音してしまう | 録音の前に必ず同意を得て、記録に残す。同意を求める手順と文面は統一する。同意が得られない打ち合わせでは録音せず、従来どおり手書きで作る |
| 同意が得られず、ツールを使える打ち合わせが少ない | 同意を得られた割合を毎月集計し、少なければ中間評価で人数の縮小を検討する |
| クラウドに保存した顧客情報が漏れる | 契約の前に、情報管理担当者がデータの保存場所、AIの学習に使われるか、保存期間と削除の方法、アクセス権の設定を確かめる。社内規程に合うかを情報システム部門と確かめ、問題があれば導入しない |
| 文字起こしや要約の誤り | 出力をそのまま議事録にせず、担当者が確認・修正してから確定する |
| 期待した効果が出ない | 3か月目の中間評価で効果を確かめ、見合わなければ経営会議で規模縮小か中止を判断する |
| 費用が想定を超える | 月額の上限を設け、ライセンスは12名分から増やさない。契約期間と中途解約の条件を契約前に確かめる |

## 6. 評価の方法

6か月目末の最終評価で、作成時間の削減が費用に見合うかと、情報管理に問題がないかをもとに、判断案を経営会議に出す。比べる基準として、開始前の2週間に今の作成時間を記録する。指標と測り方は付録Dに示す。

- **本導入へ進む**:作成時間の削減が費用に見合い、情報管理上の問題がない場合
- **規模を縮小して続ける**:効果は出ているが、利用率が低い場合(ライセンス数を減らすなど)
- **中止する**:削減効果が費用に見合わない場合、または情報管理上の重大な問題が起きた場合(この場合は期間の途中でも利用を止める)

## 7. 決裁をお願いする事項

1. 「ミナトノート」を営業部の営業担当12名で6か月間試験導入すること。ただし、契約前の確認で、データの扱いが社内規程に合っていることを条件とする
2. 費用の上限を月額10万円、6か月合計60万円とすること

## 付録D 評価の指標と測り方

1. **開始前(2週間)**:今の議事録作成時間を、担当者ごとに打ち合わせ1件単位で記録し、比べる基準にする
2. **試験期間中**:打ち合わせごとに、作成時間と、録音の同意を得られたかを記録シートに書く
3. **3か月目末**:中間評価を行い、経営会議に報告する
4. **6か月目末**:最終評価を行い、本導入・規模縮小・中止の判断案を経営会議に出す

| 指標 | 測り方 | 目安(案) |
| --- | --- | --- |
| 1件あたりの議事録作成時間 | 記録シート(開始前と比べる) | 開始前より平均30分短い。最低でも、3.2の費用対効果が見合う水準 |
| ツールの利用率 | 記録シート(利用した件数 ÷ 打ち合わせ件数) | 未定 |
| 議事録の品質 | 利用者アンケート、上長による確認 | 開始前と同等以上 |
| 情報管理 | 情報管理担当者による点検 | 情報漏えい・同意なしの録音が0件 |
| 費用 | 請求額 | 月額10万円以内 |

## 確認事項(起案者向け。提出前に埋めるか、決めて本文に反映する)

1. 営業担当者の時間単価はいくらか(人事・経理部門の数字)。費用に見合うかの判断(3.2、6章、付録D)は、どれもこの値と比べる
2. 削減した時間は何に使われる想定か。残業が減るのか、商談が増えるのか、どちらにもならないのか。3.2は、ほかの仕事に充てられる前提で書いている
3. 「週に平均8件(月に約35件)」は何の記録から出した数字か。本文は試算に合わせて営業部全体の件数として書いたが、それで正しいか。1人あたりの件数なら、試算は12倍ずれる
4. 部全体で月約35件なら、1人あたりは月3件ほど、作成時間は1人月3時間ほどになる。この規模の問題に、12名分のライセンス、6か月の試験、情報管理担当者の配置、打ち合わせごとの記録をかける価値があると言えるか
5. 録音の同意を得られる割合の見通しはあるか(先月の試行での実績を含む)。仮に半分なら、30分の削減でも月約9時間で、15分削減の行と同じ水準になる。ツールの利用率の目安(付録D)をいくつにするか
6. 先月の試行での30分に、出力を確認・修正する時間は含まれていたか
7. 評価の目安「平均30分短い」は、1名・1件の参考値と同じ値である。開始前に測った部全体の基準が60分と違っても、目安は30分のままか
8. 開始前2週間の記録、打ち合わせごとの記録、情報管理担当者の点検、説明会にかかる時間を、費用対効果の比較に含めるか
9. 試した無料版と、導入する月額6,600円のプランで、機能は同じか
10. 何もしない案、無料版のまま使う案、人数や課を絞って始める案と比べたか。ミナトノートを選んだ理由と、比べた記録はあるか
11. A社の例は、この稟議のどの主張を支えるために置いているか。A社での効果はまだ聞けていない
12. 契約条件(最低契約期間、中途解約の可否、支払い方法)はどうなっているか。途中で止めても費用が止まらない契約だった場合も導入するか。決裁の前に分かるか
13. 上限と見込みの差額124,800円のうち、税抜だった場合の増加分47,520円を除いた残りは、何を想定した額か
14. 議事録の品質について、開始前の水準を何で測るか。品質が開始前を下回った場合、本導入・規模縮小・中止のどれにするか
15. 縮小の条件(効果は出ているが利用率が低い)と中止の条件(費用に見合わない)は物差しが違う。利用率が低く費用にも見合わない場合、効果は出ているが費用に見合わない場合は、どちらにするか
16. 議事録の正確さの改善を、試験の目的に含めるか。正確さのばらつきは実際に確かめたことか。議事録の誤りや顧客との認識違いで起きた問題の記録はあるか
17. 承認から2026年12月の開始までに、契約条件の確認、同意取得の手順づくり、2週間の測定、説明会を終えられるか。情報管理担当者は誰で、その業務量はどうか。情報システム部門と法務担当は、相談先になっていることと確認にかかる期間を了承しているか
18. 6か月後の「本導入」の範囲は営業部全体か全社か。その費用はどのくらいになるか
19. 起案者が評価を報告して判断案も出し、作成時間は利用者が自分で記録する。この評価を、決裁者がそのまま受け取れる形になっているか
20. 録音の同意を求めることを、顧客や担当者が負担と感じないか。確かめたか
21. 起案日、起案者と情報管理担当者の氏名
