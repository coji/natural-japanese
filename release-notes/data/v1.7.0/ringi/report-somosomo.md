# critical-thinking somosomo:doc.md

**文書の性格**:決めてもらう文書(稟議書)。経営会議が、議事録作成支援ツール「ミナトノート」を営業担当12名で6か月試験導入するかと、費用の上限を決める。

**主結論**:「ミナトノート」を営業部の営業担当12名で6か月間試験導入し、費用の上限を月額10万円、6か月合計60万円とする(1, 12, 143, 144行)。
目的は「議事録作成にかかる時間を減らす」(12行)に絞られているが、背景では議事録の正確さ(22行)も課題に挙げている。どちらを確かめる試験なのかは、下の問い4で問う。

足場には、隣にある `doc.md.logic.yaml` の主結論・論点・前提を使った。YAML は変更していない。

---

## 前提

### 1. 削減した時間は「回収」になるか

- **問い**:54行は「営業担当者の時間単価(人件費)がこの金額を上回れば、費用は回収できる」としている。これは、浮いた30分が人件費の削減か、売上につながる仕事に振り向けられることを前提にしている。浮いた時間は実際に何に使われる想定か。残業が減るのか、商談が増えるのか、どちらでもなく吸収されるのか、書き手は見通しを持っているか
- **倒れる場所**:54行の回収の考え方。これを足場にした119行の目安(「4.2の費用対効果が見合う水準」)、127行と129行の判断基準(「費用に見合う」「見合わない」)
- **要る材料**:対象12名の残業時間の記録。削減した時間を何に振り向けるかについての営業部の方針

### 2. 月35件のすべてで使える、という前提

- **問い**:4.1の試算(47〜50行)と4.2の表(56〜60行)は、月約35件の打ち合わせすべてでツールを使う計算になっている。一方で、99行は同意が得られない打ち合わせでは録音しないとし、100行は「ツールを使える打ち合わせが少ない」リスクを自分で挙げている。仮に同意を得られるのが半分なら、30分削減でも月の削減時間は約9時間になり、58行の「15分」の行(約9,100円)と同じ水準になる。同意を得られる割合について、書き手は見通しを持っているか。120行の利用率の目安が空欄なのは、この見通しがまだないからか
- **倒れる場所**:49〜50行の削減時間、58〜60行の削減1時間あたりの費用、127行の「費用に見合い」
- **要る材料**:顧客に録音の同意を求めたときの実績(先月の試行を含む)。対象の打ち合わせのうち、同意を求められそうなものの割合の見通し

## 問いそのもの

### 3. 解こうとしている問題は、どのくらいの大きさか

- **問い**:20行の「週に平均8件(月に約35件)」は、営業部全体の件数か、担当者1人あたりの件数か。49行は35件に30分を掛けて、12名分の月額79,200円(78行)と比べているので、部全体の件数として読める。そうだとすると、1人あたりの打ち合わせは月3件ほどで、議事録の作成時間は1人月3時間ほどになる。この大きさの問題に、6か月の試験、情報管理担当者の配置(91行)、打ち合わせごとの記録(111行)をかける価値があるか、決裁者は問うのではないか。逆に1人あたりの件数なら、4.1と4.2の試算は12倍ずれ、結論は反対の向きに大きく変わる。どちらの読みで書いたか
- **倒れる場所**:12行の目的の重さ、47〜50行の試算、56〜60行の費用対効果の表、143行の「12名」という規模
- **要る材料**:12名それぞれの、月あたりの顧客打ち合わせ件数の記録

### 4. 確かめたいのは時間か、正確さか

- **問い**:背景には「議事録の正確さは担当者のメモの取り方に左右される」(22行)があり、4.3には聞き漏らしや認識違いの確認(68行)が挙がっている。しかし、目的(12行)と判断基準(127〜129行)は作成時間の削減だけで決まる。決裁者が知りたいのは「議事録が速くなるか」なのか、「顧客との認識違いが減るか」なのか。もし後者に価値があるなら、時間だけで本導入か中止かを決める基準は、確かめたいものを測っているか
- **倒れる場所**:12行の目的、119行と121行の指標、127〜129行の判断基準
- **要る材料**:議事録の誤りや顧客との認識違いが原因で起きた問題の件数や事例の記録

## 他の選択肢

### 5. 何もしない案、無料版のまま、範囲を変える案と比べたか

- **問い**:文書は、試験導入するかしないかの二択として書かれている。何もしない場合、41行で試した無料版のまま使い続ける場合、人数や対象の課を絞って始める場合と比べたか。無料版で足りない点があるなら、それは何か。ツールの選定も、根拠は「同業のA社が全社で導入している」(33行)だけに見え、A社での効果はまだ聞けていない(35行)。ミナトノートを選んだ比較の記録はあるか
- **倒れる場所**:12行と143行の「ミナトノートを、12名で」という申請の形
- **要る材料**:比べた案の記録(無料版の機能や利用の制限、人数を絞った場合の費用と、評価に足りる件数が集まるかの見通し)。ミナトノートを選んだ理由の記録

## 覆る条件

### 6. 損益の分かれ目を、承認の時点で誰も見られない

- **問い**:文書は「時間単価がこの金額を上回れば回収できる」(54行)と覆る条件を自分で書いているが、肝心の時間単価が空欄(62行)になっている。決裁者は、30分削減の行(約4,600円)を越えるのか、15分削減の行(約9,100円)でも越えるのかを、承認の時点で判断できない。また、先月の試行で60分が30分になった(41行)とき、102行が求める「担当者が必ず確認・修正」の時間は含まれていたか。含まれていなければ、30分の削減そのものが小さくなる
- **倒れる場所**:54行の回収の判断、59行の「参考値」の行、119行の「平均30分短い」という目安
- **要る材料**:営業担当者の時間単価(人事・経理部門の数字)。試行時に、出力の確認・修正にかかった時間の記録

### 7. 途中でやめられない契約だったら

- **問い**:129行は「期間の途中でも利用を止める」とし、103行は中間評価で中止を判断するとしている。しかし、中途解約できるかどうかは「契約前に確認する」(104行)とあり、まだ分かっていない。最低契約期間が6か月より長い、または一括払いの契約だった場合、途中で止めても費用は止まらず、6か月60万円という上限(15行、144行)の枠組みも崩れる。この確認の前に承認を求めるのは、確認の結果によっては導入しない、という含みか。それとも条件が合わなくても進めるつもりか
- **倒れる場所**:15行と144行の費用の上限、103行と129行の途中での中止
- **要る材料**:ミナトノートの契約条件(最低契約期間、中途解約の可否、支払いの方法)

## 利害と実行

### 8. 開始前の準備を、誰がいつまでにやるか

- **問い**:開始は【2026年12月】(14行)だが、起案日は空欄(5行)で、承認から開始までに、契約条件とデータの扱いの確認、同意取得の手順づくり、2週間の作成時間の測定、説明会(110行、135行)を終える必要がある。これを中心になって進める情報管理担当者は、まだ決まっていない(91行)。情報システム部門と法務担当(93行)は、相談先として自分の名前が書かれていることと、確認にかかる期間を知っているか。この日程で開始できると、書き手は見込んでいるか
- **倒れる場所**:14行の開始時期、110行の開始前の測定、112〜113行の中間評価と最終評価の時期
- **要る材料**:情報管理担当者の候補と、その人の業務量の見通し。情報システム部門と法務担当の了承と、確認にかかる期間の見通し

### ほかに細かい問いが4件

- 本導入の範囲:6か月後に判断する「本導入」(16行、113行、127行)は、営業部全体か、全社か。その費用の大きさを、決裁者は今の時点で知りたいのではないか
- 評価する人:起案者の営業部長が責任者として評価を報告し(90行)、判断案も出す(113行)。作成時間は利用者が自分で記録する(92行、111行)。決裁者は、この評価をそのまま受け取れるか
- 顧客の側の負担:録音されるのは顧客で、同意を求めるのは打ち合わせの場にいる担当者(99行)。顧客や担当者がこれを負担と感じるかどうかを、書き手は確かめたか
- 記録の負担:打ち合わせごとの作成時間と同意の記録(111行)は、利用者に新しい作業を足す。その時間は、削減時間の計算(49行)に入っているか

## 反論(仮の立場)

検査のための仮の立場で、書き手の主張ではない。採用するかは書き手が決める。

- **削減が小さく、管理の手間に見合わないという読み**:20行の35件が部全体の件数なら、49行の削減は12名で月約17時間、1人あたり月1.5時間ほどになる。これに対して、月額79,200円(78行)に加え、情報管理担当者の配置(91行)、開始前2週間の測定(110行)、打ち合わせごとの記録(111行)、毎月の集計(100行)がかかる。試験そのものの手間が、削減する時間と同じくらいの大きさになる、と読める
- **効果の大部分が顧客次第だという読み**:99行と100行は、ツールを使えるかどうかが顧客の同意で決まることを文書自身が認めている。そうすると、この6か月で確かめられるのはツールの効果より、顧客が録音を受け入れるかどうかの方であり、それは営業部の側では動かせない、と読める
