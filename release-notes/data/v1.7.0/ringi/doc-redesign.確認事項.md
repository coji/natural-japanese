# doc-redesign.md の確認事項

稟議を出す前に書き手が答える問い。稟議書には載せない。

## 先に答える問い

1. 「週に平均8件(月に約35件)」は営業部全体の件数か、担当者1人あたりの件数か。何の記録から出した数字か。部全体なら1人あたりの打ち合わせは月3件ほどで、作成時間は1人月3時間ほどになる。それでも12名分のライセンスと6か月の試験に見合うか
2. ミナトノートの契約期間、中途解約の可否、支払いの方法はどうなっているか。途中で中止や縮小をしたとき、費用も止まるか。最低契約期間が6か月より長い、または一括払いなら、「6か月合計60万円」の上限と途中での中止が成り立たない。決裁の前に確かめられるか
3. 営業担当者の時間単価(人件費)はいくらか。人事・経理部門の数字が入らないと、決裁者は「削減1時間あたり約4,600円」を上回るかを承認の時点で判断できない

## そのほか

- 情報管理で「問題があれば導入しない」としているが、決裁事項は条件のない導入の承認になっている。「契約前の確認で問題がなければ導入する」という条件つきの承認として出すか
- 浮いた時間は、何に使われる想定か。残業が減るのか、商談が増えるのか、どちらでもなく吸収されるのか
- 開始前の測定、打ち合わせごとの記録、情報管理担当者の点検、説明会にかかる時間を、費用対効果の比較に含めるか
- 先月の試行で60分が30分になったとき、出力の確認・修正にかかる時間は含まれていたか
- 試したのは無料版で、導入するのは月額6,600円のプランである。両者の機能は同じか
- 顧客に録音の同意を求めたときの実績(先月の試行を含む)はあるか。同意を得られる割合の見通しはどのくらいか。ツールの利用率の目安はいくつにするか
- 評価の目安「開始前より平均30分短い」は1名・1件の参考値と同じ値である。部全体の開始前の作成時間が60分と違った場合も、目安は「30分短い」のままか
- 議事録の品質の目安は「開始前と同等以上」だが、開始前の2週間に記録するのは作成時間だけである。開始前の品質は何で測るか
- 品質が開始前を下回った場合、本導入・縮小・中止のどれになるか
- 「効果は出ているが、費用には見合わない」場合は、縮小と中止のどちらになるか。利用率が低くて費用に見合わない場合は、どちらの基準を優先するか
- 正確さの改善は、この試験導入の目的に入るか。議事録の誤りや顧客との認識違いが原因で起きた問題の件数や事例の記録はあるか
- 何もしない場合、無料版のまま使い続ける場合、人数や対象の課を絞って始める場合と比べたか。無料版で足りない点は何か
- ミナトノートを選んだ理由と、比べたツールの記録はあるか。A社の全社導入は、この稟議のどの主張を支えるために置いているか
- 上限と見込みの差額のうち、税抜だった場合の増加分(6か月で47,520円)を除いた残りは、どの契約条件を想定して決めたか
- 情報管理担当者は誰が務めるか。その人の業務量の見通しはあるか
- 情報システム部門と法務担当は、相談先として名前が載っていることと、確認にかかる期間を知っているか。【2026年12月】の開始に、開始前の準備が間に合うか
- 6か月後に判断する「本導入」の範囲は営業部全体か、全社か。その場合の費用の大きさを、決裁者に今の時点で示すか
- 評価の報告と判断案は起案者の営業部長が出し、作成時間は利用者が自分で記録する。決裁者がこの評価をそのまま受け取れる形になっているか
- 録音の同意を求めることを、顧客や担当者が負担と感じるかどうかを確かめたか
