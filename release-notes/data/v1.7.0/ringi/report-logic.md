## 文書の性格

## 主結論

「ミナトノート」を営業担当12名で6か月間試験導入し、費用の上限を月額10万円、6か月合計60万円とする(行12、143、144)。

主結論を支える前提のうち、次の3つは本文にない言葉で補った。「削減された時間は人件費相当の価値として回収される」(行54)、「月約35件の打ち合わせすべてでツールを使う」(行47〜50)、「期間の途中で中止・縮小すれば、その分の費用を止められる」(行103、104、129)。

文書の中の計算(件数、削減時間、削減1時間あたりの費用、税抜の場合の月額、6か月合計)は、文書の数字どうしで検算し、すべて合っていた。

## 1. 矛盾

- **行121 と 行110**:品質の目安は「開始前と同等以上」だが、開始前の2週間に記録するのは「現在の議事録作成時間」だけになっている。開始前の品質は、何を使って測るのか。
- **行104 と 行100・128**:費用の対策では「ライセンス数を12名分に固定する」と書き、同意のリスクと判断基準では「人数の縮小」「ライセンス数を減らす」と書いている。「固定」は増やさないという意味か、期間中は変えないという意味か。
- **行16・112・137 と 行103・100**:冒頭とスケジュールでは、中間評価は経営会議への「報告」で、判断は6か月目に「改めて」行う形になっている。一方、リスクの表では「3か月目の中間評価で……規模縮小か中止を判断する」と書いている。3か月目に縮小や中止を決めるのは誰か。経営会議か、責任者か。
- **行101 と 行143**:情報漏えいの対策には「問題があれば導入しない」とある。一方、10章の決裁事項は条件のない導入の承認になっている。今回の決裁は「契約前の確認で問題がなければ導入する」という条件つきの承認か。
- **行83 と 行84**:上限と見込みの差額は「税区分や契約条件の確認結果に備えるため」と書き、続く行では、想定外の費用(機材など)も「上限の範囲で対応」すると書いている。差額はどちらに備えるためのものか。

## 2. 根拠のない主張

- **行54・62・119・127・129(前提条件のちがい)**:費用を回収できるか、本導入か中止かの判断は、どれも営業担当者の時間単価と比べる形になっている。ところが、その時間単価は「【 】円」のまま空いている。時間単価が分からない状態で、経営会議は行119の「最低でも、4.2の費用対効果が見合う水準」を、どの数字として読めばよいか。
- **行47〜50 と 行99・100・120(前提条件のちがい)**:削減時間の試算は、月約35件すべてでツールを使う計算になっている。一方、同意が得られない打ち合わせでは「録音せず、従来どおり手書き」にするとあり、利用率の目安は「【 】%以上」で空いている。試算の約17時間は、利用率100%を前提にした数字か。
- **行20(前提条件のちがい/異質なものの同質化)**:「営業部では、顧客打ち合わせが週に平均8件」とあるが、これは営業部全体の件数か、1人あたりの件数か。部全体なら、12名で月約35件、つまり1人あたり月3件前後になる。12名分のライセンスと、この件数の組み合わせでよいか。また、「平均8件」は何の記録から出した数字か。
- **行119 と 行41・21(偶然の必然化)**:行41では「1名・1件だけのものであり、参考値にとどまる」と断っている。それなのに、評価の目安は同じ値の「平均30分短い」になっている。基準の60分も、試した同じ担当者のもの(行21)である。部全体の基準が60分と違った場合でも、目安は「30分短い」のままか。
- **行54(前提条件のちがい)**:「時間単価がこの金額を上回れば、費用は回収できる」は、削減した時間がほかの仕事に使われることを前提にしている。この前提は本文に書かれていない。また、4.2の費用はライセンス料だけである。開始前2週間の記録(行110)、打ち合わせごとの記録シート(行111)、情報管理担当者の点検(行91)、説明会(行135)にかかる時間は、費用対効果の比較に含めるのか。
- **行41 と 行31(異質なものの同質化)**:試したのは「無料版」で、導入するのは「1人あたり月額6,600円」のプランである。両者の機能が同じであることは、文書のどこで確かめられているか。
- **行104 と 行129・103(前提条件のちがい)**:中止の場合は「期間の途中でも利用を止める」とあるが、「6か月で解約できるかなど」の条件は契約前に確認する予定で、まだ分かっていない。途中で中止や縮小をした場合に費用も止まるかどうかは、決裁の前に分かるか。
- **行33・35**:A社の全社導入は、導入するツールの表に「社外の利用例」として載っている。ただし、その効果や注意点は「可能であれば」これから聞き取る段階である。A社の例は、この稟議のどの主張を支えるために置いているのか。
- **行15・83**:上限を月額10万円とした根拠は、税区分と契約条件への備えとして説明されている。税抜だった場合の増加分は6か月で47,520円で、差額124,800円の残りは契約条件への備えになる。その残りの額は、何を想定して決めたのか。

## 3. 事実と推論の混在

- **行22**:「議事録の正確さは担当者のメモの取り方に左右される」は、「手書きメモと記憶をもとに作るため」から導いた推論だが、測った事実と同じ言い切りの形で書かれている。正確さのばらつきは、実際に確かめたことか。

## 4. 横の論理(並列の漏れ・ダブり・ねじれ)

- **行119〜123 と 行127〜129**:評価の指標は5つあるが、判断の基準に出てくるのは作成時間、利用率、情報管理の3つだけである。品質(行121)が開始前を下回った場合、本導入・縮小・中止のどれになるのか。
- **行128 と 行129**:縮小の条件は「効果は出ているが、利用率が低い」、中止の条件は「削減効果が費用に見合わない」で、物差しが違う(効果があるかどうかと、費用に見合うかどうか)。利用率が低いと削減時間も減り、費用に見合わなくなる。その場合、両方の条件に当てはまる。また、「効果は出ているが、費用には見合わない」場合はどちらになるのか。
- **行12 と 行22**:申請の目的は「議事録作成にかかる時間を減らすため」の1つだけだが、背景では正確さも課題に挙げている。正確さの改善は、この試験導入の目的に入るのか。
