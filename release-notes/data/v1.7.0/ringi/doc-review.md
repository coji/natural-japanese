# 稟議書:議事録作成支援ツール「ミナトノート」の試験導入について

| 項目 | 内容 |
| --- | --- |
| 起案日 | 2026年【 】月【 】日 |
| 起案者 | 営業部長 【氏名】 |
| 提出先 | 経営会議 |
| 件名 | 議事録作成支援ツール「ミナトノート」の試験導入(6か月) |

## 1. 申請内容

顧客打ち合わせの議事録作成にかかる時間を減らすため、音声の文字起こしと要約を行うクラウドツール「ミナトノート」を、営業部の営業担当12名で6か月間試験導入したい。

- **期間**:承認後の【2026年12月】から6か月
- **費用**:月額の上限は10万円、6か月の総額は60万円以内(見込みは475,200円)
- **進め方**:試験期間中に効果と情報管理の状況を測る。3か月目に中間評価、6か月目に最終評価を行い、本導入・規模縮小・中止のいずれにするかを経営会議で改めて判断する

## 2. 背景と課題

営業部全体の顧客打ち合わせは週平均8件(月約35件)で、担当者は打ち合わせのあと、手書きメモから議事録を作っている。

- 件数は、営業支援システムの訪問記録の直近6か月から出した。12名で割ると、1人あたり月3件ほどになる。
- 先月ツールを試した担当者は、普段は1件あたり約60分かけている。部全体の平均作成時間はまだ測っておらず、試験導入の開始前に測る(6章)。
- 手書きメモと記憶をもとに作るため、議事録の正確さは担当者のメモの取り方に左右されると考えている。

## 3. 期待効果

先月の試行と同じ30分の削減では、すべての打ち合わせで使っても、費用が、削減できる時間の人件費を上回る。下回るのは1件あたり約39分以上減った場合で、そこまで減るかをこの試験導入で確かめる。

- 先月、営業2課の担当者1名が無料版を1件の打ち合わせで試したところ、作成時間は普段の60分から30分に減った。1名・1件だけの結果で、参考値にとどまる。
- 月約35件のすべてで使い、1件あたり30分減ると、削減時間は月約17時間になる。月額79,200円をこれで割ると、削減1時間あたりの費用は約4,600円になる。経理部が社内の試算に使う標準単価(1時間3,500円)より高い(試算は付録A)。
- 金額にしにくい効果も見込む。発言が記録に残り、聞き漏らしや顧客との認識違いを後から確かめられること、議事録が早くでき、顧客へのフォローや社内共有を早く始められること、担当者が交代するときに引き継ぎやすいことである。まだ確かめていないため、試験期間中に利用者アンケートで確かめる。

## 4. 費用

申請する上限は月額10万円、6か月合計60万円とする。見込みは月額79,200円(1人あたり6,600円 × 12名)、6か月で475,200円である。

- 単価が税込か税抜かは、契約前に確かめる。税抜でも月額は87,120円で、上限に収まる。
- 上限と見込みの差額は、税区分や契約条件の確認結果に備えるためのもの。機材など上記以外の費用は想定していない。上限を超える場合は、支出の前に改めて申請する。
- ライセンス数は12名分を上限とし、増やさない。
- 最低契約期間はなく、月単位で解約できる(販売店に確認済み)。途中で縮小や中止をすれば、費用も止められる。

## 5. リスクと対策

顧客の同意が得られなければ録音せず、契約前の確認で情報管理に問題があれば導入しない。

| リスク | 対策 |
| --- | --- |
| 顧客の同意を得ないまま録音してしまう | 録音の前に必ず顧客の同意を得て、記録に残す。同意を求める手順と文面は統一する。同意が得られない打ち合わせでは録音せず、従来どおり手書きで議事録を作る |
| 同意が得られず、ツールを使える打ち合わせが少ない | 同意を得られた割合を毎月集計する。少ない場合は、中間評価で人数の縮小を検討する |
| クラウドに保存した顧客情報が漏れる | 契約の前に、情報管理担当者がデータの保存場所、AIの学習に使われるかどうか、保存期間と削除の方法、アクセス権の設定を確認し、社内規程に合うかを情報システム部門と確かめる。どれもまだ確かめていない。問題があれば導入しない |
| 文字起こしや要約に誤りがある | ツールの出力をそのまま議事録にせず、担当者が必ず確認・修正してから確定する |
| 期待した効果が出ない | 3か月目の中間評価の結果を経営会議に報告し、見合わない場合は規模縮小か中止を検討する |

## 6. 評価の方法

開始前に今の作成時間を測り、3か月目と6か月目に評価して、本導入・規模縮小・中止を経営会議で判断する。

1. **承認後〜開始前**:契約条件とデータの扱いの確認、同意取得の手順づくり、利用者への説明会。現在の作成時間を2週間、担当者ごとに打ち合わせ1件単位で記録し、比較の基準にする
2. **1〜3か月目**:打ち合わせごとに、作成時間と録音の同意を得られたかどうかを記録シートに記入する。利用状況と費用は毎月確かめる
3. **3か月目末**:中間評価を行い、結果を経営会議に報告する
4. **4〜6か月目**:中間評価の結果に応じて見直しながら、運用を続ける
5. **6か月目末**:最終評価を行い、本導入・規模縮小・中止の判断案を経営会議に提出する

| 指標 | 測定方法 | 目安(案) |
| --- | --- | --- |
| 1件あたりの作成時間 | 記録シート(開始前と比較) | 費用に見合う水準(開始前より平均約39分短い) |
| ツールの利用率 | 記録シート(利用した件数 ÷ 打ち合わせ件数) | 【 】%以上 |
| 議事録の品質 | 利用者アンケート、上長による確認 | 開始前と同等以上 |
| 情報管理 | 情報管理担当者による点検 | 情報漏えい・同意なしの録音が0件 |
| 費用 | 請求額 | 月額10万円以内 |

- **本導入へ進む**:作成時間の削減が費用に見合い、情報管理上の問題がない場合
- **規模を縮小して続ける**:効果は出ているが、利用率が低い場合(ライセンス数を減らすなど)
- **中止する**:削減効果が費用に見合わない場合、または情報管理上の重大な問題が起きた場合(この場合は期間の途中でも利用を止める)

2. 費用の上限を月額10万円、6か月合計60万円とすること

## 付録A 削減時間と費用対効果の試算

月約35件(週8件 × 52週 ÷ 12か月)のすべてでツールを使う場合の試算。人件費の比較には、経理部が社内の試算に使う標準単価(1時間3,500円)を使う。

| 1件あたりの削減時間 | 月あたりの削減時間 | 6か月の削減時間 | 削減1時間あたりの費用 | 標準単価との比較 |
| --- | --- | --- | --- | --- |
| 15分 | 約9時間 | 約52時間 | 約9,100円 | 上回る |
| 30分(試行時の参考値) | 約17時間 | 約104時間 | 約4,600円 | 上回る |
| 45分 | 約26時間 | 約156時間 | 約3,000円 | 下回る |

- 削減1時間あたりの費用は、月額79,200円を月あたりの削減時間で割った値。
- 標準単価と同じになるのは、月約22.6時間(79,200円 ÷ 3,500円)の削減で、1件あたり約39分にあたる。単価が税抜で月額87,120円の場合は、1件あたり約43分になる。
