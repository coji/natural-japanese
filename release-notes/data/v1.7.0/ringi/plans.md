# doc.md の構成案

元の文書は「ツールを導入する稟議」として、申請内容 → 背景 → ツール → 期待効果 → 費用 → 体制 → リスク → 評価 → スケジュール → 決裁事項の順に並んでいる。効果の根拠は1名・1件の試行だけで、時間単価・利用率・中途解約の条件が空いたまま、費用対効果の表が本編の中ほどに置かれている。

## 案A:頼む中身を小さくする案(開始前の確認と測定を先にして、導入は2回目に頼む)

- **主張**:導入するかを決める前に、手元で確かめられることがある。契約条件とデータの扱いの確認、営業担当者ごとの打ち合わせ件数と作成時間の測定を先に済ませ、その結果を添えて、試験導入と費用の上限を改めて申請する
- **骨組み**:申請内容(先に確かめること)/確かめないと決められない理由/確かめ方/結果が出たあとの申請
- **答える問い**:S3(件数は部全体か1人あたりか)、S7(中途解約できるか)、S6(時間単価)、S2(同意を得られる割合の見通し)、L1(行20・47〜50)、L4(行101と143)
- **元の決裁事項が倒れる場所**:
  - S3・行20:週平均8件が部全体の件数なら、1人あたりの作成時間は月3時間ほどになる。6か月の試験、情報管理担当者の配置(行91)、打ち合わせごとの記録(行111)をかけるほどの問題か、という問いが立つ
  - S7・行104:6か月で解約できない契約なら、途中で中止しても費用は止まらず、行15・144の「6か月合計60万円」という上限の枠組みが崩れる
  - S6・行62:時間単価が空欄のままでは、行54の「回収できる」を承認の時点で誰も確かめられない
- **縮めた決裁事項**(元の文書の言葉で):契約条件とデータの扱いの確認、現在の作成時間の測定(行135)を先に行うこと。試験導入(行143)と費用の上限(行144)は、その結果を添えて改めて申請する
- **この案を選ぶなら先に見る問い**:S3(行20の件数が部全体か1人あたりか)と S7(契約期間と中途解約の条件)。この2つの答えで、元の決裁事項をそのまま出してよいかが決まる
- **弱点**:開始が遅れる。測定には契約が要らないが、作成時間の短縮そのものは試験を始めないと確かめられない

## 案B:6か月で3つの問いに答える試験として頼む(採用)

- **主張**:導入するかを決める材料はまだない。6か月・上限60万円で、「作成時間が費用に見合うだけ減るか」「顧客が録音に同意するか」「情報を規程どおり管理できるか」の3つに答えを出し、本導入・規模縮小・中止を経営会議で改めて判断する
- **骨組み**:申請内容(確かめる3点)/背景/効果の見込み/確かめ方と判断の基準/情報管理と顧客の同意/費用/決裁をお願いする事項/付録(ツールの概要、試算、評価の指標、体制、スケジュール)
- **答える問い**:L 偶然の必然化(行41・119)は「参考値」の扱いを前に出して、L 利用率100%の前提(行47〜50)は試算の条件を本文に書いて、L 中間評価で誰が判断するか(行16・103・112)は経営会議に揃えて、L 固定と縮小(行104・128)と L 差額の使い道(行83・84)はどちらかに揃えて、L 正確さの言い切り(行22)は言い方を合わせて答える。S2・S4・S6 は確かめる3点と判断の基準を前に出すことで、問いのありかを決裁者に見せる
- **弱点**:S3(件数の読み)と S7(中途解約)の答えは本文の中では出ない。決裁者がそこを突けば、案Aに戻る

## 案C:損益の分かれ目を背骨にして頼む

- **主張**:削減1時間あたりの費用は、30分削減なら約4,600円、15分なら約9,100円になる。営業担当者の時間単価がこれを上回るかを、6か月の実測で確かめさせてほしい
- **骨組み**:申請内容/損益の分かれ目(削減時間ごとの1時間あたり費用)/分かれ目を確かめる測り方/費用と止め方/決裁をお願いする事項/付録
- **答える問い**:S6(時間単価)、L 費用回収の前提(行54)、L 縮小と中止の物差し(行128・129)
- **弱点**:背骨の中心にある時間単価が空欄(行62)で、文書の中では埋められない。同意の割合(S2)と情報管理(行101)が脇に回る

## 選んだ案と理由

案Bを選んだ。頼む中身(12名・6か月・上限60万円)を保つ案のうち、元の文書が持っている材料だけで背骨が立つのは案Bだけだった。元の文書は、効果が1名・1件の参考値にとどまること(行41)、ツールを使えるかが顧客の同意で決まること(行99・100)、情報管理に問題があれば導入しないこと(行101)を、すでに自分で書いている。案Bはこれを申請の冒頭に集めて「何を確かめる試験か」として見せるだけで、新しい事実を要さない。案Cは背骨の中心が空欄の時間単価になり、文書の中では立たない。

案Aは頼む中身が変わるので、書き手にしか選べない。S3 と S7 の答えを見てから選ぶとよい。
