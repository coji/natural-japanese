## 先に答える問い

1. 9か月・2,700万円の契約を3か月目で止めたとき、フェーズ2の1,800万円の支払いはどう扱う契約ですか。本文には「3か月目で止められる」とだけ書いています。
2. 引き継ぎ失注の件数・金額・理由は、営業本部長の「引き継ぎで2社失った」という話のほかに材料がありますか。台帳があるとのことですが、経営会議の前に見せてもらい、規模だけでも本文に入れられますか。
3. 3か月目にフェーズ2へ進むかを決める基準(どの数字がどの水準なら進むか)はどうしますか。営業本部長の判断のあとに、もう一度経営会議にかけますか。

## そのほか

- 引き継ぎ失注の原因が「情報の抜け落ち」だという見立ては、何を材料にしていますか。情報がそろっていても失注した例や、抜けても失注しなかった例はありますか。
- 課題の大きさがまだ分からないまま、経営会議に900万円(または2,700万円)を決めてもらってよいですか。1か月目の試算で見合わないと分かったら、1か月目で止められますか。
- 1か月目の試算で「失注率の改善幅」をどう置きますか。目標値の合意は3か月目なので、本文では「仮に置いて」としました。
- 入力項目を最小限に絞ることと、引き継ぎで抜けやすい経緯や約束事を SFA に残すことを、どう両立させますか。本文の期待効果は「SFA に残っていれば」という条件つきにしました。
- 診断で「SFA より先に取り組むべきこと」が見つかった場合、フェーズ1の成果物(SFA の要件・製品比較・導入計画)は何に置き換わりますか。
- SFA を入れない道(何もしない、引き継ぎルールの整備だけを先に行う、退職が近い担当者の顧客に絞る、御社と SFA ベンダーだけで進める)と本提案を比べましたか。比べたなら、その記録を経営会議に出せますか。
- 継続判断の材料をそろえる当社が、フェーズ2の受注者でもあります。この利害の重なりを、御社にどう説明しますか。
- 入力率がどこまで下がったら効果が出ないと見ますか。7か月目の全体展開のあとに入力率が上がらなかった場合、どう扱いますか。
- 全体展開(7か月目)より前に退職するベテランがいた場合、その方の顧客情報は計画のどこで残しますか。向こう1〜2年に退職・異動の予定がある担当者は何名ですか。
- 全体展開から効果測定(9か月目)までは約2か月です。その間に、担当が替わる顧客や独り立ちする新人は何件ありそうですか。9か月目の「効果目標に対する結果」は何を測りますか。

- 経営会議が見る総額に、ライセンス費(30名+管理職分)の概算の幅と、御社側の工数(ヒアリング、試行メンバー、窓口)の見込みを入れられますか。
- 「営業担当の平均年齢が高い」は、何の数字に基づいていますか。年齢の分布は出せますか。
- 新人の立ち上がりは、御社の課題として確かめたことですか。課題の節には書いていません。新人は年に何人配属されますか。
- 昨年の異動・退職4名で、担当が替わった顧客は何社ですか。
