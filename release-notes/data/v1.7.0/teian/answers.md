1. 問い:経営会議に承認をお願いするのは、総額2,700万円の9か月契約ですか、それともフェーズ1の900万円だけですか。3か月目にフェーズ2へ進まないと決めた場合、フェーズ2の1,800万円は払わずに済む契約ですか(行19・21・157・190)。
   答え:経営会議にかけるのは9か月・2,700万円の契約です。3か月目で止められる形にしてあります。フェーズ1だけの契約にすることもでき、その場合も費用は900万円で変わりません。9か月契約を3か月目で止めたときの支払いの細かい条件は、いまお伝えできる以上のことは分かりません。

2. 問い:「引き継ぎの場面で実際に失注が起きている」は、何をもとに書きましたか(御社からの聞き取り、特定の失注事例など)。件数や金額で、いま分かっていることはありますか(行12・33・121)。
   答え:営業本部長が「引き継ぎで2社失った」と話したのを聞いたことがもとです。失注の理由を確かめた記録はなく、その2社を失った理由も聞いていません。失注の件数と金額は分かりません。御社の台帳を見せてもらっていないためです(営業本部長によれば台帳はあるそうです)。関連して分かっているのは、営業本部長の話では去年の異動と退職が合わせて4名だったことだけで、担当が替わった顧客の数は聞いていません。

3. 問い:3か月目にフェーズ2へ進むかを決めるのは、営業本部長ですか、それとももう一度経営会議にかけますか(行179・189)。
   答え:御社の営業本部長が判断する想定です。もう一度経営会議にかけるかどうかは分かりません。判断の基準もまだ決めていません。
