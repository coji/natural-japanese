# 稟議書:議事録作成支援ツール「ミナトノート」の試験導入について

| 項目 | 内容 |
| --- | --- |
| 起案日 | 2026年【 】月【 】日 |
| 起案者 | 営業部長 【氏名】 |
| 提出先 | 経営会議 |
| 件名 | 議事録作成支援ツール「ミナトノート」の試験導入(6か月) |

## 1. 申請内容

顧客打ち合わせの議事録作成にかかる時間を減らすため、音声の文字起こしと要約を行うクラウドツール「ミナトノート」を、営業部の営業担当12名で6か月間試験導入したい。

- **期間**:承認後の【2026年12月】から6か月
- **費用**:月額の上限は10万円、6か月の総額は60万円以内(見込みは475,200円)
- **進め方**:試験期間中に効果と情報管理の状況を測定する。3か月目に中間評価、6か月目に最終評価を行い、本導入・規模縮小・中止のいずれにするかを経営会議で改めて判断する

## 2. 背景と課題

議事録の作成には、先月ツールを試した担当者の場合、普段は1件あたり約60分かかっている。手書きメモと記憶をもとに作るため、議事録の正確さは担当者のメモの取り方に左右される。

## 3. 議事録作成時間の削減

参考値どおり1件あたり30分減った場合、月あたり約17時間、6か月で約104時間の削減になる。月あたりの打ち合わせ約35件(週8件 × 52週 ÷ 12か月)に、1件あたりの削減時間30分(試行時の参考値)を掛けた値である。参考値の内容は付録Aに示す。

## 4. 費用対効果の目安

営業担当者の時間単価(人件費)が、削減できる1時間あたりの費用を上回れば、費用は回収できる。削減できる1時間あたりの費用は、1件30分の参考値の場合、月額費用79,200円を月あたりの削減時間約17時間で割った約4,600円である。ほかの削減時間の場合は付録Bに示す。

## 5. 費用

申請する上限は、月額10万円、6か月合計60万円である。見込みの内訳は次のとおり。

| 項目 | 金額 |
| --- | --- |
| 単価 | 6,600円/人・月 |
| 人数 | 12名 |
| 月額(見込み) | 79,200円 |
| 6か月合計(見込み) | 475,200円 |

上限と見込みの差額は、税区分や契約条件の確認結果に備えるためのものである。上限を超える支出は行わない。上記以外の費用(機材など)は想定していない。必要になった場合も上限の範囲で対応し、超える場合は改めて申請する。

## 6. リスクと対策

リスクは次の6つである。

- 録音について顧客の同意を得ないまま録音してしまう
- 顧客の同意が得られず、ツールを使える打ち合わせが少ない
- クラウドに保存した顧客情報が漏れる
- 文字起こしや要約に誤りがある
- 期待した効果が出ない
- 費用が想定を超える

費用が想定を超えるリスクには、月額の上限を設け、ライセンス数を12名分に固定する。6か月で解約できるかなど、契約期間と中途解約の条件を契約前に確認する。ほかの5つの対策は付録Fに示す。

## 7. 評価の指標

試験は次の5つの指標で評価する。

| 指標 | 測定方法 | 目安(案) |
| --- | --- | --- |
| 1件あたりの議事録作成時間 | 記録シート(開始前と比較) | 開始前より平均30分短い。最低でも、4章の費用対効果が見合う水準 |
| ツールの利用率 | 記録シート(利用した件数 ÷ 打ち合わせ件数) | 【 】%以上 |
| 議事録の品質 | 利用者アンケート、上長による確認 | 開始前と同等以上 |
| 情報管理 | 情報管理担当者による点検 | 情報漏えい・同意なしの録音が0件 |
| 費用 | 請求額 | 月額10万円以内 |

## 8. 判断の基準

本導入・規模縮小・中止は、次の基準で判断する。

- **本導入へ進む**:作成時間の削減が費用に見合い、情報管理上の問題がない場合
- **規模を縮小して続ける**:効果は出ているが、利用率が低い場合(ライセンス数を減らすなど)
- **中止する**:削減効果が費用に見合わない場合、または情報管理上の重大な問題が起きた場合(この場合は期間の途中でも利用を止める)

## 付録A 背景と試行の結果

- 営業部では、顧客打ち合わせが週に平均8件(月に約35件)ある。
- 担当者は打ち合わせ後、手書きメモをもとに議事録を作成している。
- 部全体での平均作成時間はまだ測っていない。試験導入の開始前に測定する(付録G)。

先月、営業2課の担当者1名が無料版を1件の打ち合わせで試したところ、議事録の作成時間が普段の60分から30分に減った。ただし、この結果は1名・1件だけのものであり、参考値にとどまる。部全体で同じ効果が出るかどうかは、この試験導入で確かめる。

## 付録C 金額にしにくい効果(試験期間中に確認)

次の効果も見込まれるが、まだ確かめられていないため、試験期間中に利用者アンケートで確認する。

- 発言が記録に残るため、聞き漏らしや顧客との認識違いを後から確認できる
- 議事録が早くできあがり、顧客へのフォローや社内共有を早く始められる
- 担当者が交代するとき、過去の打ち合わせ内容を引き継ぎやすい

## 付録F リスクと対策

| リスク | 対策 |
| --- | --- |
| 録音について顧客の同意を得ないまま録音してしまう | 録音の前に、必ず顧客の同意を得る。同意を求める手順と文面を統一し、同意を得たことを記録に残す。同意が得られない打ち合わせでは録音せず、従来どおり手書きで議事録を作る |
| 顧客の同意が得られず、ツールを使える打ち合わせが少ない | 同意を得られた割合を毎月集計する。利用が少ない場合は、中間評価で人数の縮小を検討する |
| クラウドに保存した顧客情報が漏れる | 契約の前に、情報管理担当者がデータの保存場所、AIの学習に使われるかどうか、保存期間と削除の方法、アクセス権の設定を確認する。社内規程に合っているかどうかを情報システム部門と確認し、問題があれば導入しない |
| 文字起こしや要約に誤りがある | ツールの出力をそのまま議事録にせず、担当者が必ず確認・修正してから確定する |
| 期待した効果が出ない | 3か月目の中間評価で効果を確かめ、見合わない場合は規模縮小か中止を判断する |

## 付録G 測定の進め方

1. **開始前(2週間)**:現在の議事録作成時間を、担当者ごとに打ち合わせ1件単位で記録し、比較の基準とする。
2. **試験期間中**:打ち合わせごとに、議事録の作成時間と、録音の同意を得られたかどうかを記録シートに記入する。
3. **3か月目末**:中間評価を行い、結果を経営会議に報告する。
4. **6か月目末**:最終評価を行い、本導入・規模縮小・中止の判断案を経営会議に提出する。
