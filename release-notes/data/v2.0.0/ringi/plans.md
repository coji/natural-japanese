# 構成案:ミナトノート試験導入の稟議書

行番号は doc.md、L と S の番号は report-logic.md と report-somosomo.md の指摘を指す。どの案も、案の材料は doc.md にある事実と頼む中身だけで作っている。

選んだのは案2。案1は頼む中身そのものが変わるので、書き手にしか選べない。

## 案1 頼む中身を小さくする案(確かめてから、前半の3か月だけを頼む)

**主張**:確かめられることを先に確かめ、そのうえで中間評価までの3か月だけを頼む。4〜6か月目は、中間評価の結果を見て改めて頼む。

**縮めた決裁事項**

1. 「ミナトノート」を営業部の営業担当12名で3か月間試験導入すること
2. 費用の上限を月額10万円、3か月合計30万円とすること

**経営会議に出す前に置くこと**:時間単価(行62)、税区分(行82)、データの扱いと社内規程の確認(行101)、契約期間と中途解約の条件(行104)、現在の作成時間の測定(行110)。

**骨組み**

1. 申請内容
2. 確かめた結果
3. 背景と課題
4. 前半3か月で確かめること
5. 費用
6. 中間評価のあとの申請
7. 決裁をお願いする事項

**答える問い**:S1、S2、S3、S6、L3、L10、L12

**元の決裁事項が倒れる問い**

- S1(行20、行21):週8件が12名の合計で、60分が全体の平均に近いなら、議事録にかかる時間は全員で月約35時間が上限になり、行143 を頼む理由が立たない
- S2(行54、行101、行104):時間単価が約4,600円を下回れば参考値どおりでも行54 が成り立たない。社内規程に合わなければ行101 のとおり導入しない。6か月で解約できなければ行144 の上限の意味が変わる
- S3(行99、行100、行120):利用率が半分なら行59 の約4,600円は約9,100円になり、12名で試す前提が立たなくなる

**この案を選ぶなら先に見る問い**:S2 の時間単価(行62)と、S1 の週8件の単位(行20)。

**弱点**:申請が2回に分かれ、経営会議の手間と開始までの時間が増える。元の決裁事項から期間と総額が変わる。

## 案2 試験の稟議として組み直す案(選んだ案)

**主張**:部全体で効果が出るかは分かっていないので、作成時間、利用率、情報管理の3点を6か月で確かめ、その結果で本導入・規模縮小・中止を判断する。上限は月額10万円、6か月合計60万円とする。

**骨組み**

1. 申請内容
2. 背景と課題
3. 試験で確かめること
4. 費用
5. 費用対効果の目安
6. 判断の基準
7. 決裁をお願いする事項
8. 付録(測定と指標、計算、リスクと対策、体制とスケジュール、ツール、金額にしにくい効果)

**答える問い**:L1(試算が全件利用の値だと本文で明示)、L8、L14、L16、L17、L18、細かいものの丸め。L4 と L9 は食い違いを本文に見せる。S7 と L21 は、確かめる3点と判断の基準を同じ軸でそろえることで、未決の場所を見えるようにする。

**弱点**:時間単価と利用率の目安が空欄のままなので、S1〜S3 の「試す見込みが今あるか」には答えられない。枠を替えるだけでは閉じない。

## 案3 支出の上限を背骨にする案

**主張**:支出は上限60万円までで、契約前の確認、3か月目の中間評価、6か月目の最終評価の3か所で止められる。だから試せる。

**骨組み**

1. 申請内容
2. 支出の上限
3. 止める場面と基準
4. 期待する効果
5. リスクと対策
6. 決裁をお願いする事項
7. 付録

**答える問い**:L3、L4、L12、S7、反論2

**弱点**:6か月で解約できるかが未確認で(行104)、止める線も空欄の時間単価に頼る(行62)ので、背骨の「止められる」が立たない。

## 案2を選んだ理由

doc.md は、行12 で「時間を減らすため」と書き、行41 と行106〜129 では「効果があるかを確かめる試験」として書いている。案2はこのずれを、主結論と決裁事項を変えずに解消できる。確かめる3点は判断の基準(行127〜129)の軸そのものなので、新しい枠を持ち込まずに済む。案3は要の解約条件が未確認で、言い切ると根拠を超える。
