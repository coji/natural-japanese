# 稟議書:議事録作成支援ツール「ミナトノート」の試験導入について

| 項目 | 内容 |
| --- | --- |
| 起案日 | 2026年【 】月【 】日 |
| 起案者 | 営業部長 【氏名】 |
| 提出先 | 経営会議 |
| 件名 | 議事録作成支援ツール「ミナトノート」の試験導入(6か月) |

## 1. 申請内容

顧客打ち合わせの議事録作成にかかる時間を減らすため、音声の文字起こしと要約を行うクラウドツール「ミナトノート」を、営業部の営業担当12名で6か月間試験導入したい。ただし、今ある参考値(1件30分の削減)では費用に見合わず、データの扱いが社内規程に合うかもまだ確かめていない。

- **期間**:承認後の【2026年12月】から6か月
- **費用**:月額の上限は10万円、6か月の総額は60万円以内(見込みは475,200円)
- **進め方**:試験期間中に効果と情報管理の状況を測定する。3か月目に中間評価、6か月目に最終評価を行い、本導入・規模縮小・中止のいずれにするかを経営会議で改めて判断する

## 2. 背景と課題

議事録作成にかかる時間は、1件60分が全件に当てはまるとすると、部全体で月約35時間、1人あたり月約3時間である。

- 顧客打ち合わせは営業部全体で週に平均8件(月に約35件)ある。1人あたりの件数ではなく、営業支援システムの訪問記録の直近6か月から出した。
- 担当者は打ち合わせ後、手書きメモをもとに議事録を作成している。60分は、先月ツールを試した担当者の普段の時間である。
- 手書きメモと記憶をもとに作るため、議事録の正確さは担当者のメモの取り方に左右されると見ている。
- 部全体での平均作成時間はまだ測っていない。開始前に測定する予定で(付録E)、2週間あれば12名分を記録でき、承認の前に測ることもできる。

## 3. 期待効果

費用に見合うのは、打ち合わせの全件で使い、1件あたり約39分以上減った場合で、今ある参考値の30分では届かない。

先月、営業2課の担当者1名が無料版を1件の打ち合わせで試したところ、議事録の作成時間が普段の60分から30分に減った。ただし、この結果は1名・1件だけのものであり、参考値にとどまる。部全体で同じ効果が出るかどうかは、この試験導入で確かめる。

月額費用79,200円を月あたりの削減時間で割ると、**削減できる1時間あたりの費用**になる。営業担当者の時間単価がこの金額を上回れば、費用は回収できる計算になる。時間単価は、経理部が社内の試算に使う標準単価の1時間3,500円である。

| 1件あたりの削減時間 | 月あたりの削減時間 | 削減1時間あたりの費用 | 時間単価3,500円で |
| --- | --- | --- | --- |
| 15分 | 約8.7時間 | 約9,100円 | 回収できない |
| 30分(参考値) | 約17.3時間 | 約4,600円 | 回収できない |
| 45分 | 約26時間 | 約3,000円 | 回収できる |

表は月約35件のすべてでツールを使った場合の値である(計算は付録C)。同意が得られず使えない打ち合わせがあれば、その分だけ削減時間は減り、1時間あたりの費用は上がる。単価が税抜の場合は費用がどの行も1割高くなり、約39分は約43分になる。比べているのは利用料だけで、同意の取得や記録などで増える時間は入れていない。

## 4. 費用

申請する上限は月額10万円、6か月合計60万円である。見込みは1人月額6,600円の12名分で、月額79,200円、6か月合計475,200円になる。

- 単価6,600円が税込か税抜かは、契約前に確認する。税抜の場合でも月額は87,120円で、上限の範囲に収まる。
- 上限と見込みの差額は、税区分や契約条件の確認結果に備えるためのものである。上限を超える支出は行わない。
- 上記以外の費用(機材など)は想定していない。必要になった場合も上限の範囲で対応し、超える場合は改めて申請する。

## 5. リスクと対策

データの扱いが社内規程に合うかは、まだ確かめていない。情報システム部門には声をかけただけで、ミナトノートのデータの扱いの資料は取り寄せていない。問題があれば導入しない。

| リスク | 対策 |
| --- | --- |
| 録音について顧客の同意を得ないまま録音してしまう | 録音の前に、必ず顧客の同意を得る。同意を求める手順と文面を統一し、同意を得たことを記録に残す。同意が得られない打ち合わせでは録音せず、従来どおり手書きで議事録を作る |
| 顧客の同意が得られず、ツールを使える打ち合わせが少ない | 同意を得られた割合を毎月集計する。利用が少ない場合は、中間評価で人数の縮小を検討する |
| クラウドに保存した顧客情報が漏れる | 契約の前に、情報管理担当者がデータの保存場所、AIの学習に使われるかどうか、保存期間と削除の方法、アクセス権の設定を確認する。社内規程に合っているかどうかを情報システム部門と確認し、問題があれば導入しない |
| 文字起こしや要約に誤りがある | ツールの出力をそのまま議事録にせず、担当者が必ず確認・修正してから確定する |
| 期待した効果が出ない | 3か月目の中間評価で効果を確かめ、見合わない場合は規模縮小か中止を判断する。中間評価は経営会議への報告としており、そこで判断するかは確認中である |
| 費用が想定を超える | 月額の上限を設け、ライセンス数を12名分に固定する(途中で減らせるかは確認中)。解約は月単位ででき、最低契約期間もないので、6か月で解約できる(販売店に確認済み) |

## 6. 評価の方法

判断の中心は、作成時間の削減が費用に見合うかと、情報管理上の問題がないかの2つである。

### 6.1 評価の指標

| 指標 | 測定方法 | 目安(案) |
| --- | --- | --- |
| 1件あたりの議事録作成時間 | 記録シート(開始前と比較) | 開始前より平均30分短い。最低でも、3章の費用対効果が見合う水準で、全件で使う場合は約39分である。30分より長く、どちらを目安にするかは確認中である |
| ツールの利用率 | 記録シート(利用した件数 ÷ 打ち合わせ件数) | 【 】%以上 |
| 議事録の品質 | 利用者アンケート、上長による確認 | 開始前と同等以上 |
| 情報管理 | 情報管理担当者による点検 | 情報漏えい・同意なしの録音が0件 |
| 費用 | 請求額 | 月額10万円以内 |

### 6.2 判断の基準

- **本導入へ進む**:作成時間の削減が費用に見合い、情報管理上の問題がない場合
- **規模を縮小して続ける**:1件あたりの時間は減っているが、利用率が低い場合(ライセンス数を減らすなど)
- **中止する**:削減効果が費用に見合わない場合、または情報管理上の重大な問題が起きた場合(この場合は期間の途中でも利用を止める)

## 7. 決裁をお願いする事項

1. 「ミナトノート」を営業部の営業担当12名で6か月間試験導入すること
2. 費用の上限を月額10万円、6か月合計60万円とすること

## 付録B 金額にしにくい効果

次の効果も見込まれるが、まだ確かめられていないため、試験期間中に利用者アンケートで確認する。

- 録音した打ち合わせで、聞き漏らしや顧客との認識違いを後から確認できること
- 議事録が早くできあがり、顧客へのフォローや社内共有を早く始められること
- 担当者が交代するとき、過去の打ち合わせ内容を引き継ぎやすいこと

## 付録C 削減時間の計算

| 項目 | 値 |
| --- | --- |
| 月あたりの打ち合わせ件数 | 約35件(週8件 × 52週 ÷ 12か月 = 約34.7件) |
| 1件あたりの削減時間 | 30分(試行時の参考値) |
| 月あたりの削減時間 | 約17.3時間 |
| 6か月の削減時間 | 約104時間 |

費用に見合う水準は、月額費用を時間単価で割り、月の件数で割って求めた。税込の場合の月額79,200円では、月約22.6時間、1件あたり約39分になる。税抜の場合の月額87,120円では、月約24.9時間、1件あたり約43分になる。

## 付録E 測定の進め方

1. **開始前(2週間)**:現在の議事録作成時間を、担当者ごとに打ち合わせ1件単位で記録し、比較の基準とする。
2. **試験期間中**:打ち合わせごとに、議事録の作成時間と、録音の同意を得られたかどうかを記録シートに記入する。
3. **3か月目末**:中間評価を行い、結果を経営会議に報告する。
4. **6か月目末**:最終評価を行い、本導入・規模縮小・中止の判断案を経営会議に提出する。
