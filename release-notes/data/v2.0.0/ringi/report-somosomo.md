# somosomo の検査結果:doc.md

行番号は doc.md の行番号で数えている。L の番号は `report-logic.md` の指摘を指す。

## 文書の性格

経営会議に、議事録作成支援ツール「ミナトノート」の6か月の試験導入と費用の上限を決めてもらう稟議書。

## 主結論

顧客打ち合わせの議事録作成にかかる時間を減らすため、「ミナトノート」を営業部の営業担当12名で6か月間試験導入したい(行12)。決裁事項は、この試験導入と、費用の上限を月額10万円、6か月合計60万円とすること(行143、行144)。

書き手の意図とずれていそうな点が1つある。行12 は時間を減らすための導入と読めるが、本文の多く(行41、行106〜129)は、効果があるかどうかを確かめる試験として書かれている。

## 決裁者の論点

営業担当12名で6か月、上限60万円をかけて試すだけの見込みが今あり、この試験の結果で本導入・規模縮小・中止を決められるか。

指摘は全部で8件と細かいもの6件。先頭の3件は、答えしだいで決裁事項が成り立たなくなる問い。

## 決裁事項を倒しうる問い

**S1 行20、行21:この課題は、60万円の試験に値する大きさか(問いそのもの)**

問い:行20 の「週に平均8件」と行21 の「約60分」から見て、議事録作成は12名の仕事のどのくらいを占めると見ていますか。週8件が12名の合計なら、議事録にかかる時間は全員で月約35時間、1人あたり月約3時間です。1人あたりの件数なら月約416時間です(L11)。60分も1名の値で、部全体は測っていません(行23)。経営会議に頼む大きさの課題だと言える材料はありますか。

倒れる場所:行12、行20、行21、行47〜50、行54〜60

要る材料:週8件を集計した元の記録とその単位、12名分の議事録作成時間の記録、当社の時間単価

どう倒れるか:週8件が12名の合計で、60分が全体の平均に近いなら、作成時間がすべてなくなっても得られるのは月約35時間分で、月額79,200円と比べられる額はそれが上限になる。実際の削減はその一部なので、見合わなければ行143 を頼む理由が立たない。

**S2 行23、行62、行82、行101、行104、行110、行135:確かめてから頼めることを、頼んでから確かめる形になっていないか(問いそのもの)**

問い:時間単価は空欄で(行62)、開始前の作成時間(行110)、データの扱いと社内規程の照合(行101、行135)、税区分(行82)、解約の条件(行104)は、承認の後か契約の前に確かめる形になっています。このうち、経営会議に出す前に確かめられないものはどれで、その理由は何ですか。

倒れる場所:行54、行101、行143、行144

要る材料:時間単価の値、現在の作成時間の記録、提供元のデータの扱いが分かる資料と社内規程を突き合わせた記録、契約条件が分かる書面

どう倒れるか:社内規程に合わなければ、行101 のとおり導入しないので行143 の承認は使われない。6か月で解約できない条件なら、行144 の上限の意味が変わる。時間単価が約4,600円を下回れば、参考値どおりに減っても行54 の「回収できる」が成り立たない。いずれも承認の後に分かるので、経営会議は結論の出ていない案件の承認を求められている。

**S3 行99、行100、行120:顧客はどのくらい録音に同意する前提か(前提)**

問い:録音の前に必ず顧客の同意を得るとしているのに(行99)、月約17時間の試算はすべての打ち合わせでツールを使う前提で(行47〜50、L1)、利用率の目安は空欄です(行120)。顧客はどのくらい同意すると見ていますか。そう見る材料はありますか。

倒れる場所:行47〜50、行54〜60、行100、行127

要る材料:顧客に録音の可否を確かめた記録、または打ち合わせの相手ごとに録音できるかどうかの見込みの記録

どう倒れるか:利用率が半分なら、行59 の約4,600円は行58 と同じ約9,100円になる。1件あたりの効果が出ても費用に見合わず、12名で試す前提が立たなくなる。行100 の対策は中間評価で人数の縮小を検討することで、それまでの3か月分の費用はかかる。

## 1. 前提

**S4 行41、行119:30分という数字は、12名と月約35件に当てはまる前提でよいか**

問い:試した1件と試した担当者1名は、12名の打ち合わせをどのくらい代表していますか。打ち合わせの長さや相手で、作成時間と削減の幅は変わりませんか。文書は30分を参考値と断っていますが、行119 の目安にも使っています(L5)。無料版と申請するプランの違い(L15)も同じ前提に含まれます。

倒れる場所:行48〜50、行59、行119

要る材料:打ち合わせの種類ごとの作成時間の記録、複数の担当者が複数の打ち合わせで試した記録、無料版と有料プランの機能の比較

## 2. 問いそのもの

**S5 行54、行127、行129:経営会議が決めたいのは、議事録の時間が減るかどうかか**

問い:この文書は「議事録の作成時間が減るか」に答えています。経営会議が知りたいのは、減った時間で何が変わるかではありませんか。1人あたりの作業が減った分は何に使われ、どの数字に表れると考えていますか(L13)。

倒れる場所:行12、行54、行119、行127、行129

要る材料:減った時間の使い道についての部の方針、それが表れる数字の種類と現在の値

## 3. 他の選択肢

**S6 行12、行14、行143、行144:比べた案がない。なぜ12名で、なぜ6か月か**

問い:何もしない案、人数や期間を絞る案、別の手段と比べましたか。比べたなら、その記録は文書に出せますか。文書は人数の縮小を試験の途中の選択肢としていますが(行100、行128)、最初から12名とする理由も、6か月とする理由も本文にありません。3か月目に中止まで判断できるなら(行103)、後の3か月で何を確かめますか。

倒れる場所:行12、行14、行143、行144

要る材料:案ごとの費用と確かめられることを並べた比較の記録、12名と6か月に決めた理由

## 4. 覆る条件

**S7 行103、行127〜129:何が起きたらこの試験を止めるか、数字で言えるか**

問い:文書は中止の条件を言葉では書いていますが、「費用に見合う」の線は空欄の時間単価に頼り(行62)、利用率の目安も空欄で(行120)、「重大な問題」も定義がありません(行129)。3か月目と6か月目に、どの数字がいくつなら止めますか。その線は試験を始める前に決まりますか(L10、L19〜21)。

倒れる場所:行16、行103、行119、行120、行127〜129

要る材料:時間単価、利用率の下限を決めた記録、重大な問題の定義、それらを決める人の名前

## 5. 利害と実行

**S8 行90、行92、行111、行121:効果を測る人と、効果があると得をする人が同じになっていないか**

問い:作成時間の記録も(行92、行111)、品質のアンケートも(行121)、ツールを使う12名の自己申告です。起案者の営業部長は責任者として評価の報告も担います(行6、行90)。試験を進めたい側が測って報告する数字を、経営会議はどう信じればよいですか。

倒れる場所:行113、行119、行121、行127

要る材料:自己申告でない作成時間の記録、営業部の外の人による確認の記録

## 反論(仮の立場)

採用するかは書き手が決める。検査のための仮の立場で、書き手の主張ではない。

**反論1 行21、行22:** 時間がかかる原因は道具ではなく議事録の作り方にある、という読みが成り立つ。行21 は1名の作成時間で、行22 は測定のない推論なので、作り方を見ないままツールで解く課題だと決めている、と読める。

**反論2 行16、行90、行119、行127:** これは試験の形をとった本導入の手続きだ、という読みが成り立つ。止める線が空欄のまま、起案者が責任者として評価を報告し、費用に見合えば本導入に進むので、試験の結果に関わらず続ける方向に寄る、と読める。
