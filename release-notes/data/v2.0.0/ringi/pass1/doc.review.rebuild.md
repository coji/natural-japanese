# 稟議書:議事録作成支援ツール「ミナトノート」の試験導入について

| 項目 | 内容 |
| --- | --- |
| 起案日 | 2026年【 】月【 】日 |
| 起案者 | 営業部長 【氏名】 |
| 提出先 | 経営会議 |
| 件名 | 議事録作成支援ツール「ミナトノート」の6か月の試験導入 |

## 1. 申請内容

顧客打ち合わせの議事録作成にかかる時間を減らすため、音声の文字起こしと要約を行うクラウドツール「ミナトノート」を、営業部の営業担当12名で6か月間試験導入したい。この試験で確かめるのは、費用を回収できるだけの時間が部全体で減るかどうかである。

- **期間**:承認後の【2026年12月】から6か月
- **費用**:月額の上限は10万円、6か月の総額は60万円以内。見込みは475,200円
- **進め方**:試験期間中に効果と情報管理の状況を測定する。3か月目に中間評価、6か月目に最終評価を行い、本導入・規模縮小・中止のいずれにするかを経営会議で改めて判断する

## 2. 費用を回収できる線

費用の回収には1件あたり約39分の削減が要り、参考値の1件30分では回収できない。

月額費用79,200円を月あたりの削減時間で割ると、**削減できる1時間あたりの費用**になる。営業担当者の時間単価がこの金額を上回れば、費用は回収できる。時間単価は、経理部が社内の試算に使う標準単価の1時間3,500円である。

| 1件あたりの削減時間 | 月あたりの削減時間 | 削減1時間あたりの費用 | 時間単価3,500円で回収できるか |
| --- | --- | --- | --- |
| 15分 | 約9時間 | 約9,100円 | できない |
| 30分(参考値) | 約17時間 | 約4,600円 | できない |
| 45分 | 約26時間 | 約3,000円 | できる |

単価6,600円が税抜の場合は月額87,120円になり、回収には1件あたり約43分の削減が要る。

## 3. いま分かっていること

件数は訪問記録から分かっており、削減時間の手がかりは1名・1件の参考値である。

- 営業支援システムの直近6か月の訪問記録では、顧客打ち合わせは営業部全体で週に平均8件、月に約35件ある。12名で割ると1人あたり月に約3件で、1件約60分なら作成時間は1人あたり月に約3時間になる。
- 先月、営業2課の担当者1名が無料版を1件の打ち合わせで試したところ、議事録の作成時間が普段の約60分から30分に減った。ただし、この結果は1名・1件だけのものであり、参考値にとどまる。部全体で同じ効果が出るかどうかは、この試験導入で確かめる。
- 参考値どおり1件あたり30分減り、月約35件のすべてでツールを使えた場合、削減時間は月約17時間、6か月で約104時間になる。
- 部全体での平均作成時間は、試験導入の開始前に測定する(付録D)。

## 4. 評価の指標

評価の指標は次の5つである。

| 指標 | 測定方法 | 目安の案 |
| --- | --- | --- |
| 1件あたりの議事録作成時間 | 記録シートで開始前と比較 | 開始前より平均30分短い。最低でも、2章の費用対効果が見合う水準 |
| ツールの利用率 | 記録シートで、利用した件数 ÷ 打ち合わせ件数 | 【 】%以上 |
| 議事録の品質 | 利用者アンケート、上長による確認 | 開始前と同等以上 |
| 情報管理 | 情報管理担当者による点検 | 情報漏えい・同意なしの録音が0件 |
| 費用 | 請求額 | 月額10万円以内 |

## 5. 判断の基準

6か月目末に、次の基準で判断案を経営会議に提出する。

- **本導入へ進む**:作成時間の削減が費用に見合い、利用率と品質が4章の目安に届き、情報管理上の問題がない場合
- **規模を縮小して続ける**:効果は出ているが、利用率が低い場合。ライセンス数を減らすなどで続ける
- **中止する**:削減効果が費用に見合わない場合、または情報管理上の重大な問題が起きた場合。重大な問題が起きた場合は、期間の途中でも利用を止める

## 6. 費用

6か月の見込みは475,200円で、申請する上限は月額10万円、6か月合計60万円である。

| 項目 | 金額 |
| --- | --- |
| 単価 | 6,600円/人・月 |
| 人数 | 12名 |
| 月額の見込み | 79,200円 |
| 6か月合計の見込み | 475,200円 |
| **申請する上限** | **月額10万円、6か月合計60万円** |

- 単価6,600円が税込か税抜かは、契約前に確認する。税抜の場合でも月額は87,120円で、上限の範囲に収まる。
- 上限と見込みの差額は、税区分や契約条件の確認結果に備えるためのものである。上限を超える支出は行わない。
- 機材などの費用は想定していない。必要になった場合も上限の範囲で対応し、超える場合は改めて申請する。

## 7. リスクと対策

リスクは次の6つで、それぞれの対策を示す。

| リスク | 対策 |
| --- | --- |
| 録音について顧客の同意を得ないまま録音してしまう | 録音の前に、必ず顧客の同意を得る。同意を求める手順と文面を統一し、同意を得たことを記録に残す。同意が得られない打ち合わせでは録音せず、従来どおり手書きで議事録を作る |
| 顧客の同意が得られず、ツールを使える打ち合わせが少ない | 同意を得られた割合を毎月集計する。利用が少ない場合は、中間評価で人数の縮小を検討する |
| クラウドに保存した顧客情報が漏れる | 契約の前に、情報管理担当者がデータの保存場所、AIの学習に使われるかどうか、保存期間と削除の方法、アクセス権の設定を確認する。社内規程に合っているかどうかを情報システム部門と確認し、問題があれば導入しない |
| 文字起こしや要約に誤りがある | ツールの出力をそのまま議事録にせず、担当者が必ず確認・修正してから確定する |
| 期待した効果が出ない | 3か月目の中間評価で効果を確かめて経営会議に報告し、見合わない場合は規模縮小か中止を経営会議で判断する |
| 費用が想定を超える | 月額の上限を設け、ライセンス数を12名分に固定する。月単位で解約でき、最低契約期間はないと販売店に確認した |

## 8. 決裁をお願いする事項

1. 「ミナトノート」を営業部の営業担当12名で6か月間試験導入すること
2. 費用の上限を月額10万円、6か月合計60万円とすること

## 付録A ツールの概要

| 項目 | 内容 |
| --- | --- |
| ツール名 | ミナトノート |
| 提供形態 | クラウドサービス |
| 主な機能 | 打ち合わせ音声の文字起こし、要約 |
| プラン | 1人あたり月額6,600円 |
| 利用者 | 営業部の営業担当12名 |
| 社外の利用例 | 従業員300名の同業A社が全社で導入している |

A社での効果や運用上の注意点については、可能であれば開始前に聞き取りを行い、運用ルールづくりに活かす。

## 付録B 背景の補足

- 議事録の作成には、先月ツールを試した担当者の場合、普段は1件あたり約60分かかっている。担当者は打ち合わせ後、手書きメモをもとに議事録を作成している。
- 手書きメモと記憶をもとに作るため、議事録の正確さは担当者のメモの取り方に左右されると考えられる。

金額にしにくい効果として、次のものも見込まれるが、まだ確かめられていないため、試験期間中に利用者アンケートで確認する。

- 発言が記録に残るため、聞き漏らしや顧客との認識違いを後から確認できる
- 議事録が早くできあがり、顧客へのフォローや社内共有を早く始められる
- 担当者が交代するとき、過去の打ち合わせ内容を引き継ぎやすい

## 付録C 実施体制

| 役割 | 担当 | 主な業務 |
| --- | --- | --- |
| 責任者 | 営業部長 【氏名】 | 全体の管理、中間評価・最終評価の報告 |
| 情報管理担当者 | 【氏名】1名 | 契約条件とデータの扱いの確認、利用ルールの整備と周知、録音データの管理状況の点検 |
| 利用者 | 営業担当12名 | ツールの利用、作成時間と録音同意の記録、アンケートへの回答 |
| 相談先 | 情報システム部門、法務担当 | セキュリティと契約内容の確認 |

## 付録D 測定の進め方

1. **開始前の2週間**:現在の議事録作成時間を、担当者ごとに打ち合わせ1件単位で記録し、比較の基準とする。
2. **試験期間中**:打ち合わせごとに、議事録の作成時間と、録音の同意を得られたかどうかを記録シートに記入する。
3. **3か月目末**:中間評価を行い、結果を経営会議に報告する。
4. **6か月目末**:最終評価を行い、本導入・規模縮小・中止の判断案を経営会議に提出する。
