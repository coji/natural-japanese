# somosomo の検査報告:doc.md

- **文書の性格**:経営会議に、議事録作成支援ツール「ミナトノート」の6か月の試験導入と費用の上限を決めてもらう稟議書。
- **主結論**:議事録作成の時間を減らすため、営業担当12名で6か月間試験導入したい(12行)。
- **決裁者の論点**:60万円を上限に12名で6か月試す値打ちが議事録作成の課題にあり、顧客の音声をこのクラウドに預けてよいと言えるか。

## 決裁事項を倒しうる問い

### 1. 減らした時間は月額に見合う金額になるか

- **問い**:営業担当者の時間単価はいくらか。54行は単価が1時間あたりの費用を上回れば回収できると書くが、62行の単価は空欄のままだ。減った時間は残業の減少になるのか、別の仕事に回るのか。
- **倒れる場所**:54、62、119、127、129行、および決裁事項(143〜144行)。
- **どう倒れるか**:時間単価が参考値の約4,600円を下回れば、参考値どおりの効果が出ても費用を回収できない。
- **要る材料**:営業担当者の時間単価、減った時間の使い道の見込み。

### 2. そもそも課題はどのくらいの大きさか

- **問い**:月約35件が12名全員の合計なら、作成時間は1件60分としても月約35時間で、1人あたり月約3時間になる。この大きさは、経営会議で試験導入を諮るだけの課題か。部全体の平均を23行が未測定としているのに、110行の2週間の記録を承認のあとに回す理由はあるか。
- **倒れる場所**:12、20、23、47〜50、58〜60行、および決裁事項(143行)。
- **どう倒れるか**:件数や平均時間が小さければ、4.1と4.2の数字が同じ比率で小さくなり、課題の大きさが頼む中身に見合わなくなる。
- **要る材料**:12名ごとの打ち合わせ件数の記録、部全体の議事録作成時間の測定結果。

### 3. 「問題があれば導入しない」ことを、なぜ承認のあとに確かめるのか

- **問い**:101行は社内規程に問題があれば導入しないと書き、104行は解約条件を、82行は税区分を契約前に確認すると書く。135行はこれらを承認後に置いている。承認の前に確かめられない理由はあるか。確かめずに頼むと、決裁者は導入できるか分からないものを承認することにならないか。
- **倒れる場所**:82、83、101、104、135行、および決裁事項(143〜144行)。
- **どう倒れるか**:データの扱いが社内規程に合わなければ試験導入ができず、6か月で解約できなければ60万円の上限と83行の言い切りが成り立たない。
- **要る材料**:提供元の契約条件と利用規約、データの扱いの資料、社内規程と照らした情報システム部門・法務担当の見解。

## 前提

### 4. 顧客は録音にどのくらい同意するか

- **問い**:99行は同意が得られない打ち合わせでは録音しないと書くが、同意の見込みは書かれていない。半分しか同意が得られなければ、月の削減時間は4.2の表の15分の行と同じ水準になる。見込みはどのくらいか。
- **倒れる場所**:47〜50、58〜60、100行。
- **要る材料**:顧客に録音の可否を尋ねた記録、または顧客側の録音に関する取り決めの有無。

### 5. 先月の試行は、この稟議の情報管理のルールに合っていたか

- **問い**:41行の試行は無料版で打ち合わせ1件を処理している。そのとき顧客の同意を得たか。無料版のデータの扱いを確かめたか。7章で「必ず」と書いたことを、先月の試行が満たしていなければ、決裁者はどう受け取るか。
- **倒れる場所**:41、99、101行。
- **要る材料**:試行時の同意の有無、無料版の利用規約。

## 問いそのもの

### 6. 解くのは時間か、議事録の正確さか

- **問い**:12行の目的は時間の削減だが、22行は正確さも課題に挙げ、68行は認識違いの確認を効果に挙げている。決裁者が知りたいのはどちらか。正確さが本題なら、時間を主な指標にした評価で判断できるか。
- **倒れる場所**:12、22、68、119、121行。
- **要る材料**:議事録の誤りや認識違いが問題になった事例の記録。

## 他の選択肢

### 7. 「比べた案」が本文にない

- **問い**:12名全員で6か月という形を、何もしない案、人数や範囲を変える案、文書が試している無料版を続ける案と比べたか。比べたなら、何を軸に比べ、選んだ理由は本文のどこに書けるか。
- **倒れる場所**:12、41、143行。
- **要る材料**:案ごとの費用と効果を比べた記録、無料版の制約が分かる資料。

## 覆る条件

### 8. 利用率がどこまで下がったら縮小するのか

- **問い**:120行の利用率の目安は空欄で、100行の「利用が少ない」も128行の「利用率が低い」も線がない。どの値を下回ったら縮小や中止に進むのか。
- **倒れる場所**:100、120、128行。
- **要る材料**:費用に見合う利用率の計算、同意率の見込み。

## 利害と実行

### 9. 評価する人と、頼む人が同じでよいか

- **問い**:起案者の営業部長(6行)が責任者として評価を報告し(90行)、判断案も出す(113行)。作成時間も、効果を受ける利用者本人の記入に頼っている(92、111行)。自己申告の数字で、決裁者は判断できるか。
- **倒れる場所**:92、111、113、119行。
- **要る材料**:起案者以外の確認の有無、自己申告でない記録の有無。

## 細かいもの 2件

- 54行の費用対効果は月額だけを見ている。記録シートの記入、説明会、情報管理担当者の点検にかかる時間は入れなくてよいか(92、91、135行)。
- 127行で本導入に進むとき、費用はどの規模になるか。決裁者が試験の先を読むための材料が文書にない。

## 反論(仮の立場)

- 12名で月約35件なら1人あたり月約3件で、全員分のライセンスを配る理由は薄い、という読みが成り立つ(20、32、47行)。
- 102行のとおり担当者が出力を確認・修正するなら、1件の試行で見えた30分の短縮は日常の運用では縮む、と読める(41、102行)。
