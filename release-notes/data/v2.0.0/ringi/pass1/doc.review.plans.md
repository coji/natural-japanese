# doc.review.md の構成案

問いの番号は、L が `report-logic.md`、S が `report-somosomo.md` の番号です。

## 案1:頼む中身を小さくする案(書き手が選ぶ)

- **主張**:規程の確認と2週間の測定を先に済ませ、中間評価までの3か月に縮めて頼む
- **縮めた決裁事項**
  - 「ミナトノート」を営業部の営業担当12名で3か月間試験導入すること
  - 費用の上限を月額10万円、3か月合計30万円とすること
- **骨組み**:申請内容 / 先に確かめたこと / 費用対効果の目安 / 費用 / リスクと対策 / 評価の指標 / 決裁をお願いする事項
- **答える問い**:S1、S2、S3、L6、L8
- **元の決裁事項が倒れる条件**:S3 の答えが「社内規程に合わない」なら、72行の文のとおり導入できない。S2 の測定で平均が約39分を下回れば、38行の時間単価の計算で費用を回収できず、3か月でも頼む理由が立たない
- **この案を選ぶなら先に見る答え**:S3 の規程の確認と、S2 の2週間の測定
- **弱点**:続けるには中間評価のあとにもう一度頼むことになる

## 案2:回収の線を確かめる試験の稟議(本文にした案)

- **主張**:「ツールを導入する稟議」ではなく、「1件あたり約39分減るかを、上限60万円で確かめる6か月の試験の稟議」として頼む
- **骨組み**:申請内容 / 費用を回収できる線 / いま分かっていること / 評価の指標 / 判断の基準 / 費用 / リスクと対策 / 決裁をお願いする事項
- **答える問い**:S1、S2、L6、L8
- **弱点**:線を前面に出すので、目安の「平均30分短い」と約39分のずれが目立つ。宿題の3が終わるまでは出せない

## 案3:止められることから書く稟議

- **主張**:6か月の試験は月単位で解約でき、上限を超えず、問題があれば導入しないので、止める条件の中で試せる
- **骨組み**:申請内容 / 止める条件 / リスクと対策 / 費用 / 費用対効果の目安 / 評価の指標 / 決裁をお願いする事項
- **答える問い**:S3、L1、L15
- **弱点**:データの扱いの確認が済んでいないので、「問題があれば導入しない」が背骨のままでは決裁者の問い S3 に答えていない

## 選んだ案

案2を選んだ。頼む中身を保つ案のうち、書き手の答えで分かった最大の点である「参考値の30分では費用を回収できない」を正面から扱えるのは案2だからだ。案1は頼む中身が変わるので、書き手が選ぶ。
