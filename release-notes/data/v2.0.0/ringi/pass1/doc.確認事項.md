# doc.review.md の確認事項

提出前に書き手が読むファイルです。直した文書には載せていません。

## 出す前にやること

1. データの扱いの資料を販売店から取り寄せ、データの保存場所、AIの学習に使われるかどうか、保存期間と削除の方法、アクセス権の設定を見て、社内規程に合っているかを情報システム部門と突き合わせる → 5章の「クラウドに保存した顧客情報が漏れる」の対策を、確認した結果の文に書き換える。規程に合わなければ、5章の文のとおり導入しないので、この稟議は出さない
2. 営業担当12名の議事録作成時間を2週間、打ち合わせ1件単位で記録シートに記録する → 2章の「約60分」と「部全体での平均作成時間は、試験導入の開始前に測定する」を実測の平均の文に書き換え、付録Eと付録Fの「開始前の測定」を外す。平均が約39分を下回るなら、作成時間がなくなっても費用を回収できないので、頼む中身を見直す
3. 単価6,600円が税込か税抜かと、途中で人数を減らせるかを販売店に聞く → 4章の「契約前に確認する」の文を確認した結果に書き換え、3.2の約39分か約43分のどちらかに絞り、6.1の「開始前より平均30分短い」をその線に合わせて決める。回収の線は30分より上にあるので、いまの目安のままでは目安を満たしても費用を回収できない。人数を減らせないなら、5章と6.2の「人数の縮小」「ライセンス数を減らす」の文を書き直す

## 頼む中身を小さくする案

上の1と2を先に済ませ、頼むのは中間評価までの3か月、上限は月額10万円、3か月合計30万円にする。選ぶのは書き手で、直した文書は元の頼む中身のままです。案の詳細は `doc.review.plans.md` の案1にあります。

## 先に答える問い

1. 顧客は録音にどのくらい同意するか。同意が得られない打ち合わせでは使えないので、回収に要る1件あたりの削減はさらに大きくなる。試験を始めないと分からないので、本文は「月約35件のすべてでツールを使えた場合」という仮定の形にしてある
2. 先月の無料版の試行で、顧客の同意を得たか。無料版のデータの扱いを確かめたか。5章で「必ず」と書いたことを試行が満たしていなければ、決裁者はどう受け取るか
3. 減った時間は残業の減少になるのか、別の仕事に回るのか。時間単価3,500円で金額に換算する前提は、ここで決まる

## そのほか

- 無料版を1件で試した結果を、月額6,600円のプランの見込みに使っている。無料版とプランで効果が同じと言える材料はあるか
- 試行の30分には、担当者が出力を確認・修正する時間が含まれているか。日常の運用では短縮が縮むという読みも成り立つ
- 「普段の約60分」「30分に減った」は記録からの値か、本人の感覚か
- 開始前の2週間で記録できるのは全体で約16件で、12名に割ると1人1件強になる。担当者ごとの比較の基準として足りるか
- 週8件は訪問記録からの件数である。訪問を伴わない打ち合わせは入っているか
- 測定を承認前に回すと、【2026年12月】の開始に間に合うか
- 議事録の品質の目安は「開始前と同等以上」だが、開始前の品質は何で測るのか
- 利用率の目安の空欄をどの値にするか。5章の「利用が少ない場合」と6.2の「利用率が低い場合」も、この線で読むことになる
- 月10万円という上限はどこから決めたか。税抜でも月12,880円の余りがあり、4章はこれを税区分や契約条件への備えとし、機材などの費用もこの範囲で対応すると書いている
- 「ライセンス数を12名分に固定する」は上限としての意味か。人数の縮小を書いている5章、6.2とどう読むか
- 情報管理上の問題があるが重大ではない場合、たとえば同意なしの録音が1件あった場合は、どの判断になるのか
- 品質が目安を下回ったときは、3つの判断のどれになるのか
- 付録Bの効果を利用者アンケートで確認した結果は、判断のどこで使うのか
- 解くのは時間の削減か、議事録の正確さか。2章は正確さも課題に挙げているが、評価は時間が中心である
- 「議事録の正確さは担当者のメモの取り方に左右される」は、ばらつきを見た事実か。本文は「考えられる」と推論の形にした
- 比べた案が本文にない。何もしない案、人数や範囲を変える案、無料版を続ける案と比べたか。比べたなら、選んだ理由を書けるか
- 1人あたり月約3件で、全員分のライセンスを配る理由は書けるか
- 起案者の営業部長が評価を報告し、判断案も出す。作成時間も利用者本人の記入に頼っている。自己申告の数字で決裁者は判断できるか
- 記録シートの記入、説明会、情報管理担当者の点検にかかる時間は、費用対効果に入れなくてよいか
- 本導入に進むとき、費用はどの規模になるか
- A社の例は効果も注意点も未確認なので、付録Aに回した。本編に戻すなら、どの主張を支えるために置くか
- 未記入の欄が残っている。起案日、起案者の氏名、開始月、情報管理担当者の氏名、利用率の目安
