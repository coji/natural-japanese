# 構成案:doc.review.md の組み直し

問いの番号は `report-logic.md` の L1〜L17(番号どおり)と `report-somosomo.md` の S1〜S3 を指す。

## 案1:頼む中身を小さくする案

- 主張:月単位で解約できるので、中間評価までの3か月分だけを先に承認してもらい、続きは結果を見て改めて頼む
- 骨組み:1. 申請内容、2. 中間評価までに確かめること、3. 3か月の費用、4. 続きを頼む条件、5. 決裁をお願いする事項
- 縮めた決裁事項:「ミナトノート」を営業部の営業担当12名のうち内勤寄りの3名を除く9名で3か月間試験導入すること。費用の見込みは59,400円の3か月分で178,200円
- 答える問い:S1、S2。S1の答えの時間単価3,500円で、doc.md の行54、行59の「30分で回収」は倒れた。doc.review.md の行51のとおり、9名でも参考値の30分は月額に届かない。6か月分を先に頼む理由が残るかどうかがこの案の分かれ目になる
- 弱点:3か月目の承認をもう一度取る手間が増える。月額上限の値は元のまま使えるが、3か月の総額の上限は書き手が決める
- この案を選ぶなら先に見る問い:`doc.確認事項.md` の「先に答える問い」の3

## 案2:36分に届くかを確かめる試験として頼む(選んだ案)

- 主張:この試験は、1件あたり36分減るかどうかに答えるためのもので、届かなければ中止し、途中でも月単位で解約できる
- 骨組み:1. 申請内容、2. 確かめること、3. 現状、4. 費用と解約、5. 情報管理、6. 判断の基準、7. 決裁をお願いする事項
- 答える問い:L1、L5、L7、L8、L14、S1、S2、S3
- 弱点:参考値の30分が線に届いていないことが冒頭に近い節で読まれるので、効果の見込みより慎重さが前に出る

## 案3:確認済みの条件から入る

- 主張:顧客情報の扱いと解約の条件は確認済みで、失う額は上限50万円までに限られる
- 骨組み:1. 申請内容、2. 確認済みの条件、3. 費用、4. 効果の見込み、5. 判断の基準、6. 決裁をお願いする事項
- 答える問い:L3、S3
- 弱点:決裁者が最初に聞く「費用に見合うのか」への答えが後ろに回る

## 選んだ案と理由

確認せずに進める環境なので、頼む中身を保つ案から案2を選んだ。費用が見合うかを先に扱うと、S1 と S2 の答えで分かった数字が順に読める。また、書き手が答えの中で決めた36分の線が、文書の背骨にそのままなる。案1は書き手にしか選べないので、本文は書いていない。
