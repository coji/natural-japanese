# 確認事項:議事録作成支援ツール「ミナトノート」の試験導入

決裁事項は、答えのとおり「12名、上限60万円」から「9名、上限50万円(月額8万円)」に変えた。

頼む中身をさらに小さくする案:月単位で解約できるので、中間評価までの3か月分だけを先に頼み、続きは中間評価の結果を見て改めて頼む。選ぶのは書き手で、本文は9名・6か月のまま直した。

## 先に答える問い

1. 上限の値はこのままでよいか。月額上限8万円の6か月分は48万円で、総額の上限50万円に届かない。また、見込み356,400円との差は約14万円あり、元の文書の理由だった税区分と契約条件の確認は済んだので、本文からこの理由を外した。差額は何に備えるものか。
2. ツールの利用率の目安は何%か。7.1の空欄で、「規模を縮小して続ける」の線がこの値で決まる。
3. 無料版のまま件数を増やして試せるか。判断の線の36分は、いまの平均55分を約65%縮める値で、1名・1件の試行は半分の30分だった。なぜ30分でも試す価値があるかを、決裁者は最初に聞くはずだ。

## そのほか

- 平均55分は12名16件の値。対象の9名13件の平均はいくつか。比較の基準はどちらの値にするか
- 9名の打ち合わせ13件は、外す3名が3件という計算になる。担当者別の件数のうち少ない3名は0件、1件、1件の計2件で、この3名を外すなら14件になる。外す3名の件数は3件で合っているか
- 約43分は、単価が税抜だったときの線で、税込と分かったので本文には書いていない。別の意味で使っていたなら教えてほしい
- 顧客が録音に同意する割合の見込みはあるか。36分は月約28件のすべてで使えたときの線
- 減った時間は何に使うのか。残業が減るのか、別の仕事に回るのか。本文は時間単価で換算して費用と比べているだけで、金額が戻るとは書いていない
- 解くべき課題は作成の時間か、議事録の正確さか。正確さの問題が実際に起きた事例はあるか
- 無料版を続ける案、何もしない案、人数を変える案と比べた記録はあるか
- 中間評価で誰が何を決めるのか。本文は、規模縮小か中止を経営会議で判断する形にそろえた。違うなら教えてほしい
- 議事録の品質と費用は指標にあるが、判断の基準に出てこない。品質が下がったときや費用が上限に近づいたときは、どの判断になるのか。品質の開始前の値はあるか
- 月額上限8万円を超えるのは何が起きたときか。本文は、超える場合は改めて申請すると書いている
- A社の例は何を支えるために置いているか。聞き取りは開始前にやる作業か。付録Dの開始前の項目には入っていない
- 作成時間の記録は、ツールを使う本人の自己申告でよいか
- 責任者と起案者は同じ営業部長で、判断案も同じ人が出す。評価する人と申請する人が同じでよいか
- 情報管理担当者は誰か。付録Cで氏名が空欄。起案日と起案者の氏名も空欄のまま
- 契約内容を法務担当にも確認したか。答えにあるのは販売店と情報システム部門の確認だけ
