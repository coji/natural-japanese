# 稟議書:議事録作成支援ツール「ミナトノート」の試験導入について

| 項目 | 内容 |
| --- | --- |
| 起案日 | 2026年【 】月【 】日 |
| 起案者 | 営業部長 【氏名】 |
| 提出先 | 経営会議 |
| 件名 | 議事録作成支援ツール「ミナトノート」の試験導入(6か月) |

## 1. 申請内容

顧客打ち合わせの議事録作成にかかる時間を減らすため、音声の文字起こしと要約を行うクラウドツール「ミナトノート」を、営業部の営業担当12名のうち内勤寄りの3名を除く9名で、6か月間試験導入したい。

- **期間**:承認後の【2026年12月】から6か月
- **費用**:月額の上限は8万円、6か月の総額は50万円以内。見込みは月額59,400円、6か月で356,400円
- **進め方**:試験期間中に効果と情報管理の状況を測定する。3か月目に中間評価、6か月目に最終評価を行い、本導入・規模縮小・中止のいずれにするかを経営会議で改めて判断する

## 2. 背景と課題

議事録の作成に、営業部全体で月に約32時間かかっている。

- 営業部全体の顧客打ち合わせは週に平均8件、月に約35件である。営業支援システムの訪問記録の直近6か月から出した。
- 営業担当12名の作成時間を、2週間で打ち合わせ16件分記録した。1件あたりの平均は55分、最短25分、最長110分である。
- 担当者は打ち合わせ後、手書きメモをもとに議事録を作成している。手書きメモと記憶をもとに作るため、議事録の正確さは担当者のメモの取り方に左右されると見ている。
- 対象の9名の打ち合わせは、2週間で13件、月に約28件である。

## 3. 導入するツール

導入するのは、月単位で解約でき、人数も増減できるクラウドサービスである。

| 項目 | 内容 |
| --- | --- |
| ツール名 | ミナトノート(クラウドサービス) |
| 主な機能 | 打ち合わせ音声の文字起こし、要約 |
| プラン | 1人あたり月額6,600円(税込) |
| 利用者 | 営業部の営業担当9名 |
| 社外の利用例 | 同業のA社(従業員300名)が全社で導入している |

A社での効果や運用上の注意点については、可能であれば開始前に聞き取りを行い、運用ルールづくりに活かす。

## 4. 期待効果

### 4.1 議事録作成時間の削減

1件あたりの作成時間がどこまで減るかを、この試験導入で確かめる。先月、営業2課の担当者1名が無料版を1件の打ち合わせで試したところ、議事録の作成時間が普段の60分から30分に減った。ただし、この結果は1名・1件だけのものであり、参考値にとどまる。

### 4.2 費用対効果の目安

1件あたり約36分減れば費用に見合うので、本導入へ進む線を36分とする。月額59,400円を、経理部が社内の試算に使う標準単価の1時間3,500円で割ると月約17時間になり、月約28件で割ると1件あたり約36分になる。

参考値の30分では、月約14時間、金額にして49,000円で、月額に届かない。また、36分は月約28件のすべてでツールを使えたときの線で、同意が得られない打ち合わせがあれば、1件あたりに要る削減は大きくなる。

### 4.3 金額にしにくい効果

次の効果も見込まれるが、まだ確かめられていないため、試験期間中に利用者アンケートで確認する。

- 発言が記録に残るため、聞き漏らしや顧客との認識違いを後から確認できること
- 議事録が早くできあがり、顧客へのフォローや社内共有を早く始められること
- 担当者が交代するとき、過去の打ち合わせ内容を引き継ぎやすいこと

## 5. 費用

費用の見込みは月額59,400円、6か月で356,400円で、申請する上限の範囲に収まる。

| 項目 | 金額 |
| --- | --- |
| 単価(税込) | 6,600円/人・月 |
| 人数 | 9名 |
| 月額(見込み) | 59,400円 |
| 6か月合計(見込み) | 356,400円 |
| **申請する上限** | **月額8万円、6か月合計50万円** |

上限を超える支出は行わない。機材などの上記以外の費用は想定していない。必要になった場合も上限の範囲で対応し、超える場合は改めて申請する。

## 6. リスクと対策

顧客情報の保存と扱いは、社内規程に合っていると情報システム部門が確認した。リスクごとの対策は次のとおり。

| リスク | 対策 |
| --- | --- |
| 録音について顧客の同意を得ないまま録音してしまう | 録音の前に、必ず顧客の同意を得る。同意を求める手順と文面を統一し、同意を得たことを記録に残す。同意が得られない打ち合わせでは録音せず、従来どおり手書きで議事録を作る |
| 顧客の同意が得られず、ツールを使える打ち合わせが少ない | 同意を得られた割合を毎月集計する。利用が少ない場合は、中間評価で人数の縮小を検討する。ライセンスは月単位で減らせる |
| クラウドに保存した顧客情報が漏れる | 保存先は国内のデータセンターで、音声と文字起こしはAIの学習に使われない。録音と文字起こしは契約中は無期限で保存され、解約後は30日で削除される。社内規程は社外保存の期間に上限を置いていない。削除は依頼から30日以内で、アクセス権は管理者が設定できる |
| 文字起こしや要約に誤りがある | ツールの出力をそのまま議事録にせず、担当者が必ず確認・修正してから確定する |
| 期待した効果が出ない | 3か月目の中間評価で効果を確かめ、見合わない場合は規模縮小か中止を経営会議で判断する。月単位で解約でき、最低契約期間はないと販売店に確認した |
| 費用が想定を超える | 月額の上限を設け、ライセンス数は9名分より増やさない |

## 7. 評価の方法

作成時間が開始前より平均36分以上短くなり、情報管理上の問題がなければ、本導入へ進む。

### 7.1 評価の指標

| 指標 | 測定方法 | 目安(案) |
| --- | --- | --- |
| 1件あたりの議事録作成時間 | 記録シート(開始前と比較) | 開始前より平均36分短い |
| ツールの利用率 | 記録シート(利用した件数 ÷ 打ち合わせ件数) | 【 】%以上 |
| 議事録の品質 | 利用者アンケート、上長による確認 | 開始前と同等以上 |
| 情報管理 | 情報管理担当者による点検 | 情報漏えい・同意なしの録音が0件 |
| 費用 | 請求額 | 月額8万円以内 |

### 7.2 判断の基準

- **本導入へ進む**:作成時間が開始前より平均36分以上短くなり、情報管理上の問題がない場合
- **規模を縮小して続ける**:平均36分以上短くなったが、利用率が目安を下回る場合。ライセンス数を減らすなどして続ける
- **中止する**:短くなった時間が平均36分に届かず費用に見合わない場合、または情報管理上の重大な問題が起きた場合。情報管理上の重大な問題が起きたときは、期間の途中でも利用を止める

## 8. 決裁をお願いする事項

1. 「ミナトノート」を営業部の営業担当12名のうち内勤寄りの3名を除く9名で6か月間試験導入すること
2. 費用の上限を月額8万円、6か月合計50万円とすること

## 付録B 測定の進め方

1. **開始前**:記録した2週間分の議事録作成時間を、比較の基準とする。
2. **試験期間中**:打ち合わせごとに、議事録の作成時間と、録音の同意を得られたかどうかを記録シートに記入する。
3. **3か月目末**:中間評価を行い、結果を経営会議に報告する。
4. **6か月目末**:最終評価を行い、本導入・規模縮小・中止の判断案を経営会議に提出する。
