1. 問い:営業担当者の時間単価(人件費)はいくらですか。4.2の空欄の値です。単価が約4,600円を上回るかどうかが、参考値どおりの効果が出たときに費用を回収できるかの線になります。
   答え:経理部が社内の試算に使う標準単価は1時間3,500円です。約4,600円を下回っています。

2. 問い:2章の「週に平均8件(月に約35件)」は、ツールを使う営業担当12名全員の合計ですか。先月試した1名の「約60分」のほかに、部全体の議事録作成時間について分かっていることはありますか。
   答え:週8件は営業部全体の件数で、1人あたりではありません。営業支援システムの訪問記録の直近6か月から出しました。部全体の作成時間は、12名の2週間、打ち合わせ16件を記録しました。1件あたりの平均は55分、最短25分、最長110分です。週8件のペースと合っていて、部全体では月あたり約32時間です。

3. 問い:ミナトノートの契約条件について、いま分かっていることを教えてください。6か月で解約できるか、途中で人数を減らせるか、単価6,600円は税込か税抜か、録音データの保存場所とAIの学習に使われるかどうか、社内規程に合っているか、の5点です。
   答え:
   - 解約:月単位で解約できます。最低契約期間はありません。販売店に確認済みです。
   - 人数:ライセンスは月単位で増減できます。
   - 単価:6,600円は税込です。税抜は6,000円です。
   - 保存場所と学習:保存先は国内のデータセンターです。音声と文字起こしはAIの学習に使われません。
   - 社内規程:社内規程(顧客情報の社外保存の条件)に合っていると、情報システム部門が確認しました。

4. 問い:宿題:データの扱いの資料を販売店から取り寄せ、データの保存場所、AIの学習に使われるかどうか、保存期間と削除の方法、アクセス権の設定を見て、社内規程に合っているかを情報システム部門と突き合わせる → 5章の「クラウドに保存した顧客情報が漏れる」の対策を、確認した結果の文に書き換える。規程に合わなければ、5章の文のとおり導入しないので、この稟議は出さない。調べた結果を教えてください
   答え:販売店から資料を取り寄せ、情報システム部門と突き合わせました。結果は次のとおりで、社内規程に合っていると情報システム部門が確認しました。
   - 保存場所:国内のデータセンターです。
   - AIの学習:音声と文字起こしは学習に使われません。
   - 保存期間:録音と文字起こしは、契約中は無期限で保存され、解約後は30日で削除されます。社内規程は社外保存の期間に上限を置いていません。
   - 削除の方法:削除は依頼から30日以内です。
   - アクセス権:管理者が設定できます。

5. 問い:宿題:営業担当12名の議事録作成時間を2週間、打ち合わせ1件単位で記録シートに記録する → 2章の「約60分」と「部全体での平均作成時間は、試験導入の開始前に測定する」を実測の平均の文に書き換え、付録Eと付録Fの「開始前の測定」を外す。平均が約39分を下回るなら、作成時間がなくなっても費用を回収できないので、頼む中身を見直す。調べた結果を教えてください
   答え:12名の2週間、打ち合わせ16件を記録しました。1件あたりの平均は55分、最短25分、最長110分で、約39分を下回っていません。週8件のペースと合っていて、部全体では月あたり約32時間です。担当者別の件数は、2件以上が5名、1件が6名、0件が1名で、件数の少ない数名は内勤寄りの担当です。

6. 問い:宿題:単価6,600円が税込か税抜かと、途中で人数を減らせるかを販売店に聞く → 4章の「契約前に確認する」の文を確認した結果に書き換え、3.2の約39分か約43分のどちらかに絞り、6.1の「開始前より平均30分短い」をその線に合わせて決める。回収の線は30分より上にあるので、いまの目安のままでは目安を満たしても費用を回収できない。人数を減らせないなら、5章と6.2の「人数の縮小」「ライセンス数を減らす」の文を書き直す。調べた結果を教えてください
   答え:
   - 税区分:6,600円は税込で、税抜は6,000円です。月額は税込79,200円のままです。
   - 人数:ライセンスは月単位で増減できるので、途中で人数を減らせます。
   - 回収の線:費用に見合う約39分を本導入の線にし、参考値の30分は目安から外すと決めました。ただし、この39分は12名のときの線です。内勤寄りの3名を外して9名で始める案を検討し、申請は9名・上限50万円(月額の上限8万円)に縮めます。9名分の月額は税込59,400円で、時間単価3,500円で割ると月約17時間です。2週間の記録で9名の打ち合わせは13件、月に約28件なので、1件あたり約36分減れば回収できます。そのため、9名で申請する本導入の線は36分にします。
   - 約43分:約43分をどう扱うかは、分からないです。
