# doc.md の somosomo 検査

## 文書の性格

決めてもらう文書。経営会議が、議事録作成支援ツールの試験導入と費用の上限を決める稟議書。

## 主結論

「ミナトノート」を営業部の営業担当12名で6か月間試験導入したい(行12、行143、行144)。

## 決裁者の論点

議事録作成の時間を減らすために、顧客の打ち合わせを録音してクラウドに置くことと、最大60万円を使うことが、見合うと言えるか。

## 決裁事項を倒しうる問い

### S1. 時間単価はいくらか

- 問い:行62の時間単価が空欄のまま、行54「費用は回収できる」と書いている。単価は約4,600円(行59)を上回るのか
- 倒れる場所:行54、行59、行119、行127。下回れば、参考値どおりの効果が出ても費用は回収できない
- 要る材料:社内で試算に使う営業担当者の時間単価
- どう倒れるか:回収の線が30分より上に移り、試験の目安と費用の説明が同時に崩れる

### S2. 課題はどのくらいの大きさか

- 問い:行20「週に平均8件」は部全体の件数か、12名それぞれの件数か。部全体の作成時間は、行23のとおり「まだ測っていない」が、承認を取る前に測れるものではないか
- 倒れる場所:行12、行47〜50、行58〜60。作成時間が短ければ、回収に要る削減幅に届かない
- 要る材料:打ち合わせ件数の記録、担当者別の作成時間の記録
- どう倒れるか:課題が小さければ、試験の前提が成り立たない

### S3. 顧客情報を社外に置いてよいか

- 問い:行101は「問題があれば導入しない」と書くのに、確認を承認の後に置いている(行135)。承認を取る前に確かめられることではないか。行104の中途解約と人数の条件、行82の税区分も同じで、いずれも問い合わせれば分かることではないか
- 倒れる場所:行143、行101、行104、行82。社内規程に合わなければ決裁事項の1が成り立たない
- 要る材料:提供元のデータの扱いの資料、社内規程との照合結果、契約条件の書面
- どう倒れるか:承認のあとで「導入しない」となれば、この決裁そのものが空振りになる

## 前提

- 問い:行54は、減った時間が人件費の回収になると置いている。減った時間は何に使うのか。残業が減るのか、別の仕事に回るのか
  - 倒れる場所:行54、行127
  - 要る材料:営業担当者の残業の記録、減った時間の使い道についての部の方針
- 問い:行49は全件で使える前提の数字に見える。顧客が同意する割合はどのくらいと見ているか
  - 倒れる場所:行49、行50、行58〜60
  - 要る材料:顧客の種類別の打ち合わせの内訳、同意の取りやすさが分かる過去の記録

## 問いそのもの

  - 倒れる場所:行12、行22、行119、行121
  - 要る材料:議事録の不備が原因で起きた手戻りや認識違いの記録

- 問い:行90の責任者と行6の起案者はどちらも営業部長で、行113の判断案も同じ人が出す。評価する人と申請する人が同じでよいか

- 問い:行91の情報管理担当者は氏名が空欄。誰がやるのか。その人は文書を読んで自分がやると分かるか

## 反論(仮の立場)

- 行20と行21から、作成時間そのものは小さい課題だという読みが成り立つ。行20が部全体の件数なら、1人あたりは週に1件に満たず、そこに1人月額6,600円(行31)を払う理由が本文にない、と読める
- 行22から、問題は道具ではなく手書きメモの取り方にある、という読みが成り立つ。その場合、行41の時間短縮が出ても、課題は残ると読める
