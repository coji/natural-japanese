## 文書の性格

経営会議に、議事録作成支援ツール「ミナトノート」の6か月の試験導入と費用の上限を決めてもらう稟議書。

## 主結論

顧客打ち合わせの議事録作成にかかる時間を減らすため、「ミナトノート」を営業部の営業担当12名で6か月間試験導入したい(行12)。決裁事項は、この試験導入と、費用の上限を月額10万円、6か月合計60万円とすること(行143、行144)。

書き手の意図とずれていそうな点が1つある。行12 は「時間を減らすため」の導入と読めるが、本文の多く(行41、行106〜129)は、効果があるかどうかを確かめる試験として書かれている。

YAML には、本文にない言葉で補った前提が5件ある(週8件は12名合計の件数、全件でツールを使う、無料版の効果が有料プランでも出る、減った時間が費用の回収につながる、増える作業時間は計算に入れなくてよい)。

指摘は全部で 21 件と細かいもの 7 件。費用対効果の判断全体に関わるのは、L10(時間単価が空欄)、L11(週8件の母数)、L1(全件利用の試算)の3件。

## 指摘

### 1. 矛盾

**L1 行47〜50 と 行99、行100、行120:試算は全件でツールを使う前提になっている**
「月あたりの削減時間 約17時間」は、月約35件のすべてに30分を掛けた値。一方で、同意が得られない打ち合わせでは録音しないとし(行99)、ツールを使える打ち合わせが少ないことをリスクに挙げている(行100)。利用率の目安は空欄(行120)。
問い:「約17時間」は、同意が得られない打ち合わせがどのくらいあると見た数字ですか。4.2 の費用対効果は、利用率が下がったときも同じ読み方でよいですか。

**L2 行41 と 行99、行101:先月の試用は、この文書の条件を満たしていたか**
行41 は「無料版を1件の打ち合わせで試した」と書く。行99 は録音の前に必ず顧客の同意を得るとし、行101 は保存場所や AI の学習に使われるかどうかを「契約の前に」確認し、問題があれば導入しないとしている。
問い:試した1件は顧客との打ち合わせでしたか。そうなら、そのときの同意とデータの扱いはどうなっていましたか。

**L3 行143 と 行101、行135:承認に条件が付いているのかが読み取れない**
決裁事項は「試験導入すること」と言い切っている(行143)。しかしデータの扱いの確認は承認の後で(行135)、問題があれば導入しない(行101)。
問い:行143 の承認は「確認で問題がなければ導入する」という意味ですか。問題が見つかったとき、導入しないと決めるのは誰ですか。

**L4 行16、行112、行113、行137 と 行100、行103、行129、行138:中間評価は報告の場か、判断の場か**
行112 と行137 では、中間評価の結果を経営会議に「報告」し、判断案を出すのは6か月目末(行113)。一方、行103 は中間評価で「規模縮小か中止を判断する」とし、行100 は「人数の縮小を検討する」、行138 は「結果に応じて見直す」と書く。行129 は期間の途中でも利用を止めるとしている。
問い:3か月目に縮小や中止を決めるのは誰で、経営会議はその決定に関わりますか。行129 の途中停止は誰が決めますか。

**L5 行23、行41 と 行119:参考値にとどめた数字が目安になっている**
行41 は30分の削減を「1名・1件だけ」の参考値とし、行23 は部全体の平均をまだ測っていないとしている。それでも行119 の目安は「開始前より平均30分短い」。
問い:開始前の平均がまだ分からないのに、30分を目安にした理由は何ですか。測った結果、開始前の平均が60分より短かったとき、この目安はそのまま使いますか。

**L6 行22 と 行12、行121:課題に挙げた正確さが、目的にも目標にも出てこない**
行22 は議事録の正確さが担当者に左右されることを課題に挙げている。しかし行12 の目的は時間の削減だけで、行121 の品質の目安は「開始前と同等以上」にとどまる。
問い:正確さは、この試験で改善を確かめたい課題ですか、それとも下げないように見張る条件ですか。

**L7 行110 と 行121:品質の比較の基準を測る工程がない**
行121 の目安は「開始前と同等以上」だが、開始前に記録するのは作成時間だけで(行110、行135)、品質やアンケートは開始前の工程にない。
問い:「開始前の品質」は、何で測った値と比べますか。

**L8 行15、行54、行58〜60、行78、行79 と 行82:税区分が未確認なのに、費用対効果は1つの値で計算している**
行82 は、税抜なら月額が87,120円になるとしている。行54 の月額79,200円と、行58〜60 の1時間あたりの費用は、税込の場合の値だけが書かれている。税抜なら1時間あたりの費用は約1割高い(30分の場合で約5,000円)。
問い:行58〜60 と行15 の見込みは、税区分が分からない今、どの値として読めばよいですか。

**L9 行104 と 行100、行128:ライセンス数は固定か、減らせるか**
行104 はライセンス数を12名分に「固定する」とし、行100 と行128 は人数やライセンス数を減らすことを選択肢にしている。
問い:行104 の「固定」は増やさないという意味ですか。試験の途中で減らせるかどうかは、確かめられていますか。

### 2. 根拠のない主張

**L10 行54、行62 と 行119、行127、行129:時間単価が空欄で、費用に見合うかの線がない(前提条件のちがい)**
行54 は時間単価が削減1時間あたりの費用を上回れば回収できるとしているが、時間単価は空欄のまま(行62)。行119 の最低線も、行127 と行129 の「費用に見合う」も、この値に頼っている。
問い:経営会議は、時間単価が空欄のままで、何を根拠に試す価値があると判断しますか。いま、この試験は費用に見合う見込みがあると言えますか。

**L11 行20、行47 と 行12、行77:週8件は誰の件数か(前提条件のちがい)**

問い:週8件は12名合計の件数ですか、1人あたりの件数ですか。どの記録から出した平均ですか。

**L12 行15、行83 と 行104、行129:6か月で終われるかどうかが未確認のまま、総額を上限としている(前提条件のちがい)**
行83 は上限を超える支出は行わないと言い切るが、6か月で解約できるかどうかは契約前の確認事項になっている(行104)。行129 の途中停止も、支払いが止まるかどうかは書かれていない。
問い:6か月で解約できない条件だった場合、行144 の上限は守れますか。そのときはどうしますか。途中で止めたとき、残りの月の費用はどうなりますか。

**L13 行54:減った時間が、なぜ費用の回収になるのか(前提条件のちがい)**
行54 は時間単価と比べて「費用は回収できる」としているが、減った時間が何に変わるのかは本文にない。
問い:1人あたりの作業が減った分は、何に使われ、どの数字に表れると考えていますか。

**L14 行54、行84 と 行91、行92、行99、行102、行135:増える作業時間が計算に入っていない(前提条件のちがい)**
費用対効果の費用は利用料だけで、同意の取得と記録(行92、行99)、説明会(行135)、録音データの点検(行91)は入っていない。行102 の確認・修正の時間が行41 の30分に含まれるかどうかも書かれていない。

**L15 行41 と 行31:無料版の結果を、有料プランの参考値にしている(異質なものの同質化)**
参考値は無料版で出たもので、申請するのは1人月額6,600円のプラン。
問い:無料版と申請するプランで、作成時間に関わる機能に違いはありませんか。
