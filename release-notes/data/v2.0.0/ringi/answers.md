1. 問い:「週に平均8件」(doc.md 行20)は、営業担当12名の合計ですか、1人あたりですか。どの記録から出した平均ですか。12名の合計なら、議事録にかかる時間は全員で月約35時間、1人あたり月約3時間になり、削減できる時間の上限もそこで決まります。
   答え:営業部全体で週8件です。1人あたりではありません。営業支援システムの訪問記録の直近6か月から出しました。部全体の議事録の作成時間は測っていないので、月約35時間、1人あたり月約3時間という数字が合っているかは分かりません。承認の前に測ることはでき、2週間あれば12名分を記録できます。

2. 問い:当社の営業担当者の時間単価(行62、空欄)はいくらですか。また、ミナトノートのデータの扱いが社内規程に合うか(行101)と、6か月で解約できるか(行104)は、分かっていますか。分かっているものは値や結果を、経営会議に出す前に確かめられないものはその理由を教えてください。
   答え:時間単価は、経理部が社内の試算に使う標準単価の1時間3,500円です。社内規程に合うかは分かりません。突き合わせをまだしておらず、情報システム部門には声をかけただけで、ミナトノートのデータの扱いの資料は取り寄せていません。経営会議の前に確かめられるかどうかも分かりません。解約は、月単位でできて最低契約期間もないので、6か月で解約できます。販売店に確認済みです。

3. 問い:顧客のうち、どのくらいの割合が録音に同意すると見ていますか。そう見る材料(顧客に録音の可否を確かめた記録、打ち合わせの相手ごとの見込みなど)はありますか。月約17時間の試算は全件でツールを使う前提で(行47〜50)、利用率の目安は空欄です(行120)。
   答え:分かりません。まだ顧客に聞いたことがないので、録音の可否を確かめた記録はありません。打ち合わせの相手ごとの見込みも分かりません。利用率の目安も分かりません。
