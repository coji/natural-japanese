## 先に答える問い

1. 週に平均8件は、営業担当12名の合計か、1人あたりか。どの記録から出した平均か。12名の合計で、1件60分が全体の平均に近いなら、議事録にかかる時間は全員で月約35時間、1人あたり月約3時間で、作成時間がすべてなくなっても得られるのはそれが上限になる。1人あたりなら月約416時間で、削減は月約208時間、1時間あたりの費用は約380円になる。この課題は60万円の試験に値する大きさだと言える材料はあるか
2. 経営会議に出す前に確かめられないものはどれで、その理由は何か。時間単価、開始前の作成時間、データの扱いと社内規程の照合、税区分、解約の条件は、いまは承認の後か契約の前に確かめる形になっている。経営会議は、時間単価が空欄のままで何を根拠に試す価値があると判断するか
3. 顧客はどのくらい録音に同意すると見ているか。そう見る材料はあるか。月約17時間は全件でツールを使う前提の値で、利用率が半分なら削減1時間あたりの費用は約9,100円になる
