## 頼む中身を小さくする案

経営会議に頼むのを現状診断の3か月・900万円だけに縮め、SFA 導入・定着支援の6か月・1,800万円は診断の結果を見てから改めて頼む。分かっている失注は営業本部長の「2社」という発言だけで、理由も、入力が続く材料もないため。本文は頼む中身を保ったまま直しているので、この案を採るかは書き手が決める。

## 先に答える問い

1. 失注の大きさは、契約の前に確かめられないか(行12、33、50、121、192)。分かっているのは、営業本部長の「引き継ぎで2社失った」という発言だけです。その2社がいつの話か、件数と取引額、「失注」が取引の停止と減少のどちらを指すかは分かっていません。台帳を見ないままでは、失注の金額が2,700万円とライセンス費に届くかを言えません。経営会議の前に台帳を見られますか。過去の実績が残っていなければ、1か月目の算出と3か月目の判断は立ちません。本文では2社の発言をそのまま書き、失注の定義は御社と決めると書きました。
2. 担当替えの失注は、本当に情報の抜け落ちから起きているのか(行12、14、33、93)。2社の理由も、情報が届かなかった失注と関係が切れて起きた失注の混じり具合も、分かっていません。原因は記録の場所(個人の Excel)と記録の有無(記録に残っていない経緯や約束事)のどちらですか。書く場所が SFA に変われば、記録に残っていないことも書かれるようになりますか。本文では効果を「原因が情報の抜け落ちであれば」の仮定の形にしました。
3. 30名の毎日の入力が支援の終了後も続くと見込む材料はあるか(行71、73〜83、85)。材料、過去の支援での入力率の記録、4つの工夫を試した結果は、いずれも手元にありません。分かっているのは、営業担当3名のうち2名が賛成、1名が入力の手間を心配しているという話だけで、本文にはそのまま書きました。入力するのはベテランで得をするのは後任、新人、上長です。上長に訪問状況が見えることは本人の負担にならないか、数年で退職するベテランが入力を続ける理由は「お伝えしていきます」のほかにあるか、日報の置き換えがどこまでできるかは診断の前に分かるのかも、確かめたいところです。
