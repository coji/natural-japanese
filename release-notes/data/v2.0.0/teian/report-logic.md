## 1. 矛盾

**L1. 決める人と決める範囲が定まらない(行19、21、179、189、190)**
行189は経営会議の審議、行179は「継続判断などの重要事項」を営業本部長の判断としている。行190の「ご承認後、契約を締結」も、対象が9か月全体か3か月分かを書いていない。
- 経営会議が承認するのは2,700万円か、フェーズ1の900万円か。
- 1,800万円分の継続判断は、営業本部長が一人で決めてよいものとして書いているのか。
- 3か月目に進まないと判断したとき、支払いは900万円で終わるのか。

**L2. 失注の発生を言い切る箇所と、これから調べるとする箇所がある(行12、31 と 行33、121)**
行12は「そのため」で原因を断定し、行31の見出しは「異動・退職のたびに」と毎回のように書く。一方で行33は原因・件数・金額を現状診断で確認するとし、行121は失注件数の資料を持っていないと書く。
- 件数の資料がないのに「たびに」と書ける根拠は何か。
- 原因は分かっているのか、調べないと分からないのか。どちらの立場で書く文書か。

**L3. 失注の原因の説明が2通りある(行12、29 と 行33)**
行12と行29の原因は、記録が個人の Excel にあること(記録の場所)。行33で抜け落ちるとされるのは「記録に残っていない経緯や顧客との約束事」(記録の有無)で、しかも後任者は前任者の Excel を手がかりにしている。
- 失注の原因は記録の場所と記録の有無のどちらか。
- 記録に残っていないことが原因の場合、記録の場所を SFA に移すだけで届くのか。

**L4. 概算に必要な数字が足りない(行192 と 行119、121)**
行119の式は3項からなる。行192で教えてもらうのは異動・退職の件数と担当が替わった顧客の数で、埋まるのは「年間に担当が替わる顧客数」の1項だけに見える。行121は取引額の資料がないことを試算を控える理由に挙げている。
- 残る2項(失注率の改善幅、1顧客あたりの年間取引額)は、どこから取って概算を追加するのか。

**L5. 1か月目に出る試算に、3か月目に決まる値が要る(行121、145 と 行54、107、147)**
行121と行145は効果の試算を1か月目に置く。ところが式の「失注率の改善幅」は、過去の実績から出る値ではなく、これから改善する幅である。行54と行147で目標値を決めるのは3か月目。
- 改善幅は、1か月目のどの実績から、どう算出するのか。

**L6. 投資額が決まる前に「見合うか」を報告することになる(行121 と 行135、147)**
行121は最初の1か月で「投資額に見合う効果が見込めるか」を報告するとしている。ライセンス費の見積もりが出るのは3か月目の製品選定の段階(行135、147)。
- 1か月目の報告で比べる投資額には、ライセンス費が入っているのか。

**L7. 効果を測る時期と、測れる時期が合っていない(行107、153 と 行111、112、151)**
全体展開は7か月目、効果測定は9か月目で、間は2か月ほどしかない。
- 配属から独り立ちまでの期間(行112)は、この2か月で導入後の値が出るのか。
- 行111の「一定期間」はどれだけの長さか。その期間の内に、導入後に担当が替わった顧客の失注率は出るのか。

**L8. 「最も重要な課題」に対して、定着の期間が短い(行71 と 行14、60、152、153)**

- 何がどうなれば「使われ続ける状態」とするのか。
- 9か月目にその状態に届いていないとき、支援はどう扱うのか。

細かいものが3件。

## 2. 根拠のない主張

**L9. 「見合う」かを判断する基準がない(行21、121、157)**(前提条件のちがい)
3か所とも判断の材料は挙げているが、どうなれば進むのかは書いていない。行119の式は年間の金額で、投資額は一度に払う支援費用とライセンス費である。行20の期待効果のうち、新人の立ち上がりは式に入っていない。
- 年間の効果と投資額を、何年分で比べるのか。
- 新人の効果は「見合う」かの判断に入れるのか、入れないのか。
- 試算がどの水準なら「進む」と読み手に勧めるのか。

**L10. 新人の立ち上がりの課題が、課題の節にない(行20、95、97 と 行25〜37)**(前提条件のちがい)
新人の立ち上がりは行20の期待効果と行97に出てくるが、節1の課題3つに入っていない。立ち上がりが遅いという事実も本文にない。行52で調べる段階である。
- 短縮が要るほど、いまの立ち上がりは長いのか。
- 主に目指す効果(行103)として挙げる根拠はどこにあるか。

**L11. B社の事例が「つながった」と言っている(行101、103)**(偶然の必然化)
本文にあるのは、導入の後に受注率が12%から15%に上がったという前後関係までで、営業記録の共有が原因だと示す事実はない。行103は指標の違いと体制の違いを断っているが、因果の断りはない。
- 受注率が上がった原因を営業記録の共有と言える根拠は、文書の中にあるか。
- 行103のとおり指標が違うなら、この事例は期待効果のどの主張を支えているのか。

**L12. 「平均年齢が高い」から2つの見込みを導いている(行37、71)**(前提条件のちがい)
行37は退職の増加を、行71はツールへの抵抗を、どちらも「平均年齢が高く」から導く。平均年齢の値も年齢の分布も本文にない。
- 高いとは何歳か。数年のうちに退職する人は何名ほどか。
- 抵抗の予想は、年齢のほかに何から来ているのか。

**L13. 「関係や知見」が SFA のどこに残るのかが書かれていない(行37 と 行63、74、93)**(異質なものの同質化)
行37が残すとするのは、ベテランが築いた「顧客との関係や知見」である。施策で扱うのは訪問履歴や商談の経緯(行93)と Excel の記録(行63)で、行74は入力項目を最小限に絞る。
