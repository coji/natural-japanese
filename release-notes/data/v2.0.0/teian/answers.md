1. 問い:「御社ではこの引き継ぎの場面で実際に失注が起きています」(doc.md 行33)は、北都フーズの方から聞いた話ですか、資料で見たことですか。過去1〜2年に担当替えのあとで失った顧客の件数や取引額について、分かっていることがあれば教えてください。あわせて、ここでの「失注」は取引の停止と減少のどちらを指しますか。
   答え:聞いた話です。営業本部長が「引き継ぎで2社失った」と話したのを聞いただけで、資料では確かめていません。台帳はあると営業本部長から聞いていますが、見せてもらっていません。失った顧客の件数と取引額は、この「2社」という発言のほかは分かりません。その2社がいつの話かも分かりません。「失注」が取引の停止と減少のどちらを指すかも分かりません。失注率の定義は決めておらず、御社と決めることにしています。

2. 問い:失注した顧客ごとの理由を、北都フーズの方から聞いていますか。情報が後任に届かなかった失注と、情報は届いたのに前任者との関係が切れて起きた失注は、それぞれどのくらい混じっていると見ていますか(doc.md 行12、33、37)。
   答え:聞いていません。営業本部長が話した2社についても理由は聞いておらず、失注の理由を確かめた記録もありません。情報が届かなかった失注と関係が切れて起きた失注がどのくらい混じっているかは、分かりません。

3. 問い:営業担当30名の毎日の入力(doc.md 行71)が支援の終了後も続くと見込む材料はありますか。当社の過去の支援で、支援が終わってしばらく経ったあとの入力率の記録や、4つの工夫(doc.md 行73〜83)を実際に試した結果があれば教えてください。
   答え:分かりません。支援の終了後も入力が続くと見込む材料、過去の支援での入力率の記録、4つの工夫を試した結果は、いずれも私の手元の事実にはありません。入力に関して知っているのは、営業担当3名に話を聞いて、2名が賛成、1名が入力の手間を心配していたことだけです。これは支援の終了後の入力が続くかどうかを確かめたものではありません。
