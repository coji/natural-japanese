## 本提案の要点

御社の営業担当30名の顧客訪問記録は、現在、担当者それぞれの Excel ファイルに保存されています。そのため担当者が異動・退職するたびに顧客の情報が後任に十分引き継がれず、失注が起きています。

当社は、この訪問記録を個人の手元ではなく会社の資産として蓄積し、活用できる状態にするご支援を提案します。最初の3か月で現状を診断し、続く6か月で SFA(営業支援システム)の導入と、現場で使われ続ける状態になるまでの定着を支援します。

| 項目 | 内容 |
|---|---|
| 期間 | 9か月(現状診断 3か月+SFA 導入・定着支援 6か月) |
| 費用 | 月額300万円、総額2,700万円(SFA のライセンス費は別途) |
| 期待効果 | 引き継ぎによる失注の削減、新人が独り立ちするまでの期間の短縮 |
| 判断の区切り | 現状診断が終わる3か月目の時点で、診断結果をもとに導入フェーズへ進むかどうかをご判断いただけます |

---

## 1. 現状の課題

### 顧客の情報が担当者個人のもとにある

訪問記録が個人の Excel にあるため、どの顧客と、いつ、どのような話をしたのかは、基本的に担当者本人しか分かりません。

### 異動・退職のたびに失注が起きている

御社では担当者が替わるときの引き継ぎの場面で実際に失注が起きています。

### 今後、引き継ぎの機会は増えていく

御社の営業担当は平均年齢が高く、今後数年のうちに退職に伴う引き継ぎが増えていくと見込まれます。

---

## 2. ご提案内容

### フェーズ1 現状診断(3か月)

SFA を入れる前に、御社の営業の実態と、引き継ぎで何が起きているのかを把握します。フェーズ1の成果物として、診断報告書、SFA の要件と製品比較、導入計画書(効果目標を含む)をお渡しします。

### フェーズ2 SFA 導入・定着支援(6か月)

フェーズ1で決めた計画に沿って SFA を導入し、営業担当が日常的に使う状態まで支援します。全体展開では、営業担当30名と管理職の方を対象に研修を行います。

### 現場で使われ続けるための工夫

営業担当が毎日記録を入れて、初めて引き継ぎにも新人育成にも使える情報がたまります。当社はこの点を最も重要な課題と考え、次の4つの工夫を組み込んでいます。

1. 入力項目を最小限に絞る
2. ベテランの担当者に試行段階から参加していただく
3. 入力することが本人の手間を減らす形にする
4. 一人ひとりに合わせて支援する

## 3. 期待効果

### 引き継ぎによる失注の削減

引き継ぎルールを整えることで、口頭説明だけに頼る引き継ぎがなくなり、情報の抜け落ちによる失注を減らせます。

### 新人の立ち上がり期間の短縮

新人は担当する顧客の過去の記録を読んで、これまでの経緯をつかんだうえで訪問できます。

### 投資額に見合う効果があるかの判断

フェーズ1の最初の1か月で過去の引き継ぎ実績から失注件数や取引額を算出し、投資額に見合う効果が見込めるかをご報告します。3か月目の継続判断は、この試算をもとに行っていただけます。

## 付録A 現状の課題の補足

### 顧客の情報が担当者個人のもとにある

書式や記録の細かさも人によって違います。上長やほかの担当者が顧客の状況を知ろうとしても、本人に聞くほかないのが実情です。

### 異動・退職のたびに失注が起きている

担当者が替わるとき、後任者は前任者の Excel と口頭の説明を手がかりに顧客を引き継ぐことになります。記録に残っていない経緯や顧客との約束事は、ここで抜け落ちやすくなります。どのような情報が抜けたことで失注に至ったのか、その件数と金額はどの程度か、は現状診断で具体的に確認します。

### 今後、引き継ぎの機会は増えていく

ベテラン担当者が長年かけて築いてきた顧客との関係や知見を、在籍しているうちに会社として残しておけるかどうかが問われています。対策を始めるなら、早いほど残せる情報は多くなります。

## 付録B フェーズ1の作業内容

現状診断を丁寧に行うことで、現場に合わない仕組みを入れてしまう事態を避けます。

- 訪問記録の実態調査:30名の Excel に何が、どの程度の細かさで、どのくらいの頻度で記録されているかを確認します
- 引き継ぎ失注の分析:過去の異動・退職で担当が替わった顧客を洗い出し、失注の件数・金額・原因を整理します
- 営業担当・管理職へのヒアリング:日々の業務の流れ、記録や報告にかけている手間、新しいツールへの不安や要望をうかがいます
- 新人の立ち上がりの実態把握:独り立ちまでにかかっている期間と、その間に困っていることを確認します
- SFA の要件整理と製品選定の支援:記録すべき項目を絞り込み、候補となる製品を比較して選定をお手伝いします
- 導入計画と効果目標の策定:フェーズ2の詳細な計画と、効果を測る指標・目標値を決めます

## 付録C フェーズ2の作業内容

- 初期設定:入力項目、画面、閲覧権限などを、SFA ベンダーと連携しながら御社の業務に合わせて設定します
- 既存データの移行:Excel の記録のうち、どの顧客のどの情報を移すかを決め、移行を支援します
- 試行導入:一部の営業担当に先行して使っていただき、使いにくい点を直してから全体に広げます
- 全体展開と研修:営業担当30名と管理職の方を対象に研修を行います
- 引き継ぎルールの整備:異動・退職の際に SFA に何を残し、後任者が何を確認するかを決め、社内のルールとして定めます
- 効果測定と運用の引き渡し:効果目標に対する結果を測定し、支援終了後も御社だけで運用を続けられるよう体制を整えます

## 付録D 現場で使われ続けるための工夫の詳細

SFA は、入れただけでは効果が出ません。御社の営業担当は平均年齢が高く、新しいツールへの抵抗も予想されます。

1. 入力項目を最小限に絞る
   入力の手間が多いほど、記録は続きません。ヒアリングを通じて「引き継ぎに本当に必要な情報は何か」を現場と一緒に見極め、項目を絞り込みます。

2. ベテランの担当者に試行段階から参加していただく
   試行メンバーには、若手だけでなくベテランの方にも入っていただきます。現場の第一線にいる方の意見を設定に反映することで、実際に使える仕組みになります。また、試行を経験した方が、全体展開の際に周囲へ使い方を伝える役割を担えます。

3. 入力することが本人の手間を減らす形にする
   現在の日報や上長への報告がどのように作られているかを診断で確認し、SFA への入力で代わりにできるものは置き換えます。Excel と SFA の二重入力が生じないようにします。

4. 一人ひとりに合わせて支援する
   集合研修だけで終わらせず、操作に不安のある方には個別にサポートします。全体展開の後も入力状況を確認し、記録が止まっている方には早めに声をかけます。

あわせて、ベテランの方に記録をお願いする際には、それがご本人の仕事を会社に残し、後輩に引き継ぐことでもあるとお伝えしていきます。

## 付録E 期待効果の補足

### 引き継ぎによる失注の削減

顧客ごとの訪問履歴や商談の経緯が SFA にまとまるため、後任者は着任前に過去のやりとりを確認できます。

### 新人の立ち上がり期間の短縮

上長も新人の訪問状況を SFA で確認できるため、つまずきに早く気づいて助言できます。

### 同じ規模の食品卸での事例

御社と同規模の食品卸であるB社では、SFA の導入後に受注率が12%から15%に上がりました。同業・同規模の会社で、営業記録の共有が成果につながった例です。

ただし、B社と御社では顧客の構成や営業体制が異なります。また、B社で改善したのは受注率であり、本提案で主に目指す引き継ぎ失注の削減や新人の立ち上がり短縮とは指標が異なります。B社と同じ数字をお約束するものではなく、御社での効果目標は現状診断の結果をもとに設定します。

### 効果の測り方

次の指標を使い、導入前後を比べて効果を確認します。導入前の数値はフェーズ1で測定し、目標値は導入計画の中で御社と合意して決めます。

| 指標 | 内容 | 確認の目的 |
|---|---|---|
| 引き継ぎ顧客の失注率 | 担当が替わった顧客のうち、一定期間内に失注した割合 | 引き継ぎ失注の削減 |
| 新人の独り立ちまでの期間 | 入社(配属)から、単独で顧客を担当するまでの期間 | 立ち上がり期間の短縮 |
| SFA の入力率 | 訪問のうち、SFA に記録された割合 | 現場への定着 |

### 投資額に見合う効果があるかの判断

引き継ぎ失注の削減による効果は、おおよそ次の式で見積もれます。

> 年間に担当が替わる顧客数 × 失注率の改善幅 × 1顧客あたりの年間取引額

現時点で当社は御社の失注件数や取引額の資料を持っていないため、本資料では金額での試算を控えています。
