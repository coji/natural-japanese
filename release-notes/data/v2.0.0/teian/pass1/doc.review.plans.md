# doc.review.md の構成案

問いの番号は `report-logic.md`(L)と `report-somosomo.md`(S)のもの、行番号は `doc.md` の行です。組み直した本文には、案Bを使いました。

## 案A 頼む中身を小さくする案(書き手が選ぶ案)

**主張**:まず3か月・900万円の現状診断で、引き継ぎ失注の大きさと原因を確かめます。

**縮めた決裁事項**:「最初の3か月で現状を診断し」「フェーズ1 現状診断 3か月 900万円」を、フェーズ1の契約として決めてもらう。

**本編の骨組み**

1. 決めていただくこと
2. 引き継ぎの場面での失注
3. フェーズ1 現状診断
4. 成果物
5. フェーズ1の後の判断
6. 費用
7. 今後の進め方

**答える問い**:L9、L10、S1、S2、S3

**元の決裁事項が倒れる問い**

- S1 の答え(行50、121、145):引き継ぎ失注の金額が小さければ、行19の2,700万円も行129の900万円も頼む理由がなくなる
- S2 の答え(行12、33、93):失注の原因が記録の抜けでなければ、行14の SFA の導入と定着の支援が倒れる
- S3 の答え(行21、157、190):9か月分の契約で3か月目に止められないなら、行21の「判断の区切り」は決裁の安心材料にならない

**この案を選ぶなら先に見る答え**:営業本部長から聞く2社の失注理由と、台帳の失注の件数と金額(S1、S2)。同じ材料で、頼む前に確かめる形もとれる。行192の数字を経営会議の前に受け取り、確かめてから頼む。

**弱点**:書き手の答えでは、この形に変える考えがあるかは分かっていない。フェーズ2の1,800万円は次の判断に回るので、受注額はこの時点で確定しない。

## 案B 判断の区切りを背骨にする案(本文に使った案)

**主張**:9か月・総額2,700万円の発注を、3か月目に営業本部長が進むかどうかを判断できる支援として頼みます。

**本編の骨組み**

1. 決めていただくこと
2. 3か月目の継続判断
3. 現状の課題
4. フェーズ1 現状診断
5. フェーズ2 SFA 導入・定着支援
6. 期待効果
7. 費用
8. 体制
9. 今後の進め方

**答える問い**:L5、L10、S3、S7(判断の材料と判断する人が先頭に来る。線そのものは書き手に残る)

**弱点**:背骨が3か月目に止められることなので、止めたときの費用と判断の基準が決まらないままだと、文書の先頭で問われる。

## 案C 定着を背骨にする案

**主張**:SFA を入れることよりも、営業担当が記録を続ける状態を9か月で作ることを支援します。

**本編の骨組み**

1. 現場で使われ続けるための工夫
2. 現状の課題
3. フェーズ1 現状診断
4. フェーズ2 SFA 導入・定着支援
5. 期待効果
6. 費用
7. 体制
8. 今後の進め方

**答える問い**:L3、S4、S8

**弱点**:定着の裏づけは文書の中では予想にとどまる(L14)。失注の大きさの問い(S1、S2)に答えないまま、支援の中身を厚く見せる形になる。

## 選んだ案と理由

案Bを選びました。頼む中身を保つ案のうち、書き手の答えから分かった決裁の焦点に答えるのが案Bだからです。失注の数字がまだない文書で読む人が最初に知りたいのは、いま何を決め、何を3か月目に決めるかで、案Bはそれを先頭に置きます。案Aは頼む中身が変わるので、書き手にしか選べません。
