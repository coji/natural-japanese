1. 問い:「御社ではこの引き継ぎの場面で実際に失注が起きています」(行12、33)は、誰から聞いた、どの話をもとに書きましたか。顧客の数、件数、金額など、いま分かっていることがあれば教えてください。また、過去の失注の数字を、経営会議の前に北都フーズから出してもらえそうですか。
   答え:営業本部長が「引き継ぎで2社失った」と話したのを聞いたのがもとです。その2社の失注理由は聞いておらず、理由を確かめた記録もありません。失注の件数と金額は分かりません。御社の台帳を見せてもらっていないためです。ほかに分かっているのは、営業本部長の話で去年の異動と退職が合わせて4名だったことだけで、担当が替わった顧客の数は聞いていません。営業本部長によれば台帳はありますが、経営会議の前に数字を出してもらえるかどうかは分かりません。

2. 問い:3か月目に「進まない」と判断された場合、契約はどうなりますか。900万円で終えられて、残りの1,800万円は発生しないという条件ですか。契約は9か月で一括ですか、フェーズごとに分けますか。
   答え:3か月目で止められる形にしてあります。ただし、先方の経営会議にかけるのは9か月分の契約です。フェーズ1だけの契約にすることもでき、その場合も900万円は変わりません。9か月分の契約を結んだうえで3か月目に止めた場合に、900万円で終わり残りの1,800万円が発生しないという条件になるのかは分かりません。なお、3か月目の判断の基準は決めておらず、御社の営業本部長が判断する想定です。

3. 問い:この文書で決めてもらうのは「9か月・総額2,700万円の支援を発注するか」だと読みました。違いますか。まず3か月・900万円の現状診断だけを決めてもらう形に変えるお考えはありますか。
   答え:その読みのとおりです。決めてもらうのは、9か月・2,700万円の支援を当社に発注するかです。フェーズ1だけの契約にもできますが、まず3か月・900万円だけを決めてもらう形に変える考えがあるかどうかは分かりません。
