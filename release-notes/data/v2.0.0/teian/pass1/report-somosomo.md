# doc.md の somosomo 検査

**文書の性格**:決めてもらう文書。北都フーズの営業本部長と経営会議が読み、営業部門デジタル化支援を発注するかを決める提案書。

**主結論**:訪問記録を会社の資産にする支援を、9か月・総額2,700万円(SFA のライセンス費は別途)で提案する。

**決裁者の論点**:引き継ぎによる失注は、2,700万円とライセンス費をかけて SFA で減らすだけの大きさがあり、SFA で減らせる種類のものか。

## 決裁事項を倒しうる問い

### S1 頼む前に確かめられることを、頼んでから確かめる形になっていないか(問いそのもの)

- 問い:引き継ぎ失注の件数と金額は、御社の手元の記録から出せるのではないか。それを出す作業が900万円の診断に入っている(行50、121、145)。行192は経営会議の前に数字をもらうことも想定している。経営会議の前に確かめられないのはなぜか。
- 倒れる場所:行14、19、129。金額が小さければ、診断を頼む理由ごとなくなる。
- 要る材料:過去の異動・退職で担当が替わった顧客の一覧と、その後の取引の記録。

### S2 失注の原因は、記録の抜けか(前提)

- 問い:「情報が後任に十分引き継がれず、失注が起きています」(行12)は、失注の原因を記録の抜けと置いている。担当が替わらなかった顧客の失注と比べて、替わった顧客の失注は多いのか。価格や競合など記録以外の理由で離れた顧客はどのくらいあるのか。
- 倒れる場所:行12、33、93、111。原因が別なら、SFA を入れても失注は減らず、提案の背骨が倒れる。
- 要る材料:担当が替わった顧客と替わらなかった顧客の失注率の比較、失注の理由の記録。

### S3 3か月目に、本当に止められるか(覆る条件、利害と実行)

- 問い:「判断の区切り」(行21)は、900万円で契約を終えられることを意味するのか。行190の「契約」の範囲が書かれていない。判断の材料を作るのは、続けば1,800万円を受注する当社である(行121、157)。試算は1か月目に出る(行145)のに、判断は3か月目になる。発注側はこの判断をどう受け取るか。
- 倒れる場所:行21、121、157。止められないなら決裁額は最初から2,700万円で、「区切り」が決裁の安心材料にならない。
- 要る材料:契約書案の中途終了の条件、フェーズごとの契約の形。

## 前提

- **S4**:問い:「営業担当が毎日記録を入れて」(行71)が定着の前提になっている。御社で過去に記録や報告のやり方を変えたとき、定着したか。倒れる場所:行71、93、97、113。要る材料:過去の記録や報告の変更と、その定着の記録、いまの Excel の記録の頻度。

## 問いそのもの

- **S5**:問い:残したいのは「顧客との関係や知見」(行37)だが、これは訪問記録の入力で残せるものか。SFA が定着するのは早くて8か月目(行152)で、それまでに退職する人の情報はどうなるのか。倒れる場所:行37、63、93。要る材料:抜け落ちて失注につながった情報の種類、向こう1〜2年の退職予定者の数。

## 他の選択肢

- **S6**:問い:YAML の `比べた案` は「なし」で、比べているのは SFA の製品どうしだけ(行53)。何もしない案、範囲を変える案、自前でやる案と比べたか。文書自身が書いている引き継ぎルールの整備(行66)は、SFA の導入と切り離して考えたか。行157は「先に取り組むべきこと」の可能性に触れているが、文書全体は SFA を前提に書かれている。倒れる場所:行14、47、157。要る材料:比べた案と、比べた軸の記録。

## 覆る条件

- **S7**:問い:行121と行157は「見合う」かどうかを判断すると言うが、どの数字を下回ったら進まないのか。線が書かれていない。ライセンス費は「別途」で上限がなく(行19、135)、支援終了後も続く費用か分からない。総投資額はいくらなら見合わなくなるのか。倒れる場所:行19、21、121、135。要る材料:継続を判断する線、候補製品の価格帯と利用人数。

## 利害と実行

- **S8**:問い:営業担当30名の入力時間、研修、試行の負担は費用に入っていない。負荷は「キックオフの際に」(行177)決まるので、決裁のときには見えない。入力の手間を負うのは営業担当で、効果を受けるのは後任と会社である(行71、85)。入力する人にとって、利益はあるのか。倒れる場所:行71、79、80、177。要る材料:1件あたりの入力時間の見込みと、日々の訪問件数。

ほかに細かいものが2件ある。

- 製品選定を支援する当社と SFA ベンダーのあいだに、提携や報酬の関係はあるか(行53、62)
- 効果の測定を支援する当社が自分で行う(行67)。支援終了後は誰が測るのか(行153)

## 反論(仮の立場)

- 問題は道具ではなく引き継ぎのやり方にある、という読みが成り立つ。行33の抜け落ちは「口頭の説明」の場面で起きており、行66の引き継ぎルールが本体で、SFA はその手段の1つにとどまると読める。
- この提案には数字で示された効果が1つもない、という読みが成り立つ。行101の事例は行103で本提案とは指標が違うと断られ、行121は金額の試算を控えている。読み手は、効果の大きさを見ずに2,700万円を判断することになると読める。
