対象:北都フーズ向け「営業部門デジタル化支援のご提案」。行番号は doc.md のファイルの行番号。L1、S1 などは `report-logic.md` と `report-somosomo.md` の指摘の番号。

決裁者の論点:引き継ぎの失注は、訪問記録を SFA に移せば減らせる問題で、しかも2,700万円とライセンス費に見合う大きさか。

3案とも、文書にある事実と頼む中身だけで作った。案Bと案Cは決裁事項を変えない。案Aだけは決裁事項を縮めるので、選べるのは書き手だけである。

## 選んだ案と理由

案B を選んだ。決裁者の論点に対して、文書が今言えるのは「まだ分からず、3か月目に分かる」ところまでである。この文書の中でいちばん確かな部分を背骨にできるのは案Bだけで、S1 と S2 の不確かさを隠さずに、決裁事項(9か月、総額2,700万円、3か月目の判断)をそのまま保てる。案Cは根拠の薄い部分を前に出すことになる。案Aは決裁事項を変えるので、書き手が選ぶまで本文にはしない。
