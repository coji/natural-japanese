## 出す前にやること

1. 経営会議に出す頼み方を、9か月・総額2,700万円のままにするか、3か月・900万円の現状診断だけにするかを決める。昨年の失注は年間約1,200万円で、すべて防いでも支援費用の2,700万円を取引額で取り返すのに2年3か月かかり、ライセンス費は別にかかる。決めるのは書き手と、自社で契約条件を決める人 → 変えるなら、「本提案の要点」の表の期間と費用、4章の費用の表、7章「今後の進め方」の2と3を、3か月・900万円の頼み方に書き換える。変えないなら、本文はこのままでよい

3. 台帳の数字(4名、38社、2社と年間約1,200万円、5社と年間約900万円)を経営会議の資料に載せてよいかを、営業本部長に聞く → 載せてよいなら本文はこのままでよい。載せられないなら、「本提案の要点」の2文目、1章の最初の2段落、2章の昨年の実績の2文を削り、「その件数と金額はどの程度か、は現状診断で具体的に確認します」と元の文に戻す。1章の見出しも「異動・退職で起きている失注」に変える

## 頼む中身を小さくする案

経営会議で決めてもらう内容を、フェーズ1の3か月・900万円の現状診断だけにし、フェーズ2は3か月目の報告のあとに決めてもらう。年間約1,200万円の失注が総額2,700万円とライセンス費に見合うかが、まだ言えないためである。選ぶのは書き手で、本文は9か月・総額2,700万円のまま組み直した。
