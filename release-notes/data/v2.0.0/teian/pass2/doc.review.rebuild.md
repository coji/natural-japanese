## 本提案の要点

御社の営業担当30名の顧客訪問記録は、現在、担当者それぞれの Excel ファイルに保存されています。そのため担当者が異動・退職するときに顧客の情報が後任に十分引き継がれず、失注につながっていると当社は見ています。

当社は、この訪問記録を個人の手元ではなく会社の資産として蓄積し、活用できる状態にするご支援を提案します。最初の3か月で現状を診断し、続く6か月で SFA(営業支援システム)の導入と、現場で使われ続ける状態になるまでの定着を支援します。

決めていただきたいのは、この9か月・総額2,700万円の支援を当社に発注するかどうかです。去年の実績で見える効果は総額に届きません。3か月目に判断の区切りがあり、進まない場合はフェーズ1の900万円で終わります。

| 項目 | 内容 |
|---|---|
| 期間 | 9か月。現状診断3か月と SFA 導入・定着支援6か月 |
| 費用 | 月額300万円、総額2,700万円。SFA のライセンス費は別途 |
| 期待効果 | 引き継ぎによる失注の削減、新人が独り立ちするまでの期間の短縮 |
| 判断の区切り | 現状診断が終わる3か月目の時点で、診断結果をもとに導入フェーズへ進むかどうかを営業本部長にご判断いただけます。進まない場合はフェーズ1の900万円で終わり、フェーズ2の1,800万円は発生しません |

## 1. 引き継ぎの場面での失注

営業本部長に見せていただいた台帳では、去年の異動・退職4名の担当顧客38社のうち、翌年の取引がなくなったのは2社で、合計で年間約1,200万円です。取引が半分以下に減った顧客も5社あり、減少分の合計は年間約900万円です。失った2社は、担当が替わった直後に先方から「前任者と話していた条件が引き継がれていない」と言われて失注しました。

担当者が替わるとき、後任者は前任者の Excel と口頭の説明を手がかりに顧客を引き継ぎます。記録に残っていない経緯や顧客との約束事は、ここで抜け落ちやすくなります。

## 2. 投資額に見合う効果の判断

去年の実績では、失注と取引の減少をすべて防げたとしても、効果は年間約2,100万円で、支援費用の総額2,700万円を下回ります。2社をすべて防げた場合の効果は、失った取引の年間約1,200万円です。これに取引が半分以下に減った5社の減少分、年間約900万円を足すと、年間約2,100万円になります。いずれも1年分の取引額です。

フェーズ1の最初の1か月で過去の引き継ぎ実績からこれらの数字を算出し、投資額に見合う効果が見込めるかをご報告します。3か月目の継続判断は、この試算をもとに行っていただけます。

## 3. 3か月目の継続判断

現状診断が終わった時点で、診断報告書・効果の試算・SFA のお見積もり・導入計画をそろえてご報告します。営業本部長には、その内容をもとに、フェーズ2へ進むかどうかをご判断いただけます。進まない場合はフェーズ1の900万円で終わり、フェーズ2の1,800万円は発生しません。契約は2つに分け、フェーズ2の契約はこの報告のあとに結びます。診断の結果、SFA 導入よりも先に取り組むべきことが見つかった場合は、その旨を率直にご報告します。

## 4. フェーズ1 現状診断

SFA を入れる前の3か月で、御社の営業の実態と、引き継ぎで何が起きているのかを把握します。現場に合わない仕組みを入れてしまう事態を避けるためです。成果物として、診断報告書、SFA の要件と製品比較、効果目標を含む導入計画書をお渡しします。作業の一覧は付録Bに、月ごとの予定は付録Cにまとめました。

## 5. フェーズ2 SFA 導入・定着支援

続く6か月で、フェーズ1で決めた計画に沿って SFA を導入し、営業担当が日常的に使う状態まで支援します。異動・退職の際に SFA に何を残し、後任者が何を確認するかも決め、社内のルールとして定めます。

顧客ごとの訪問履歴や商談の経緯が SFA にまとまれば、後任者は着任前に過去のやりとりを確認できます。引き継ぎルールを整えることで、情報の抜け落ちによる失注を減らせる見込みです。

当社は、現場で使われ続けることをこの支援で最も重要な点と考えています。SFA は、入れただけでは効果が出ません。営業担当が毎日記録を入れて、初めて引き継ぎにも新人育成にも使える情報がたまります。御社の営業担当は平均年齢が高く、新しいツールへの抵抗も予想されます。このため、入力項目を最小限に絞る、ベテランの担当者に試行段階から参加していただく、といった4つの工夫を組み込みます。説明は付録Dにまとめました。

## 付録A 課題と効果の補足

### 担当者個人のもとにある顧客の情報

訪問記録が個人の Excel にあるため、どの顧客と、いつ、どのような話をしたのかは、基本的に担当者本人しか分かりません。書式や記録の細かさも人によって違います。上長やほかの担当者が顧客の状況を知ろうとしても、本人に聞くほかないのが実情です。

### 今後の引き継ぎの増加

御社の営業担当は平均年齢が高く、今後数年のうちに退職に伴う引き継ぎが増えていくと見込まれます。ベテラン担当者が長年かけて築いてきた顧客との関係や知見を、在籍しているうちに会社として残しておけるかどうかが問われています。対策を始めるなら、早いほど残せる情報は多くなります。

### 新人の立ち上がり期間の短縮

記録がたまれば、新人は担当する顧客の過去の記録を読んで、これまでの経緯をつかんだうえで訪問できます。上長も新人の訪問状況を SFA で確認でき、つまずきに早く気づいて助言できます。

### 効果の式

> 年間に担当が替わる顧客数 × 失注率の改善幅 × 1顧客あたりの年間取引額

### 同じ規模の食品卸での事例

御社と同規模の食品卸であるB社では、SFA の導入後に受注率が12%から15%に上がりました。ただし、B社と御社では顧客の構成や営業体制が異なり、改善した受注率も本提案で主に目指す指標とは異なります。B社と同じ数字をお約束するものではなく、御社での効果目標は現状診断の結果をもとに設定します。

### 効果の測り方

指標を使って導入前後を比べ、効果を確認します。導入前の数値はフェーズ1で測定し、目標値は導入計画の中で御社と合意して決めます。失注は、御社とご相談のうえ、担当交代の翌年に取引がなくなった顧客とします。

| 指標 | 内容 | 確認の目的 |
|---|---|---|
| 引き継ぎ顧客の失注率 | 担当が替わった顧客のうち、担当交代の翌年に取引がなくなった顧客の割合 | 引き継ぎ失注の削減 |
| 新人の独り立ちまでの期間 | 入社または配属から、単独で顧客を担当するまでの期間 | 立ち上がり期間の短縮 |
| SFA の入力率 | 訪問のうち、SFA に記録された割合 | 現場への定着 |

## 付録B 作業の一覧

### フェーズ1 現状診断

- 訪問記録の実態調査:30名の Excel に何が、どの程度の細かさで、どのくらいの頻度で記録されているかを確認します
- 引き継ぎ失注の分析:過去の異動・退職で担当が替わった顧客を洗い出し、失注の件数・金額・原因を整理します
- 営業担当・管理職へのヒアリング:日々の業務の流れ、記録や報告にかけている手間、新しいツールへの不安や要望をうかがいます
- 新人の立ち上がりの実態把握:独り立ちまでにかかっている期間と、その間に困っていることを確認します
- SFA の要件整理と製品選定の支援:記録すべき項目を絞り込み、候補となる製品を比較して選定をお手伝いします
- 導入計画と効果目標の策定:フェーズ2の詳細な計画と、効果を測る指標・目標値を決めます

### フェーズ2 SFA 導入・定着支援

- 初期設定:入力項目、画面、閲覧権限などを、SFA ベンダーと連携しながら御社の業務に合わせて設定します
- 既存データの移行:Excel の記録のうち、どの顧客のどの情報を移すかを決め、移行を支援します
- 試行導入:一部の営業担当に先行して使っていただき、使いにくい点を直してから全体に広げます
- 引き継ぎルールの整備:異動・退職の際に SFA に何を残し、後任者が何を確認するかを決め、社内のルールとして定めます
- 全体展開と研修:営業担当30名と管理職の方を対象に研修を行います
- 効果測定と運用の引き渡し:効果目標に対する結果を測定し、支援終了後も御社だけで運用を続けられるよう体制を整えます

## 付録D 現場で使われ続けるための工夫の説明

1. 入力項目を最小限に絞る
   入力の手間が多いほど、記録は続きません。ヒアリングを通じて「引き継ぎに本当に必要な情報は何か」を現場と一緒に見極め、項目を絞り込みます。

2. ベテランの担当者に試行段階から参加していただく
   試行メンバーには、若手だけでなくベテランの方にも入っていただきます。現場の第一線にいる方の意見を設定に反映し、実際に使える仕組みに近づけます。また、試行を経験した方が、全体展開の際に周囲へ使い方を伝える役割を担えます。

3. 入力することが本人の手間を減らす形にする
   現在の日報や上長への報告がどのように作られているかを診断で確認し、SFA への入力で代わりにできるものは置き換えます。Excel と SFA の二重入力が生じないようにします。

4. 一人ひとりに合わせて支援する
   集合研修だけで終わらせず、操作に不安のある方には個別にサポートします。全体展開の後も入力状況を確認し、記録が止まっている方には早めに声をかけます。

あわせて、ベテランの方に記録をお願いする際には、それがご本人の仕事を会社に残し、後輩に引き継ぐことでもあるとお伝えしていきます。
