# somosomo の検査報告:doc.md

**文書の性格**:決めてもらう文書。北都フーズの営業本部長が読み、経営会議が審議する、9か月の営業部門デジタル化支援の提案書。

**主結論**:訪問記録を個人の手元ではなく会社の資産として蓄積し、活用できる状態にする支援を、9か月・総額2,700万円で提案する。

**決裁者の論点**:引き継ぎ失注の損失は総額2,700万円とライセンス費に見合う大きさで、その原因は SFA で解けるものか。

## 決裁事項を倒しうる問い

**S1 失注の件数と金額を、発注の前に確かめられないか**
- 問い:失注の件数と金額、担当が替わった顧客の数は御社の記録から出せるのに、それを出す作業を900万円の診断に含めている(行33、50、121、145)。確かめてから頼めることを、頼んでから確かめる形になっていないか。行192が経営会議の前に数字をもらえればと書いている以上、もらえたか、もらえるかが先ではないか。
- 倒れる場所:行12、行19、行121
- 要る材料:過去の異動・退職で担当が替わった顧客の一覧と、そのうち失注した顧客の件数と金額
- どう倒れるか:数字を見て失注が小さければ、9か月の発注も900万円の診断も立たない

**S2 費用に見合うか**
- 問い:行119の式に実際の数字を入れると、年間の効果はいくらか。総額2,700万円と別途のライセンス費を、何年で取り返す計算か。
- 倒れる場所:行19、行117〜121、行135
- 要る材料:失注額の実績、利用人数の分のライセンス費の見当、失注の削減を取引額で見るか利益で見るかの線
- どう倒れるか:失注をすべて防いでも費用に届かなければ、頼む金額が立たない

**S3 原因は記録の置き場所か**
- 問い:失注の原因は「訪問記録が個人の Excel にあること」(行12)か。後任に伝わらなかったのは、記録に残っていないことか、残っていたのに伝わらなかったことか(行33)。
- 倒れる場所:行12、行58〜67、行93
- 要る材料:失注した顧客ごとの理由の記録
- どう倒れるか:原因が記録の置き場所でなければ、SFA を入れても失注は減らず、フェーズ2が立たない

## 前提

**S4 新人の立ち上がりは課題か**
- 問い:独り立ちまでの期間が長いという話は、誰から聞いたか(行20、52、95)。
- 倒れる場所:行20、行95〜97、行112
- 要る材料:新人の独り立ちまでの期間の記録、または現場の声

**S5 引き継ぎはどのくらい増えるか**
- 問い:「今後数年のうちに」増える引き継ぎは、何名、何社か(行37、71)。
- 倒れる場所:行35〜37、行71
- 要る材料:営業担当の年齢構成、定年までの年数

## 問いそのもの

**S6 決めてもらうのは9か月か3か月か**
- 問い:経営会議に決めてもらうのは「9か月・総額2,700万円の発注」か、「3か月・900万円の診断」か(行19、21、189、190)。3か月目に判断できると書くなら、経営会議が最初に決めるのはどちらか。
- 倒れる場所:行18、19、21、190
- 要る材料:御社の決裁の範囲と、当社の契約の形

## 他の選択肢

**S7 ほかの案と比べたか**
- 問い:`比べた案` は「なし」。何もしない案、範囲を変える案、自前でやる案と比べたか。比べたなら、比べた記録は文書に出せるか(行14)。行66の引き継ぎルールの整備は、SFA の導入が前提か。
- 倒れる場所:行14、行66、行130
- 要る材料:比べた案と比べた軸の記録

## 覆る条件

**S8 3か月目の判断はどの数字で決まるか**
- 問い:進まないと決めるのは、どの数字がどの線を下回ったときか。文書は判断の場を書いているが基準を書いていない(行21、121、157)。進まないとき、フェーズ2の1,800万円はどうなるか。
- 倒れる場所:行21、行157
- 要る材料:判断の基準と、途中で止めたときの契約条件

**S9 ライセンス費はいくらまで許されるか**
- 問い:ライセンス費は別途で、経営会議は総額が分からないまま審議する(行19、135)。いくらを超えたら、提案は成り立たないか。
- 倒れる場所:行19、行135
- 要る材料:候補製品のライセンス費の見当

## 利害と実行

**S10 診断する側がフェーズ2を受注する**
- 問い:進むかどうかの材料(診断報告書、効果の試算、導入計画)をすべて当社が作り、進めば当社が1,800万円を受注する(行121、157、173)。判断の材料の中立さを、読み手は何で確かめられるか。
- 倒れる場所:行21、行157
- 要る材料:試算の元データを御社が確かめられる形、または第三者の確認

**S11 入力する人にとっての利益は何か**
- 問い:行71は抵抗を予想している。記録を入れる30名にとって何が得か。入力率が上がらなかったときに、誰が何をするのか(行83、113)。
- 倒れる場所:行71、行83、行113
- 要る材料:営業担当の声、入力率の目標

## 反論(仮の立場)

- 問題は道具ではなく引き継ぎのやり方にある、という読みが成り立つ。行33が書く抜け落ちは「口頭の説明」の場面で起きていて、行66の引き継ぎルールだけで足りると読める。
- 行103が自ら認めているように、B社の事例は指標が違う。すると行99〜101は、効果の裏づけにならないと読める。
