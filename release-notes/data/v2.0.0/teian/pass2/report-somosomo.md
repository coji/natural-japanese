# somosomo の報告:doc.md

**文書の性格**:決めてもらう文書。コンサルティング会社が北都フーズの営業本部長と経営会議に、営業部門のデジタル化支援の発注を決めてもらう提案書。

**主結論**:訪問記録を個人の手元ではなく会社の資産として蓄積し、活用できる状態にする9か月・総額2,700万円の支援を提案する。

**決裁者の論点**:引き継ぎで失っている取引は、2,700万円とライセンス費を払って防ぐだけの大きさがあり、原因は記録の置き場にあるのか。

## 決裁事項を倒しうる問い

- S1 引き継ぎで失っている取引の金額は、2,700万円とライセンス費に見合う大きさか。
  - 倒れる場所:行19、行93、行121。金額が費用を下回れば、行14の支援は失注の削減では説明できなくなる
  - 要る材料:担当が替わった顧客の数、失注の件数と金額、効果を何年分で見るかの物差し
  - どう倒れるか:課題をすべて解決しても費用に届かないなら、9か月・2,700万円を頼む理由が立たない
- S2 失注の原因は、本当に記録が個人の Excel にあることか。
  - 倒れる場所:行12「そのため」、行33、行93。別の原因なら、SFA を入れても失注は減らない
  - 要る材料:失注した顧客ごとの理由の記録、抜けた情報が前任者の Excel にあったかどうかの記録
  - どう倒れるか:原因が記録の置き場でなければ、行14の課題と解決の組み合わせが崩れる
- S3 台帳で確かめられることを、900万円の診断に含めていないか。確かめてから頼めることを、頼んでから確かめる形になっていないか。3か月目に進まないとき、残りの費用はどうなるのか。
  - 倒れる場所:行21、行50、行121、行157、行190、行192
  - 要る材料:台帳の異動・退職と失注の記録、止めたときの契約条件、継続判断の基準
  - どう倒れるか:判断の区切りが契約で守られず、線も置かれていなければ、「3か月目で判断できる」という安心が中身のないものになる

## 前提

- S4 行37「引き継ぎの機会は増えていく」は、実際に何年に何名の退職を見込んでいるのか。
  - 倒れる場所:行37、行121の式の「年間に担当が替わる顧客数」
  - 要る材料:名簿から出る退職見込みの人数と時期
- S5 行101のB社は、どこから得た事例で、本当に同規模か。
  - 倒れる場所:行101、行103
  - 要る材料:事例の出所、B社の営業の規模、受注率が上がった理由の記録
- S6 行121の式は取引額で効果を見ている。取引額をそのまま投資の回収額として読んでよいか。
  - 倒れる場所:行119、行121
  - 要る材料:御社の粗利の水準、失注しなかった場合に続いたであろう年数

## 問いそのもの

- S7 文書が答えているのは「どう SFA を入れるか」だが、決裁者が決めたいのは「失注を減らせるか」ではないか。SFA は決まった答えとして書かれていないか。
  - 倒れる場所:行14、行47、行157
  - 要る材料:SFA 以外の手段で引き継ぎを補える範囲を検討した記録
- S8 行20の新人の短縮は、御社が課題だと言っていることか。
  - 倒れる場所:行20、行95、行52
  - 要る材料:御社の新人の立ち上がりに関する声や記録

## 他の選択肢

- S9 `比べた案` は「なし」。何もしない案、小さく始める案、自前でやる案と比べたか。比べたなら記録を文書に出せるか。
  - 倒れる場所:行14
  - 要る材料:案ごとの費用と効果の比較

## 覆る条件

- S10 SFA の入力率がどこまで届かなければ、この支援は失敗か。行71が最も重要と書く点に、線がない。
  - 倒れる場所:行71、行113
  - 要る材料:同種の支援での入力率の実績
- S11 ライセンス費がいくらなら、3か月目に止めるのか。行19は「別途」だけで、総額が分からない。
  - 倒れる場所:行19、行135
  - 要る材料:候補製品の価格帯

## 利害と実行

- S12 診断する側が導入も受注する。行157「SFA 導入よりも先に取り組むべきこと」を当社が率直に報告できる形に、なっているか。
  - 倒れる場所:行53、行121、行157
  - 要る材料:効果の試算を誰が検証するかの取り決め
- S13 行53の製品比較で、当社と製品の間に利害はあるか。
  - 倒れる場所:行53、行135
  - 要る材料:製品を売る側との関係の開示、比較の対象の数
- S14 入力の手間を負うのは営業担当30名だが、その人たちの受け止めは文書のどこにあるか。
  - 倒れる場所:行71、行77
  - 要る材料:営業担当の声

## 反論(仮の立場)

- 行12と行33は「訪問記録の置き場」の問題として読めるが、問題は道具ではなく引き継ぎのやり方にある、という読みが成り立つ。
- 行21の判断の区切りは決裁者の安心のために置かれているが、行19が総額を前面に出しているので、3か月分の支援を9か月分として売っている、と読める。
