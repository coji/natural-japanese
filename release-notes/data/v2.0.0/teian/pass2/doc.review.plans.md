# doc.review.md の構成案

保つものは次の2つの文と、事実、数値、書き手の制約です。

- 主結論:当社は、この訪問記録を個人の手元ではなく会社の資産として蓄積し、活用できる状態にするご支援を提案します
- 決裁事項:決めていただきたいのは、この9か月・総額2,700万円の支援を当社に発注するかどうかです

問いの番号は `report-somosomo.md` と `report-logic.md` のものです。

## 案1 頼む中身を小さくする案

- 主張:まず3か月・900万円の現状診断を発注いただき、フェーズ2の1,800万円は、失注の金額と原因を見てから決めていただきます
- 骨組み:本提案の要点 / 引き継ぎの場面での失注 / 今回の発注:現状診断 / 投資額に見合う効果の判断 / フェーズ2の見通し / 費用 / 今後の進め方
- 答える問い:S1、S3、S9
- 縮めたもの:決裁事項を「9か月・総額2,700万円」から「3か月・900万円」に縮める。元の文書の言葉で書くと「最初の3か月で現状を診断し」の部分だけを頼む
- 元の決裁事項が倒れる問い:S1(行19、行121)。書き手の答えから、課題をすべて解決した場合の額は年間約2,100万円で、総額2,700万円を下回った。何年分で見るかの物差しが置けなければ、9か月・2,700万円を頼む理由が立たない
- 弱点:経営会議にかけるのは9か月分の契約だと書き手が答えているので、かける中身を変えられるかが分かっていない
- 本文:`doc.review.縮小.md` にある

## 案2 判断の区切りを背骨にする案(選んだ案)

- 骨組み:本提案の要点 / 引き継ぎの場面での失注 / 投資額に見合う効果の判断 / 3か月目の継続判断 / フェーズ1 現状診断 / フェーズ2 SFA 導入・定着支援 / 費用 / 今後の進め方

## 選んだ案と理由

対話できない実行なので、頼む中身を保つ案の中から案2を選びました。決裁者が最初に計算する「効果は2,700万円に届くのか」に先に答え、その答えが3か月目の判断の区切りにつながるためです。案3は、2社の原因が確かめられていない分、言い切りが強くなります。

案1は書き手にしか選べません。選ぶなら、先に S1 の答えを見てください。効果を何年分で見るかの物差しを置けるかどうかです。
