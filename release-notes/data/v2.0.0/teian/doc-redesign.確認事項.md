# doc-redesign.md の確認事項

書き手が提出前に読むためのファイルで、北都フーズには渡さない。

## 頼む中身を小さくする案

この提案の前提(失注の大きさ、原因、入力が続くか)は、いずれもまだ確かめられていない。下の「先に答える問い」の答えによっては、今回の決裁を最初の3か月の現状診断(900万円)だけに縮め、その前に過去1〜2年の異動・退職の件数と担当が替わった顧客の数を先に確かめる案がある(`plans.md` の案A)。選ぶのは書き手で、`doc-redesign.md` は9か月・総額2,700万円の提案のまま書いている。

## 先に答える問い

1. 失注の大きさは契約の前に確かめられないか。この提案は失注の件数も取引額も知らないまま2,700万円を示している。経営会議の前に数字をもらえるなら、北都フーズの手元の実績から出せる数字を、なぜ900万円のフェーズ1の作業に入れているのか。過去の実績が残っていないとき、1か月目の試算と3か月目の判断は成り立つのか。ここで言う「失注」は取引の停止か、取引の減少か。
2. 担当替えの失注は、本当に情報の抜け落ちから起きているのか。原因は記録の場所(個人の Excel)なのか、記録の有無(記録に残っていない経緯や約束事)なのか。情報は後任に届いていたのに、顧客との関係が前任者とともに切れて起きた失注は、どのくらい混じっているか。記録に残っていなかったものは、書く場所が SFA に変われば書かれるようになるのか。
3. 営業担当30名の毎日の入力が続くと言える材料はあるか。「毎日記録を入れて初めて情報がたまる」という見込みは何から来ているか。入力するのはベテランで、得をするのは後任、新人、上長である。上長に訪問状況が見えることは本人の負担にならないか。数年で退職するベテランが入力を続ける理由は、「お伝えしていきます」のほかにあるか。日報や報告の置き換えがどこまでできるかは、診断の前に分かっているのか。4つの工夫は当社の過去の支援で確かめたものか。

## そのほか

決める人と決める範囲

- 経営会議が承認するのは2,700万円か、フェーズ1の900万円か。「ご承認後、契約を締結」の対象は9か月全体か、3か月分か。
- 1,800万円分の継続判断は、営業本部長が一人で決めてよいものとして書いているのか。
- 3か月目に進まないと判断したとき、支払いは900万円で終わるのか。本文はこの点を書いていない。
- 経営会議が決めたいのは「SFA を入れるか」か、「引き継ぎの失注をどう止めるか」か。営業本部長の決裁権限の範囲はどこまでか。

失注の事実

- 「御社ではこの引き継ぎの場面で実際に失注が起きています」は、御社から聞いた話か、資料で見たことか、当社の推論か。本文は言い切りのまま残している。

効果の試算と判断の基準

- 式の「失注率の改善幅」は過去の実績から出る値ではない。1か月目のどの実績から、どう算出するのか。
- 経営会議の前に数字をもらって埋まるのは式の1項だけである。残る2項(失注率の改善幅、1顧客あたりの年間取引額)は、どこから取るのか。
- 「見合う」かを判断する基準は何か。年間の効果と投資額を何年分で比べるのか。新人の効果は判断に入れるのか。試算がどの水準なら「進む」と勧めるのか。
- 提案する側は、どの数字がどこまで下がればこの提案が成り立たないと見ているのか。
- ライセンス費は支援が終わったあとも続く費用か。それを足した額でも結論は変わらないのか。

判断の材料を作る人

- 3か月目の判断の材料を作るのも、効果目標を決めるのも、結果を測るのも、続けば1,800万円を受ける当社である。北都フーズは「率直にご報告します」のほかに、何でその内容を確かめられるのか。
- 製品選定を支援する当社と SFA ベンダーの間に、取引上の関係はあるか。

他の選択肢

- SFA を入れる案は、何と比べて選んだのか。何もしない案、Excel のまま引き継ぎルールだけを整える案、対象を絞って小さく始める案、自前でやる案と比べたか。比べたなら、記録は文書に出せるか。
- 診断の結論が「SFA は要らない」となる余地はどのくらいあるのか。そのとき、製品選定と導入計画の作業分の費用はどう扱うのか。

定着と効果の測定

- 何がどうなれば「使われ続ける状態」とするのか。定着支援に充てているのは8か月目の1か月で、9か月目に届いていないとき、引き渡しと費用はどうなるのか。
- 全体展開から効果測定まで2か月ほどである。配属から独り立ちまでの期間は、この間に導入後の値が出るのか。失注率の「一定期間」はどれだけの長さで、その期間内に導入後の失注率は出るのか。
- 置き換えられる日報や報告が少なかったとき、「本人の手間を減らす」は成り立つか。

新人の立ち上がり

- 短縮が要るほど、いまの立ち上がりは長いのか。新人の立ち上がりを課題だと言っているのは、北都フーズの誰か。主に目指す効果として挙げる根拠はどこにあるか。

- B社は当社の支援先か。数字の出どころはどこか。SFA を入れても受注率が上がらなかった同業の例は見ているか。

平均年齢と退職の見込み
