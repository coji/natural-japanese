# doc.md の somosomo 検査

**文書の性格**:〇〇コンサルティングから北都フーズへの提案書。営業部門デジタル化の支援を契約するかを決めてもらう文書で、読むのは営業本部長、審議するのは経営会議(行188、189)。

**主結論**:訪問記録を個人の手元から会社の資産に移す支援を提案する。3か月の現状診断と、6か月の SFA 導入・定着支援で、総額2,700万円(ライセンス費は別途)。3か月目に、導入へ進むかを判断できる(行14、19、21)。

**決裁者の論点**:引き継ぎの失注は、訪問記録を SFA に移せば減らせる問題で、しかも2,700万円とライセンス費に見合う大きさか。

行番号は doc.md のファイルの行番号。S1 などは指摘の番号、L1 などは `report-logic.md` の指摘の番号。

## 決裁事項を倒しうる問い

**S1. 失注の大きさは、契約の前に確かめられるのではないか(行33、50、121、192)**
- 問い:行121は失注件数と取引額の資料を持っていないと書く。つまりこの提案は、失注の大きさを知らないまま2,700万円を示している。行192は、異動・退職の件数と担当が替わった顧客の数を経営会議の前にもらえれば概算を足せると書く。北都フーズの手元の実績から出せる数字を、なぜ900万円のフェーズ1の作業(行50、145)に入れているのか。また、ここで言う「失注」は取引の停止か、取引の減少か。
- どう倒れるか:失注の金額が2,700万円とライセンス費に届かない大きさなら、導入だけでなく、そのための診断も頼む理由がなくなる。過去の実績が残っていなければ、行121の1か月目の試算も、それを材料にする3か月目の判断も立たない。
- 倒れる場所:行14、19、21、121、129
- 要る材料:過去1〜2年に担当が替わった顧客の一覧、その顧客のその後の取引の推移、失注した顧客の取引額、社内で使っている「失注」の定義

**S2. 担当替えの失注は、本当に情報の抜け落ちから起きているのか(行12、33、93)**
- 問い:行12は「そのため」で、失注の原因を訪問記録が個人の Excel にあることに置いている。一方、行33は原因をこれから確認すると書く。情報は後任に届いていたのに、行37の言う「顧客との関係」が前任者とともに切れて起きた失注は、どのくらい混じっているか。行33で抜け落ちるとされる「記録に残っていない経緯や顧客との約束事」は、書く場所が SFA に変われば書かれるようになるのか。
- どう倒れるか:失注の主な原因が記録の場所でなければ、SFA を入れても失注は減らない。行93の効果と、SFA を手段に選んだ行14の筋がともに立たなくなる。
- 倒れる場所:行12、14、20、93
- 要る材料:担当替えのあとに失注した顧客ごとの失注理由、失注しなかった担当替えの顧客との引き継ぎ内容の比べ、いまの Excel に残っている記録の見本

**S3. 30名の毎日の入力が続くと言える材料はあるか(行71、80、85)**
- 問い:行71は「営業担当が毎日記録を入れて、初めて」情報がたまると書き、これを最も重要な課題とする。この見込みは何から来ているか。入力するのはベテランで、得をするのは後任、新人、上長である(行93、97)。上長に訪問状況が見えることも、本人には負担になりうる。数年で退職するベテランが入力を続ける理由は、行85の「お伝えしていきます」のほかにあるか。行80の置き換えがどこまでできるかは、診断の前に分かっているのか。4つの工夫(行73〜83)は、当社の過去の支援で確かめたものか。
- どう倒れるか:入力が続かなければ情報はたまらず、期待効果の2つ(行20)がどちらも立たない。費用は支払い済みで、利用料だけが続くことになりうる。
- 倒れる場所:行20、60、71、93、97
- 要る材料:同種の支援で、支援が終わってから一定期間後の入力率の記録、北都フーズが過去に入れた業務ツールの定着状況、日報と上長への報告にかかっている手間の記録、営業の評価で記録がどう扱われているか

## 1. 前提

**S4. 急ぐ理由になっている退職の増加は、どのくらい確かで、対策は間に合うのか(行37、63、151)**
- 問い:行37は平均年齢の高さから退職に伴う引き継ぎの増加を見込み、「早いほど残せる情報は多くなります」と書く。今後数年で実際に何名が辞めるのか(平均年齢の値がないことは L12)。全体展開は7か月目(行151)で、それより前に辞める人の分は Excel の移行(行63)でしか残らない。ベテランの「長年かけて築いてきた」関係や知見は、導入のあとに日々の訪問記録を積むことで残るものか。
- 倒れる場所:行35、37、および行14の提案をいま始める理由
- 要る材料:営業担当30名の年齢の分布、定年と再雇用の規程、過去数年の異動と退職の人数、今後の退職の見込み

## 2. 問いそのもの

**S5. 文書が答えている問いと、北都フーズが決めたいことは同じか(行1、14、189、190)**
- 問い:課題は引き継ぎの失注(行12)だが、文書の分量の多くは SFA の入れ方と定着(行45〜83)に使われている。経営会議が決めたいのは「SFA を入れるか」か、「引き継ぎの失注をどう止めるか」か。文書は経営会議に何を決めてほしいのか。2,700万円の承認か、フェーズ1の900万円の承認か(L1)。
- 倒れる場所:行1、14、21、189、190
- 要る材料:この提案が持ち上がった経緯の記録(北都フーズの誰が、何に困っていると言ったか)、営業本部長の決裁権限の範囲、経営会議の決裁基準

## 3. 他の選択肢

**S6. SFA を入れる案は、何と比べて選んだのか(行47、53、54、66、157)**
- 問い:YAML の `比べた案` の2つ(導入へ進まない、SFA より先に取り組むべきこと)は、どちらも診断のあとの話である。提案の時点で、何もしない案、Excel のまま引き継ぎルール(行66)だけを整える案、対象を絞って小さく始める案、自前でやる案と比べたか。比べたなら、記録は文書に出せるか。行47の「SFA を入れる前に」は導入を前提にした言い方で、フェーズ1には製品選定と導入計画も入っている(行53、54)。診断の結論が「SFA は要らない」となる余地は、どのくらいあるのか。そのとき、行53と行54の作業分の費用はどう扱うのか。
- 倒れる場所:行14、47、53、54、66、129、157
- 要る材料:比べた案の一覧、比べた軸、選んだ理由の記録

## 4. 覆る条件

**S7. 何が出たら進まないのかを、文書は書いているか(行21、135、153、157)**
- 問い:判断の時期は書いてあるが、何が出たら止めるかがない(基準がないことは L9)。提案する側は、どの数字がどこまで下がれば、この提案が成り立たないと見ているのか。ライセンス費は行19、131の総額の外にあり、支援が終わったあとも続く費用かどうかも書かれていない。それを足した額でも、結論は変わらないのか。9か月目(行153)に入力が定着していなかったとき、引き渡しと費用はどうなるのか。
- 倒れる場所:行19、21、121、131、135、153、157
- 要る材料:候補になりうる製品の価格帯、利用人数と年数で見た利用料の概算、北都フーズがこの種の投資に求める回収年数

## 5. 利害と実行

**S8. 判断の材料を作る人と、その判断で利益を得る人が同じではないか(行54、67、130、157)**
- 問い:3か月目の判断の材料(診断報告書、効果の試算、導入計画)を作るのは、続けば1,800万円(行130)を受ける当社である。効果目標を決めるのも(行54)、結果を測るのも(行67、153)当社である。北都フーズは、行157の「率直にご報告します」のほかに、何でその内容を確かめられるのか。製品選定を支援する当社(行53)と SFA ベンダー(行62)の間に、取引上の関係はあるか。
- 倒れる場所:行21、53、54、67、121、157
- 要る材料:フェーズ1だけで終えられる契約の形、成果物を他社に渡してよいかの条件、SFA ベンダーとの取引関係の有無、試算の前提を北都フーズの側で確かめられる資料

細かいものが4件。
- 行101、103:B社は当社の支援先か。数字の出どころはどこか。SFA を入れても受注率が上がらなかった同業の例は見ているか。
- 行20、97:新人の立ち上がりを課題だと言っているのは、北都フーズの誰か(行52で調べる段階にあることは L10)。
- 行67、177〜182:支援が終わったあとの運用は、北都フーズの誰が持つのか。依頼の一覧に運用の担当はない。
- 行133:月額は9か月とも300万円である。診断の月と定着の月で、3名の稼働は同じなのか。

## 反論(仮の立場)

書き手の主張ではなく、検査のための仮の立場。採用するかは書き手が決める。

- **解決策が先にある提案だという読み**:行33は原因を、行121は金額を、これから調べると書く。それでも行14は SFA の導入まで9か月を提案している。課題の大きさも原因も分からないまま手段を決めた提案だ、という読みが成り立つ。行157の「SFA 導入よりも先に取り組むべきこと」は、その可能性を書き手自身が認めた一文とも読める。
- **問題は道具より引き継ぎのやり方にあるという読み**:行33によれば、後任者はいまも前任者の Excel と口頭の説明を受け取っている。行66は、何を残し何を確認するかを決めるとしており、これが欠けていること自体が問題だという読みが成り立つ。この読みでは、行93の効果の多くは SFA ではなく行66のルールから来ることになる。
