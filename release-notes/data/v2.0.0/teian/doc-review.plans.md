# doc-review.md の構成案

対象:北都フーズ向け「営業部門デジタル化支援のご提案」。行番号は doc-review.md のファイルの行番号。L1、S1 などは `report-logic.md` と `report-somosomo.md` の指摘の番号。2つの報告は doc.md を検査したものなので、指摘の行番号は doc-review.md の該当行に読み替え、doc-review.md で解消した指摘は数えていない。

決裁者の論点:引き継ぎの失注は、訪問記録を SFA に移せば減らせる問題で、しかも2,700万円とライセンス費に見合う大きさか。

3案とも、文書にある事実と頼む中身だけで作った。案Bと案Cは決裁事項を変えない。案Aだけは決裁事項を縮めるので、選べるのは書き手だけである。

## 案A 頼む中身を小さくする案:現状診断だけを頼む

- 主張:まず最初の3か月の現状診断をお願いします。フェーズ2へ進むかどうかは、失注の理由、件数、金額を確認してから改めてご相談します。
- 縮めた決裁事項(元の文書の言葉):「最初の3か月で現状を診断し」(行12)、「フェーズ1 現状診断|3か月|900万円」(行127)。「続く6か月で SFA(営業支援システム)の導入と、現場で使われ続ける状態になるまでの定着を支援します」(行12)と「フェーズ2 SFA 導入・定着支援|6か月|1,800万円」(行128)は今回の決裁から外す。頼む前に、「過去1〜2年の異動・退職の件数と、そのときに担当が替わった顧客の数」(行177)を先に確かめる。
- 本編の骨組み
  - 本提案の要点
  - 現状の課題
  - 経営会議の前にいただきたい数字
  - 現状診断
  - 費用
  - 体制
  - 今後の進め方
- 答える検査の問い:S1、S2、S5、S6、S7、L1
- この案を立てる理由(元の決裁事項が倒れる問い)
  - S1(行14、33、35、52、117、177):失注の金額が2,700万円とライセンス費に届かない大きさなら、行12、19、21、129 が倒れる。導入だけでなく、そのための診断も頼む理由がなくなる。
  - S2(行14、35、95):失注の主な原因が記録の場所でなければ、SFA を手段に選んだ行12と、行95の効果が立たなくなる。
  - S3(行73、75、84、87):入力が続かなければ、行20の期待効果の2つがどちらも立たない。
- 弱点:SFA の導入・定着まで含めた提案を読みたい北都フーズには先の絵が見えにくく、提案としての受注額も小さくなる。3か月分だけの契約ができるかは、文書に書かれていない。

## 案B 3か月目の判断を背骨にする(選んだ案)

- 主張:最初の3か月で失注の理由、件数、金額を確認し、診断結果をもとに導入フェーズへ進むかどうかをご判断いただける、9か月の支援を提案します。
- 本編の骨組み
  - 本提案の要点
  - 現状の課題
  - フェーズ1 現状診断
  - 3か月目の継続判断
  - フェーズ2 SFA 導入・定着支援
  - 期待効果
  - 費用
  - 体制
  - 今後の進め方
  - 付録(フェーズ2の作業、月ごとの作業、効果を測る指標、同じ規模の食品卸での事例、当社の体制)
- 答える検査の問い:S5(一部。文書の分量の多くが SFA の入れ方に使われている点を、判断を中心に組み直して答える)。S1 と S2 は、確かめる順序としては答えるが、中身の答えは出ない
- 弱点:書き手の答えがないと、どの水準なら進むかは書けない(L9、S7)。判断の材料を当社が作る点(S8)も残る。入力が続くかどうか(S3)は、3か月目の判断の材料にならない。

## 案C 定着を背骨にする

- 主張:SFA は、入れただけでは効果を見込めません。営業担当が記録を入れ続ける状態をつくる9か月の支援を提案します。
- 本編の骨組み
  - 本提案の要点
  - 現状の課題
  - 現場で使われ続けるための工夫
  - 現状診断
  - SFA 導入・定着支援
  - 期待効果
  - 費用
  - 体制
  - 今後の進め方
- 答える検査の問い:S3(一部)、S5(一部)、L8(一部)
- 弱点:行73の見込みと4つの工夫を支える記録が文書になく、定着に充てる期間も8か月目の1か月だけなので(L8)、背骨にするほどの根拠がない。行75の3名の話も、支援の終了後に入力が続くかを確かめたものではない。失注の大きさの問い(S1)にも答えない。

## 選んだ案と理由

案B を選んだ。決裁者の論点に対して文書が今言えるのは、失注の大きさも原因も未確認で、3か月目に分かるところまでである。この文書でいちばん確かな部分を背骨にできるのは案Bだけで、S1 と S2 の不確かさを隠さずに、決裁事項(9か月、総額2,700万円、3か月目の判断)をそのまま保てる。案Cは根拠の薄い部分を前に出すことになる。案Aは決裁事項を変えるので、書き手が選ぶまで本文にはしない。
