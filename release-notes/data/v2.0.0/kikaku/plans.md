# doc.md の構成案

番号の L と S は `report-logic.md` と `report-somosomo.md` の指摘の番号、「行」は doc.md の行番号です。

元の背骨は「背景 → 制度 → 効果 → 懸念 → 進め方 → まとめ」で、理由を積み上げてから、最後に承認を求める形です。未確定のこと(費用、効果の金額、VPNの利用状況)は3章と4章の後ろに分かれて出てきます。

## 案1 頼む中身を小さくする案(書き手が選ぶ案)

- 主張:就業規則の改定、接続環境の調整、一部部署での試行に、本日は着手だけを承認いただく。2027年4月から始めるかどうかは、試行の結果と費用をそろえて2月の経営会議でお諮りする
- 決裁事項の変化:本日の決裁事項を「準備として、就業規則の改定、情報システム部との接続環境の調整、一部部署での試行に着手すること」(行11)だけにする。「内勤の従業員180名を対象に、週1日の在宅勤務制度を2027年4月から始めること」(行10)は2月の最終案でお諮りする
- 骨組み
  1. 本日お諮りしたいこと(行11の着手のみ)
  2. 着手する理由
  3. 試行で確かめること
  4. 2月にお諮りすること(行10)
  5. 進め方
- 答える問い:L1、L13、S2、S9、反論2
- 元の決裁事項が倒れる問い
  - S1(行25・行27):柔軟性のなさを挙げた内勤の人が数名なら、離職の抑制を理由に4月開始を頼む筋が立たない
  - S2(行13・行80・行95):費用が効果の見込みを上回れば行10が成り立たず、金額を見てから決めて間に合うなら、本日決めることは行11だけになる
  - S3(行45〜行50):制度の形が辞めた理由と違っていれば、S1 の該当者が多くても行72の効果が立たない
- 弱点:2月に決めるなら、試行の結果を見て止める余地が日程の中に要る(反論2)。4月の開始に間に合うかは、文書の日程からは分からない

## 案2 本日言えることと言えないことを分ける案(採用)

- 主張:内勤の従業員180名を対象に、週1日の在宅勤務制度を2027年4月から始める。本日お示しできるのは現状、目的、制度の案までで、金額とふだんのVPN利用分はまだお示しできないため、試行の結果を踏まえて2月に最終案をお諮りする
- 骨組み
  1. 本日お諮りしたいこと
  2. 本日お示しできること(現状、目的、制度の案)
  3. 本日お示しできないこと(確認が必要なことの一覧)
  4. 進め方
  5. 付録(制度の設計、期待効果、懸念と対策)
- 答える問い:L1、L2、L13、L28、L29、S2、S8
- 弱点:未確定のことを前に出すので、本日承認する理由が弱く見える。S1 と S3 には本文で答えられない

## 選んだ案

案2 を選びました。頼む中身を保つのは案2と案3で、案1は書き手にしか選べません。
