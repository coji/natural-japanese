# doc-review.md の構成案

番号の L と S は `report-logic.md` と `report-somosomo.md` の指摘の番号です。2つの報告は doc.md を検査したものなので、番号はそのまま使い、「行」は doc-review.md の行番号に読み替えています。L1、L2、L9、L22〜L25、L27〜L29 は doc-review.md の時点で本文が答えているので、ここでは材料にしていません。S1 は人数までは答えが出ていて、柔軟性の中身が残っています。

元の背骨は「背景と目的 → 制度の内容 → 期待効果と費用 → 懸念と対策 → 進め方 → まとめ」で、理由を積み上げてから、最後にまとめる形です。冒頭で頼みごとは示していますが、未確定のこと(費用の総額、効果の金額、ふだんのVPN利用)は2章、3章、まとめに分かれて出てきます。

## 案1 頼む中身を小さくする案(書き手が選ぶ案)

- 主張:本日は規程と費用の準備の着手だけを承認いただく。在宅勤務制度を作る方針は、費用の総額と採用・育成コストがそろう2月の最終案で、開始日とあわせてお諮りする
- 決裁事項の変化
  - 元:「内勤の従業員180名を対象に、週1日の在宅勤務制度を作る方針を承認いただくこと(開始は 2027年4月 を目標とします)」(行10)と「規程と費用の準備を始めること。就業規則の改定、情報システム部との接続環境の調整、一部部署での試行に着手します」(行11)
  - 縮めた形:行11だけを本日の決裁事項にする。行10は2月の最終案でお諮りする
- 骨組み
  1. 本日お諮りしたいこと(行11の着手のみ)
  2. 着手の理由
  3. 2月にそろう材料
  4. 2月にお諮りすること(行10の方針と開始日)
  5. 進め方
- 答える問い:L13、S2、S9、反論2
- 元の決裁事項が倒れる問い
  - S1(行21・行27):在宅勤務に触れた退職者は4名、柔軟性を挙げた内勤は7名で、差のおよそ10名に届かない。自由記述の中身が在宅勤務の話でなければ、離職の抑制を理由に方針を頼む筋が細くなる
  - S2(行13・行84・行86):手当の年間総額と採用・育成コストが出て、費用が効果の見込みを上回れば、行10が成り立たない
  - S3(行44・行49・行76・行136・行139):週1日、部署の割り当て、上長の承認つきの制度が、辞めた人の求めていた柔軟性と違えば、行76の効果が立たない
  - L12・S6(行25・行33・行48・行64・行80):内勤の退職は180名中19名、内勤以外は70名中12名で、率の高い側が制度の対象外になる。差の多くが対象の外にあるなら、離職率を理由に方針を頼む筋が細くなる
- 弱点:方針が決まらないまま試行と規程の原案を進めることになる。2月に方針を決めて4月の目標に間に合うかは、文書の日程からは分からない
