# 在宅勤務制度（週1日）導入の企画

人事部 人事企画担当
経営会議 付議資料

---

## 本日お諮りしたいこと

1. 内勤の従業員180名を対象に、週1日の在宅勤務制度を作る方針を承認いただくこと（開始は **2027年4月** を目標とします）
2. 規程と費用の準備を始めること。就業規則の改定、情報システム部との接続環境の調整、一部部署での試行に着手します

制度の詳細（規程の条文、費用の確定額）は、本日の承認を受けて詰め、2月の経営会議で最終案としてお諮りします。開始日も、その最終案で改めて決めていただきます。

---

## 1. 背景と目的

### 現状

当社の離職率は業界平均より4ポイント高く、在宅勤務がないことは「辞める理由」の一部で、「選ばれない理由」にもなりうると考えます。

| 項目 | 当社 | 比較対象 |
|---|---|---|
| 昨年の離職率 | 12%（250名規模で31名。内勤19名、外勤など12名） | 業界平均 8%（当社の規模に当てはめると年間およそ20名） |
| 在宅勤務制度 | なし | 競合2社は週1〜2日を導入済み |
| 退職者アンケート | 回答者は22名。「働き方の柔軟性のなさ」が退職理由の上位で、挙げたのは9名（うち内勤7名）。自由記述で在宅勤務に触れたのは4名 | — |

### 目的と期待効果

在宅勤務は、退職理由のうち働き方の柔軟性に関わる部分に手を打つ施策と位置づけています。見込む効果は離職の抑制と採用力の向上で、次の指標で測ります。

| 効果 | 見込み | 測り方 |
|---|---|---|
| 離職の抑制 | 制度が退職者の求めていた柔軟性に応えられれば、柔軟性のなさを理由とした退職が減る | 離職率、退職者アンケートでの理由の順位と割合 |
| 採用力の向上 | 求人で在宅勤務の制度を示せるようになり、応募や内定承諾で見劣りしにくくなる | 応募数、内定承諾率、面接辞退の理由 |

---

## 2. 制度の内容

### 基本の設計

週1日まで、曜日は部署ごとの割り当てで始めます。日数を最初から増やさず、確実に回る形で始めることを優先します。

| 項目 | 案 |
|---|---|
| 対象者 | 内勤の従業員180名（試用期間中の者は除く） |
| 日数 | 週1日まで。翌週への繰り越しはしない |
| 曜日 | 部署ごとに割り当てる |

### 曜日の割り当て

部署ごとに在宅勤務の曜日を割り当て、**どの曜日も1日あたりの在宅勤務者が上限を大きく下回る**ようにします。本人の希望に任せると月曜や金曜に偏るおそれがあります。

情報システム部によると、VPNの同時接続は **100件が上限** です。対象の180名が週1日ずつ在宅勤務をする場合、5日に均等に分かれれば1日あたり36名で、上限を下回ります。ふだんの利用分は確認中です。

## 3. 費用

いま概算が出ている費用は、ノートPCの追加購入費の約900万円です。内勤180名のうち約60名がデスクトップPCで、1台の購入費が約15万円なので、60台すべてを買う場合の金額です。在宅勤務手当は、設ける場合は1日あたり250円を想定しています。手当の要否と年間の総額、通勤手当の扱いは、2月の最終案で示します。

## 付録

### 目的

- **離職の抑制**：柔軟性のなさを理由とした退職を減らす
- **採用力の向上**：求人で在宅勤務の制度を示せるようにし、応募や内定承諾で見劣りしないようにする

在宅勤務だけで離職率が業界平均まで下がるとは考えていません。

### 業界平均との差

業界平均との差は、人数にすると年間でおよそ10名です。このうち何名分を在宅勤務で埋められるかは、導入後の実績で確かめます。

### 効果の金額

効果を金額で示すには、退職者1名あたりの採用・育成コストが必要です。これは現在、人事部で集計中で、2月までに出ます。離職者が年に1名減るごとに、このコスト1名分の削減になります。

### 付随する効果

| 効果 | 見込み | 測り方 |
|---|---|---|
| 付随する効果 | 通勤負担が減り、育児や介護との両立がしやすくなる | 従業員アンケート |

### VPNのふだんの利用

外勤の方などがふだんからVPNを使っている場合は、その分も上限に含めて考える必要があります。現在の利用状況は情報システム部に確認中です。

### 公平性への配慮

対象外となる70名（内勤以外の従業員）には、業務の性質上、在宅勤務が難しい職種であることを丁寧に説明するとともに、対象外の職種に向けた施策（たとえば時差出勤や休暇の取りやすさの改善）を、別途検討することを提案します。不公平だという声が出る可能性があるためです。

### 開始までの手続きと開始後の見直し

| 時期 | 内容 |
|---|---|
| 2027年2月〜3月 | 従業員代表への意見聴取、労働基準監督署への届出。管理職向け説明会、全従業員向け説明会 |
| 2027年10月 | 半年の時点で、利用状況・離職率・採用の指標を経営会議に報告し、日数などの見直しを判断 |

当社はまず週1日から始め、運用が安定したら日数の見直しを検討します。

就業規則の改定が必要です。在宅勤務規程を新設し、就業規則に位置づけます。社会保険労務士に条文を確認してもらい、従業員代表の意見を聴いたうえで、労働基準監督署に届け出ます。

試行期間中の扱い（暫定的なルールが必要かどうか）は、社会保険労務士に確認したうえで決めます。

### 制度の運用

| 項目 | 案 |
|---|---|
| 申請 | 前週までに上長へ申請し、上長が承認する |
| 勤務時間 | 通常の勤務時間と同じ。始業・終業は勤怠システムで打刻する |
| 勤務場所 | 自宅に限る（カフェ等は情報管理の観点から認めない） |
| 業務上の必要 | 会議や来客などで出社が必要な日は、上長が日を変更できる |

### 懸念ごとの対策

| 懸念 | 対策 |
|---|---|
| VPNの同時接続数の上限（100） | 部署ごとに曜日を割り当て、1日あたりの在宅勤務者が上限を大きく下回るように保つ。試行期間中に、実際の接続数の最大値を測る |
| 対象外の従業員の不公平感 | 上の「公平性への配慮」のとおり、説明と別施策の検討で対応する |
| 労働時間の管理 | 勤怠システムでの打刻を必須とする。在宅勤務日の時間外労働は事前申請制にする |
| 情報セキュリティ | 会社貸与のPCのみ使用可とし、VPN経由で接続する。紙の書類の持ち出しは原則禁止とする。運用ルールは情報システム部と作る |
| 業務の滞りやコミュニケーションの低下 | 在宅勤務日でも連絡がつく手段（チャット、オンライン会議）を決めておく。部署ごとに、在宅でできる業務とできない業務を整理する |
| 評価への不安 | 在宅勤務の利用の有無を評価に影響させないことを、規程と管理職向けの説明で明確にする |
