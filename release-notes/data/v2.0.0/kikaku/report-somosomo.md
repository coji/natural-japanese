# doc.md の somosomo 検査

## 文書の性格

決めてもらう文書。人事部が経営会議に、内勤180名を対象にした週1日の在宅勤務制度の導入と、その準備への着手を諮る企画です。

## 主結論

内勤の従業員180名を対象に、週1日の在宅勤務制度を2027年4月から始める。本日は方針の承認を受け、試行の結果を踏まえて2月に最終案を諮る。

書き手の意図とずれていそうな点が1つあります。行10は4月開始そのものの承認を求め、行128は「方針の承認」と書いています。この検査では、行10の文を決裁事項として読みました。

## 決裁者の論点

費用の額がまだ分からない今の時点で、週1日の在宅勤務が当社の離職と採用の問題に効くと見て、2027年4月の開始を決めてよいか。

## 指摘

番号の S は指摘の番号で、「行」は doc.md の行番号です。

### 決裁事項を倒しうる問い

**S1. 行25・行27:「柔軟性のなさ」で辞めた内勤の人は何名いて、在宅勤務があれば辞めなかったのですか**

- 問い:行27は、退職者アンケートの「働き方の柔軟性のなさ」を「在宅勤務がないこと」と読み替えています。昨年の退職者およそ30名のうち、この理由を挙げた人は何名で、そのうち制度の対象になる内勤は何名ですか。その人たちは在宅勤務のことを言っていましたか。行80は「導入後の実績で確かめます」としていますが、行25で引いているアンケートから導入の前に確かめられる分は、確かめましたか。
- どう倒れるか:該当する人が数名なら、年間およそ10名の差に対して手を打てる幅が小さく、離職の抑制を理由に4月開始を頼む筋が立ちません。
- 倒れる場所:行10、行27、行31、行72、行80、行125
- 要る材料:昨年の退職者アンケートの内訳(回答者数、理由別の人数、内勤と内勤以外の別)、「柔軟性」の中身が分かる自由記述か退職面談の記録

**S2. 行13・行80・行95:費用も効果も金額がないまま、4月開始を本日決める必要がありますか**

- 問い:行10は開始の承認を求めていますが、費用の確定額は2月(行13、行95)、効果は X 円のまま(行80)で、経営会議が比べられる金額が本日の文書にありません。費用はおよそどの桁で、差の10名を全部埋めたとしても効果の金額で足りますか。どの金額を超えたら2月に引き返しますか。行78の採用・育成コスト、行99のノートPCの不足数、行100のVPNの利用状況、行101の手当の総額は、社内で確かめられることに見えます。本日の決裁の前に出さなかった理由は何ですか。金額を見る前に決めないと間に合わないのは、行10と行11のどちらですか。
- どう倒れるか:費用が効果の見込みを上回れば、行10の「4月から始める」が成り立ちません。金額を見てから決めても間に合うなら、本日決めることは行11の準備の着手だけになります。
- 倒れる場所:行10、行13、行95、行111、行128
- 要る材料:費用の概算(ノートPCの不足数と単価、手当の案ごとの年間総額、通勤手当の扱いによる増減)、退職者1名あたりの採用・育成コストの集計、4月開始から逆算した各工程の締め切り

**S3. 行45〜行50:週1日・割り当て・上長の承認つきの制度は、辞めた人が求めていた柔軟性ですか**

- 問い:制度は週1日まで、曜日は部署の割り当て、前週までに上長の承認、上長が日を変更できる、という形です(行45〜行50)。辞めた人が求めていたのは、日を自分で選べることですか、働く場所ですか、時間ですか。この制度があれば、その人たちは辞めなかったと言えますか。行74の育児や介護との両立は、週1回の決まった曜日で足りますか。
- どう倒れるか:制度の形が辞めた理由と違っていれば、S1 の該当者が多くても離職は減らず、行72の効果と主結論の理由が立ちません。
- 倒れる場所:行31、行34、行52、行72、行74
- 要る材料:退職者の自由記述か退職面談の記録、在職者の希望の調査(日数、選び方)、同じ程度の制度を入れた会社の導入後の離職率の変化

## 反論(仮の立場)

以下は書き手の主張ではなく、検査のための仮の立場です。採用するかどうかは書き手が決めます。

**反論1. 行25・行27・行34**:「柔軟性のなさ」は辞めるときに言いやすい理由で、本当の理由は別にある、という読みが成り立ちます。行25の根拠は辞めた人の答えだけで、辞めなかった人と比べていません。行34が「在宅勤務だけでは下がらない」と先に断っていることも、在宅勤務が離職の本体に届いていないことを書き手が知っている、と読めます。

**反論2. 行111〜行116**:本日の承認は「方針」と書かれていますが、実質は4月開始の決定だ、という読みが成り立ちます。試行は1月〜2月、最終案の付議は2月、その直後から意見聴取と説明会が続き、4月に全社で始まる日程で、行113の試行の結果を見て止める余地が日程の中に見当たりません。2月の経営会議は、試行の結果で決める場ではなく、すでに動いている準備を追認する場になる、と読めます。
