# 確認事項:doc.review.md

## 出す前にやること

1. **柔軟性のなさを挙げた内勤7名の中身を読む。** 昨年の退職者アンケートで内勤の7名が書いた内容を見て、週1日の在宅勤務があれば辞めなかったと読める人が何名かを数える。答えが出たら、1章の現状の「理由と考えています」の文に、その人数を書く。少なければ、同じ節の最初の文の「辞める理由」を書き直す。
2. **退職者1名あたりの採用・育成コストを出す。** 人事部の集計を見る。書き手の答えでは2月までに出る見込みなので、付議の前に間に合うかを先に確かめる。答えが出たら、3章の「X 円」を金額に置き換え、4章の約900万円が離職者の何名分に当たるかを書く。
3. **外勤の方などのいまのVPN同時接続を聞き出す。** 情報システム部に、多い日の同時接続の件数を聞く。答えが出たら、2章の曜日の割り当ての「なお」の文を件数の文に書き換え、まとめの「利用が大きくない限り」の条件を外す。
4. **部署ごとの内勤の人数を出す。** 人事部の人員の記録を見て、部署ごとに曜日を割り当てる。答えが出たら、2章の「均等に分かれれば1日あたり36名」のあとに、在宅勤務者がいちばん多い曜日の人数を書き、3の件数と足して100件に対する余りを書く。
5. **在宅勤務手当の年間の総額を計算する。** 1日あたり250円に、対象の人数と年間の利用日数を掛ける。答えが出たら、4章の手当の文のあとに総額を書く。

## 頼む中身を小さくする案

本日は準備として「就業規則の改定、情報システム部との接続環境の調整、一部部署での試行に着手すること」だけをお諮りし、「2027年4月から始める」ことは、試行の結果と費用が出る2月の最終案でお諮りする。

## 先に答える問い

本文を仮の形にとどめた問い(コスト、VPN、部署ごとの人数、手当の総額)は、上の「出す前にやること」に書いた。ここには、聞かなかった問いのうち書き手の判断が要るものを書く。

1. 本日の承認で4月の開始まで決まるのか。2月の最終案で止める、または延ばす余地はあるのか。本文は「方針」の承認に揃えたが、どこまで決まるかは書いていない。2月の最終案が修正や持ち越しになったとき、2〜3月の意見聴取と届出、説明会は4月に間に合うのか。
2. 試行でどんな結果が出たら、4月の開始を止める、または遅らせるのか。VPN、業務への影響、利用者の声のそれぞれの線はどこか。
3. 離職率と採用の指標がいくつになれば成功で、いくつなら見直すのか。基準となる値と目標はいくつか。半年の時点で年間の離職率の変化は読めるのか。2027年10月の見直しは日数の話で、縮小や取りやめも含むのか。

## そのほか

- 内勤の7名のほかに、柔軟性のなさを挙げた外勤などの2名と、アンケートに回答しなかった9名は、どう読むのか。
- 業界平均との差のおよそ10名は全社の数字で、施策の対象は内勤180名だ。差のうち内勤の分は何名か。
- 差のおよそ10名は12%と8%の差から出した数で、退職者31名から20名を引くと11名になる。本文はおよそ10名のままにしたが、これでよいか。
- 何名分を在宅勤務で埋められるかは導入後の実績で確かめるとしているが、それでも費用に見合うと判断してよいのか。
- 180名は、試用期間中の者を除いたあとの数か、前の数か。前の数なら、除かれる人は対象外の70名とは別に何名いるのか。
- 競合に在宅勤務があることは、当社の応募や内定承諾を実際に下げているのか。「見劣りしている」は何の測定から来ているのか。
- 曜日が部署で決まり、前週に申請し、上長が日を変えられる制度は、競合の週1〜2日と求人の上で同じと言えるのか。週2日の競合がある場合はどうか。本文は「在宅勤務制度があると示せる」に改めた。
- 業界平均8%と競合2社の制度は、何を出どころにした数字か。業界平均は、当社と同じ規模と職種構成との比較と言えるのか。競合2社の週1〜2日は、1社ずつの日数か、2社とも週1〜2日か。
- 退職理由の内訳、1名あたりのコスト、VPNの利用状況は社内で集められる材料に見える。11月に諮らなければならない理由は何か。
- 決裁者が決めたいのは「在宅勤務を入れるか」か、「離職率の4ポイントの差をどう縮めるか」か。後者の中で在宅勤務はどれだけを担うのか。柔軟性以外の退職理由への対応はあるのか。
- 何もしない案、範囲を変える案、試行の結果を見てから開始を諮る案とは比べたか。時差出勤や休暇の取りやすさの改善は、内勤の柔軟性の問題にも当たるのか。
- ノートPCは、約60名の全員分を買う前提でよいか。
- 対象外の職種に向けた施策の検討は、本日の付議事項に入れるのか。本文は「提案します」を、懸念と対策の表の「別施策の検討で対応する」に合わせて「別途検討します」にした。誰がいつまでに検討するのか。
- 対象外の70名の不公平感が対象外の離職として出たとき、全社の離職率はどう読むのか。
- 試行が規程も暫定ルールも未定のまま始まる順番でよいか。試行は2月まで続くが、2月の経営会議に出す試行の結果はどの時点までのものか。
- 30名程度の試行で測る接続数の最大値から、180名に広げたときの最大値が言えるのか。
- 曜日を部署ごとに割り当てるのに、前週までに何を申請するのか。上長が日を変えたとき、変更先が割り当て外の曜日になっても「どの曜日も」は保たれるのか。
- 曜日の割り当て、部署ごとの業務の整理、申請の承認、日の変更は、誰がやるのか。上長が日を変えられるとき、利用率が低い部署が出ても制度の効果として測れるのか。
- 「運用が安定したら」「確実に回る形」は、何をもって判断するのか。
- 試用期間中の者を除くことは、採用の条件として見たときにどう説明するのか。
- 2027年10月の報告で、人事部が自部門の施策を自部門の数字で評価することを、経営会議はどう受け取るのか。
- 「就業規則の改定」「在宅勤務規程を新設」「規程の原案」は同じものを指すか。「外勤の方など」と「内勤以外の従業員」は同じ人たちか。
