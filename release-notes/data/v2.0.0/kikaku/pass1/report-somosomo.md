# somosomo の検査報告:doc.md

**文書の性格**:決めてもらう文書。人事部の人事企画担当が経営会議に、在宅勤務制度の開始と準備への着手を諮る。

**主結論**:内勤の従業員180名を対象に、週1日の在宅勤務制度を2027年4月から始める。本日は方針の承認を求め、試行の結果を踏まえて2月に最終案を諮る。

**決裁者の論点**:週1日の在宅勤務は、費用に見合うだけ離職と採用に効き、VPNの上限の中で4月に始められるのか。

以下の S1 などの番号は検査の作業用。

## 決裁事項を倒しうる問い

### S1 柔軟性を理由に辞めた人は、在宅勤務で防げた人か

- **問い**:昨年の退職者およそ30名のうち、「働き方の柔軟性のなさ」を挙げた人は何名で、そのうち在宅勤務の対象になる内勤の人は何名か。その人たちの言う柔軟性は、週1日の在宅勤務で解消するものか。
- **倒れる場所**:行27、行31、行72、行80、行125
- **要る材料**:昨年の退職者アンケートの回答数、理由別の件数、内勤と外勤の別、自由記述
- **どう倒れるか**:該当者が数名なら、目的の第一である離職の抑制が決裁の理由にならない。

### S2 効果の金額は、費用を上回るのか

- **問い**:退職者1名あたりの採用・育成コストと、PC、在宅勤務手当、社会保険労務士などの費用を突き合わせたとき、離職者が年に何名減れば費用を回収できるか。その人数は、在宅勤務で埋められそうな人数の範囲に入るのか。
- **倒れる場所**:行13、行78、行80、行95、行99、行101
- **要る材料**:1名あたりのコストの集計、ノートPCを持っていない人数と単価、手当の案、そのほかの導入費用の見積り
- **どう倒れるか**:費用を回収できる人数が年間およそ10名の差を超えるなら、4月に始める理由が金額では立たない。本日の承認も、費用の上限がないまま準備に着手する形になる。

### S3 外勤の方などの利用を足しても、VPNの上限に収まるのか

- **問い**:外勤の方などのふだんの同時接続に、曜日を割り当てたあとで最も多い曜日の在宅勤務者を足すと、100件に対してどれだけ余るか。行60の分が大きいとき、文書のどこまでが成り立つのか。
- **倒れる場所**:行56、行58、行60、行88、行100、行127
- **要る材料**:VPNの曜日別・時間帯別の同時接続の記録、部署別の内勤の人数
- **どう倒れるか**:上限を超えるなら、「週1日・曜日の割り当て制で始めれば収まる」という設計の前提が倒れ、4月の開始と費用の両方が変わる。

## 前提

- **S4 問い**:競合に在宅勤務があることは、当社の応募や内定承諾を実際に下げているのか。**倒れる場所**:行27、行32、行73、行126。**要る材料**:応募数と内定承諾率の推移、面接辞退の理由の記録。
- **S5 問い**:業界平均8%は、当社と同じ規模、同じ職種構成との比較と言えるのか。**倒れる場所**:行23、行27、行125。**要る材料**:業界平均の出どころと集計の範囲、内勤と外勤に分けた当社の離職率。

## 問いそのもの

- **S6 問い**:退職理由の内訳、1名あたりのコスト、VPNの利用状況、PCの台数は、どれも社内で集められる材料に見える。これらを見ずに開始を承認してもらう形になっていないか。確かめてから頼めることを、頼んでから確かめる形になっていないか。**倒れる場所**:行13、行60、行78、行97〜101。**要る材料**:それぞれの集計にかかる時間の見込み、11月に諮らなければならない理由。
- **S7 問い**:決裁者が決めたいのは「在宅勤務を入れるか」か、「離職率の4ポイントの差をどう縮めるか」か。文書は前者に答えているが、後者の中で在宅勤務がどれだけを担うかを書いていない。**倒れる場所**:行27、行34、行80。**要る材料**:退職理由の全体の内訳、柔軟性以外の理由への対応の有無。

## 他の選択肢

- **S8 問い**:文書が比べている案は、週2日で始める案(行52)と曜日を本人に任せる案(行58)で、どちらも在宅勤務の中での比較になっている。何もしない案、範囲を変える案、試行の結果を見てから開始を諮る案とは比べたか。行64の時差出勤や休暇の取りやすさの改善は、内勤の柔軟性の問題にも当たるのか。**倒れる場所**:行10、行52、行64。**要る材料**:比べた記録、比べた軸。

## 覆る条件

- **S9 問い**:試行でどんな結果が出たら、4月の開始を止める、または遅らせるのか。文書は判断の基準を書いているか。**倒れる場所**:行10、行113、行114、行116。**要る材料**:VPN、業務への影響、利用者の声のそれぞれの合否の線。
- **S10 問い**:離職率と採用の指標が、いくつになれば成功で、いくつなら見直すのか。半年の時点で、年間の離職率の変化は読めるのか。行52と行117の見直しは日数の話で、縮小や取りやめは含むのか。**倒れる場所**:行72、行73、行117。**要る材料**:導入前の基準値、目標値、見直しの条件。
- **S11 問い**:2月の最終案が修正になったり持ち越しになったりしたとき、2〜3月の意見聴取と届出、説明会は4月に間に合うのか。制約の「2027年4月」を動かす条件はあるのか。**倒れる場所**:行10、行114、行115、行116。**要る材料**:手続きに要る日数、最終案が通らなかった場合の日程。

## 利害と実行

- **S12 問い**:対象外の70名の不公平感が、対象外の離職として出たとき、全社の離職率はどう読むのか。別施策の検討は、誰がいつまでに行うのか。**倒れる場所**:行64、行94。**要る材料**:対象外の職種の離職の状況、検討の担当と時期。
- **S13 問い**:曜日の割り当て、部署ごとの業務の整理、申請の承認、日の変更は、誰がやるのか。部署の管理職は、この文書を読んで自分の仕事だと分かるか。上長が日を変えられるとき、利用率が低い部署が出ても制度の効果として測れるのか。**倒れる場所**:行46、行47、行50、行92。**要る材料**:管理職の役割の整理、部署別の業務の見立て。

細かいものが2件ある。行44の試用期間中の除外は、採用の条件として見たときにどう説明するのか(行32)。行117の報告で、人事部が自部門の施策を自部門の数字で評価することを、経営会議はどう受け取るのか。

## 反論(仮の立場)

- **反論1**:行25の「柔軟性のなさ」は勤務時間や異動なども含む広い言葉で、在宅勤務がないことは行27が書くほど大きな理由ではない、という読みが成り立つ。行34で書き手自身が、業界平均までは下がらないと書いている。
- **反論2**:曜日が部署で決まり(行46)、前週に申請し(行47)、上長が日を変えられる(行50)制度は、行24の競合の週1〜2日と求人の上で並ぶとは言えない、という読みが成り立つ。
