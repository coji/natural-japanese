## 案A 頼む中身を小さくする案

- **主張**:本日は準備と試行への着手だけをお諮りし、2027年4月から始めることは、試行の結果と費用が出る2月の最終案でお諮りする。
- **決裁事項の変更**:元の決裁事項は「内勤の従業員180名を対象に、週1日の在宅勤務制度を 2027年4月から 始めること」と「準備として、就業規則の改定、情報システム部との接続環境の調整、一部部署での試行に着手すること」の2つ(行10、行11)。この案で頼むのは後者だけにする。
- **本編の骨組み**:本日お諮りしたいこと / 現状 / 試行で確認すること / 2月にお諮りすること / 費用 / 進め方
- **答える問い**:S1、S2、S3、S6、S9、L2
- **元の決裁事項が倒れる問い**:S1(行27、行31、行72、行80、行125)。内勤で柔軟性のなさを挙げた退職者は7名で、週1日の在宅勤務で防げた人がその一部なら、離職の抑制は決裁の理由にならない。S2(行13、行78、行80、行95、行99、行101)。回収に要る人数が差のおよそ10名を超えるなら、金額では開始の理由が立たない。S3(行56、行58、行60、行88、行100、行127)。外勤の方などの利用を足して上限を超えるなら、開始と費用の両方が変わる。
- **先に見る答え**:S2 の退職者1名あたりのコスト。約900万円と突き合わせられるので、ここが出れば開始まで頼むかどうかを決められる。
- **弱点**:4月に間に合わせるための2〜3月の手続きが、2月の判断のあとに詰まる(S11)。
