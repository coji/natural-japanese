# 在宅勤務制度（週1日）導入の企画

人事部 人事企画担当
経営会議 付議資料

---

## 本日お諮りしたいこと

1. 内勤の従業員180名を対象に、週1日の在宅勤務制度を **2027年4月から** 始めること
2. 準備として、就業規則の改定、情報システム部との接続環境の調整、一部部署での試行に着手すること

本日の承認を、4月開始の決定とするか方針の承認とするかは確認中です。制度の詳細（規程の条文、費用の確定額）は、本日の承認を受けて詰め、試行の結果を踏まえて2月の経営会議で最終案としてお諮りします。

---

## 本日お示しできること

### 現状

当社の離職率は業界平均より4ポイント高い水準です。退職者アンケートで「働き方の柔軟性のなさ」が退職理由の上位にあること、競合2社がすでに制度を持っていることから、在宅勤務がないことは「辞める理由」と「選ばれない理由」の両方になっていると考えます。

| 項目 | 当社 | 比較対象 |
|---|---|---|
| 昨年の離職率 | 12%（250名規模で年間およそ30名） | 業界平均 8%（当社の規模に当てはめると年間およそ20名） |
| 在宅勤務制度 | なし | 競合2社は週1〜2日を導入済み |
| 退職者アンケート | 「働き方の柔軟性のなさ」が退職理由の上位 | — |

業界平均との差は、人数にすると年間でおよそ10名です。離職率もこの差も250名全体の数字で、制度の対象は内勤の180名です。

### 目的

目的は離職の抑制と採用力の向上の2つです。

- 離職の抑制：柔軟性のなさを理由とした退職を減らす
- 採用力の向上：求人で在宅勤務制度があることを示せるようにし、応募や内定承諾で見劣りしないようにする

在宅勤務だけで離職率が業界平均まで下がるとは考えていません。退職理由のうち、働き方の柔軟性に関わる部分に手を打つ施策と位置づけています。業界平均との差（年間およそ10名）のうち、何名分を在宅勤務で埋められるかは、導入後の実績で確かめます。

### 制度の案

週1日までの制度を、部署ごとに曜日を割り当てて始めます。対象者は内勤の従業員180名（試用期間中の者は除く）で、翌週への繰り越しはしません。

競合2社は週1〜2日です。当社はまず週1日から始め、運用が安定したら日数の見直しを検討します。最初から日数を大きくせず、確実に回る形で始めることを優先します。

曜日を割り当てるのは、情報システム部によるとVPNの同時接続は **100件が上限** だからです。180名が週1日ずつ在宅勤務をする場合、5日に均等に分かれれば1日あたり36名ですが、本人の希望に任せると月曜や金曜に偏るおそれがあります。そのため、どの曜日も1日あたりの在宅勤務者が上限を大きく下回るようにします。

対象外となる70名（内勤以外の従業員）からは、不公平だという声が出る可能性があります。説明と別施策の検討で対応します（付録C）。

## 本日お示しできないこと

費用の額と効果の額は、本日の資料にはありません。費用の確定額は2月の最終案でお示しするため、本日は金額を見ずにご判断いただくことになります。確認が必要なことは次のとおりです。

| 確認が必要なこと | いまの状況 |
|---|---|
| 退職者1名あたりの採用・育成コスト | 人事部で集計中。効果を金額で示すのに必要で、仮に1名あたり X 円とすると、離職者が年に1名減るごとに X 円の削減 |
| 内勤180名のうち、持ち出せるPC（ノートPC）を持っていない人の数と、追加購入の費用 | 未確認 |
| 通信費・光熱費の補助（在宅勤務手当）の要否、設ける場合の金額と年間の総額、通勤手当の扱い | 金額は2月の最終案で示す |
| 外勤の方などによる、現在のVPNの利用状況 | 情報システム部に確認中。ふだんの利用分も上限に含めて考える必要がある |
| 実際の接続数の最大値、業務への影響、利用者の声 | 試行で確認する |
| 試行期間中の扱い（暫定的なルールが必要かどうか） | 社会保険労務士に確認したうえで決める |

週1日・曜日の割り当て制でVPNの上限の範囲内に収まるかは、外勤の方などの利用状況が分かるまで、見込みにとどまります。

## 進め方

試行の結果を受けて、2月に最終案を経営会議に付議します。2027年4月の開始に向けた予定は次のとおりです。

| 時期 | 内容 |
|---|---|
| 2026年11月 | 経営会議で方針を承認（本日） |
| 2026年11月〜12月 | 規程の原案を作成。情報システム部とVPN・PC・セキュリティのルールを調整。社会保険労務士に相談 |
| 2027年1月〜2月 | 1〜2部署（30名程度）で試行。VPNの接続数、業務への影響、利用者の声を確認 |
| 2027年2月 | 試行の結果を受けて最終案を経営会議に付議（規程・費用・運用ルール） |
| 2027年2月〜3月 | 従業員代表への意見聴取、労働基準監督署への届出。管理職向け説明会、全従業員向け説明会 |
| 2027年4月 | 全社（内勤180名）で開始 |
| 2027年10月 | 半年の時点で、利用状況・離職率・採用の指標を経営会議に報告し、日数などの見直しを判断 |

## 付録A 制度の設計

| 項目 | 案 |
|---|---|
| 対象者 | 内勤の従業員180名（試用期間中の者は除く） |
| 日数 | 週1日まで。翌週への繰り越しはしない |
| 曜日 | 部署ごとに割り当てる |
| 申請 | 前週までに上長へ申請し、上長が承認する |
| 勤務時間 | 通常の勤務時間と同じ。始業・終業は勤怠システムで打刻する |
| 勤務場所 | 自宅に限る（カフェ等は情報管理の観点から認めない） |
| 業務上の必要 | 会議や来客などで出社が必要な日は、上長が日を変更できる |

## 付録B 期待効果

| 効果 | 内容 | 測り方 |
|---|---|---|
| 離職の抑制 | 柔軟性のなさを理由とした退職が減る見込み | 離職率、退職者アンケートでの理由の順位と割合 |
| 採用力の向上 | 応募や内定承諾で見劣りしなくなる見込み | 応募数、内定承諾率、面接辞退の理由 |
| 定着と満足度 | 通勤負担が減り、育児や介護との両立がしやすくなる見込み | 従業員アンケート |

## 付録C 懸念と対策

| 懸念 | 対策 |
|---|---|
| VPNの同時接続数の上限（100） | 部署ごとに曜日を割り当て、1日あたりの在宅勤務者が上限を大きく下回るようにする。試行期間中に、実際の接続数の最大値を測る |
| 労働時間の管理 | 勤怠システムでの打刻を必須とする。在宅勤務日の時間外労働は事前申請制にする |
| 情報セキュリティ | 会社貸与のPCのみ使用可とし、VPN経由で接続する。紙の書類の持ち出しは原則禁止とする。運用ルールは情報システム部と作る |
| 業務の滞りやコミュニケーションの低下 | 在宅勤務日でも連絡がつく手段（チャット、オンライン会議）を決めておく。部署ごとに、在宅でできる業務とできない業務を整理する |
| 評価への不安 | 在宅勤務の利用の有無を評価に影響させないことを、規程と管理職向けの説明で明確にする |
| 対象外の従業員の不公平感 | 業務の性質上、在宅勤務が難しい職種であることを丁寧に説明するとともに、対象外の職種に向けた施策（たとえば時差出勤や休暇の取りやすさの改善）を、別途検討することを提案する |

就業規則の改定も必要です。在宅勤務規程を新設し、就業規則に位置づけます。従業員代表の意見を聴いたうえで、労働基準監督署に届け出ます。社会保険労務士に条文を確認してもらいます。
