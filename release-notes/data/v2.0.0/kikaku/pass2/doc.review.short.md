# 在宅勤務制度（週1日）導入の企画

人事部 人事企画担当
経営会議 付議資料

---

## 本日お諮りしたいこと

1. 内勤の従業員180名を対象に、週1日の在宅勤務制度を **2027年4月から** 始めること
2. 準備として、就業規則の改定、情報システム部との接続環境の調整、一部部署での試行に着手すること

規程の条文や費用の確定額といった制度の詳細は、本日の承認を受けて詰め、2月の経営会議で最終案としてお諮りします。費用は、ノートPCの購入に約570万円、在宅勤務手当を設ける場合に年間約216万円を見込んでいます。

---

## 1. 背景と目的

在宅勤務がないことは、退職者の一部にとって「辞める理由」になっており、「選ばれない理由」にもなっていると考えます。当社に在宅勤務制度はなく、競合2社は週1〜2日を導入済みです。

退職者アンケートでは、回答した22名のうち9名が「働き方の柔軟性のなさ」を挙げ、退職理由の2位でした。1位は給与の11名です。

9名のうち5名は、通院や送り迎えのための在宅のように、週1日の在宅勤務で応えられる中身を書いていて、そのうち内勤は4名です。残りの4名は時短や時差出勤を求めていて、在宅勤務では応えられません。

## 2. 制度の内容

対象者は内勤の従業員180名で、試用期間中の者は除きます。週1日までで翌週への繰り越しはせず、曜日は部署ごとに割り当てます。

部署ごとに曜日を割り当てれば、VPNの同時接続は、いちばん多い曜日でも上限の100件に収まります。在宅勤務者がいちばん多い曜日は、2部署が重なる水曜の44名です。外勤など内勤以外のふだんの同時接続は最大で約40件なので、足すと84件で、上限に対して16件の余りがあります。

## 3. 期待効果

| 効果 | 内容 | 測り方 |
|---|---|---|
| 離職の抑制 | 柔軟性のなさを理由とした退職が減る | 離職率、退職者アンケートでの理由の順位と割合 |
| 採用力の向上 | 求人で在宅勤務制度があると示せる | 応募数、内定承諾率、面接辞退の理由 |

ノートPCの購入と手当の1年分を合わせた費用は約786万円で、離職者およそ4.4名分です。退職者1名あたりの採用・育成コストは約180万円で、採用費と教育期間の人件費を合わせた内勤の平均です。離職者が年に1名減るごとに約180万円の削減になります。

ノートPCを持っていないデスクトップPCの人は、内勤180名のうち約60名です。60台すべては買わず、まず希望者に限って配ります。在宅勤務を希望すると答えた112名のうちデスクトップの人は38名なので、1台約15万円で38台、約570万円です。離職者およそ3.2名分にあたります。

在宅勤務手当は、設ける場合は1日あたり250円を想定しています。180名全員が48週使う計算で年間約216万円、離職者およそ1.2名分です。

## 4. 懸念と対策

就業規則の改定が必要です。在宅勤務規程を新設し、就業規則に位置づけます。従業員代表の意見を聴いたうえで、労働基準監督署に届け出ます。社会保険労務士に条文を確認してもらいます。

費用は、在宅勤務手当として通信費・光熱費を補助するかどうかと、通勤手当の扱いを決めます。確定額は2月の最終案で示します。

## 5. 進め方

| 時期 | 内容 |
|---|---|
| 2026年11月 | 本日の経営会議で方針を承認 |
| 2027年1月〜2月 | 1〜2部署の30名程度で試行。VPNの接続数、業務への影響、利用者の声を確認 |
| 2027年2月 | 試行の結果を受けて、規程・費用・運用ルールの最終案を経営会議に付議 |

## まとめ

- 当社の離職率は業界平均より4ポイント高く、退職理由では給与に次いで働き方の柔軟性のなさが挙がっています
- 競合はすでに在宅勤務を導入しており、採用でも見劣りしていると考えます
- 週1日・曜日の割り当て制で始めれば、VPNはいちばん多い曜日でも84件で、上限の100件に収まります
- 費用はノートPCの約570万円と、手当を設ける場合の年間約216万円で、合わせて離職者およそ4.4名分です
- 本日は方針の承認をいただき、試行の結果を踏まえて2月に最終案をお諮りします

## 付録A 背景の数字と目的

| 項目 | 当社 | 比較対象 |
|---|---|---|
| 昨年の離職率 | 12%。250名規模で、退職者は31名 | 業界平均 8%。当社の規模に当てはめると年間およそ20名 |

業界平均との差は、人数にすると年間でおよそ10名です。昨年の退職者31名のうち、内勤は19名、外勤などは12名でした。柔軟性のなさを挙げた9名のうち内勤は7名です。

目的は次の2つです。

- **離職の抑制**：柔軟性のなさを理由とした退職を減らす
- **採用力の向上**：求人で競合と同じく在宅勤務制度があると示せるようにし、応募や内定承諾で見劣りしないようにする

在宅勤務だけで離職率が業界平均まで下がるとは考えていません。退職理由のうち、働き方の柔軟性に関わる部分に手を打つ施策と位置づけています。

## 付録B 制度の内容の残り

| 項目 | 案 |
|---|---|
| 勤務場所 | 自宅に限る。カフェ等は情報管理の観点から認めない |
| 申請 | 前週までに上長へ申請し、上長が承認する |
| 勤務時間 | 通常の勤務時間と同じ。始業・終業は勤怠システムで打刻する |
| 業務上の必要 | 会議や来客などで出社が必要な日は、上長が日を変更できる |

競合は週1〜2日です。当社はまず週1日から始め、運用が安定したら日数の見直しを検討します。最初から大きく始めず、確実に回る形で始めることを優先します。

対象の180名が週1日ずつ在宅勤務をする場合、5日に均等に分かれれば1日あたり36名です。ただし、本人の希望に任せると月曜や金曜に偏るおそれがあります。そのため、内勤の8部署それぞれに在宅勤務の曜日を割り当てます。

内勤以外の従業員70名は対象外になるので、不公平だという声が出る可能性があります。業務の性質上、在宅勤務が難しい職種であることを丁寧に説明するとともに、時差出勤や休暇の取りやすさの改善のような、対象外の職種に向けた施策を別途検討します。

## 付録C 効果と費用の残り

| 効果 | 内容 | 測り方 |
|---|---|---|
| 定着と満足度 | 通勤負担が減り、育児や介護との両立がしやすくなる | 従業員アンケート |

業界平均との差のおよそ10名のうち、何名分を在宅勤務で埋められるかは、導入後の実績で確かめます。

在宅勤務手当の年間約216万円は、1日250円、180名、週1日、48週を掛けた値です。48週は、人事部の勤怠の記録で年間の所定労働週数として使っている値です。

## 付録D 懸念と対策の残り

| 懸念 | 対策 |
|---|---|
| **VPNの同時接続数の上限100件** | 部署ごとに曜日を割り当て、上限を超えないように保つ。試行期間中に、実際の接続数の最大値を測る |
| **労働時間の管理** | 勤怠システムでの打刻を必須とする。在宅勤務日の時間外労働は事前申請制にする |
| **情報セキュリティ** | 会社貸与のPCのみ使用可とし、VPN経由で接続する。紙の書類の持ち出しは原則禁止とする。運用ルールは情報システム部と作る |
| **業務の滞りやコミュニケーションの低下** | 在宅勤務日でも連絡がつく手段として、チャットとオンライン会議を決めておく。部署ごとに、在宅でできる業務とできない業務を整理する |
| **評価への不安** | 在宅勤務の利用の有無を評価に影響させないことを、規程と管理職向けの説明で明確にする |
| **対象外の従業員の不公平感** | 付録Bのとおり、説明と別施策の検討で対応する |

## 付録E 進め方の残り

| 時期 | 内容 |

| 2027年2月〜3月 | 従業員代表への意見聴取、労働基準監督署への届出。管理職向け説明会、全従業員向け説明会 |

試行期間中に暫定的なルールが必要かどうかは、社会保険労務士に確認したうえで決めます。
