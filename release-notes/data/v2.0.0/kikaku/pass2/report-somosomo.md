# somosomo の検査報告:doc.md

同じ文書を2回検査すると、指摘の数や言い方は揺れます。

**文書の性格:** 経営会議に、内勤180名への週1日の在宅勤務制度の方針と準備の着手を決めてもらう付議資料です。

**主結論:** 週1日・曜日の割り当て制で始めれば、VPNの上限の範囲内で運用できる見込みなので、本日は方針を承認してほしい。

**決裁者の論点:** 週1日の在宅勤務は、かける費用に見合うだけ離職と採用の問題に手を打てて、VPNの上限の中で全社の内勤に広げられるか。

## 決裁事項を倒しうる問い

1. 柔軟性のなさを挙げた退職者のうち、週1日の在宅勤務で応えられるのは何名か。そのうち対象の内勤は何名か。
   - 倒れる場所:行27、行31、行72、行125。少なければ「辞める理由」が立たず、離職の抑制という目的が小さくなる
   - 要る材料:退職者の部署や職種の内訳、アンケートの回答数と順位、自由記述の中身
2. 費用はいくらで、離職者何名分に当たるのか。金額を示さずに方針を承認してよいのか。
   - 倒れる場所:行13、行78、行80、行95、行99、行101。費用が効果の見込みを大きく超えると、行10が立たない
   - 要る材料:退職者1名あたりのコストの集計、ノートPCの不足台数と単価、手当の想定額
3. 外勤の方などの利用を足しても、在宅勤務者がいちばん多い曜日に上限100件に収まるのか。
   - 倒れる場所:行58、行88、行127、行116。収まらないと、内勤180名への広げ方が立たない
   - 要る材料:多い日の同時接続の記録、部署ごとの内勤の人数

## 前提

- 業界平均8%は、当社と同じ規模と職種構成との比較と言えるのか。競合2社の週1〜2日は1社ずつの日数か。
  - 倒れる場所:行23、行24、行27、行52
  - 要る材料:業界平均の出どころ、競合の制度の出どころ
- 競合に制度があることは、当社の応募や内定承諾を実際に下げているのか。
  - 倒れる場所:行32、行73、行126
  - 要る材料:応募数と内定承諾率の推移、面接辞退の理由の記録
- 差のおよそ10名は全社の数字で、施策の対象は内勤180名だ。差のうち内勤の分は何名か。
  - 倒れる場所:行27、行80
  - 要る材料:内勤と内勤以外それぞれの離職率

## 問いそのもの

- 決裁者が決めたいのは「在宅勤務を入れるか」か、「離職率の4ポイントの差をどう縮めるか」か。柔軟性以外の退職理由への対応はあるのか。
  - 倒れる場所:行31、行34、行125
  - 要る材料:退職理由の順位の全体、ほかの離職対策の有無
- 本日の承認で4月の開始まで決まるのか。退職理由やコストのように手元で確かめられることを、頼んでから確かめる形になっていないか。
  - 倒れる場所:行10、行13、行78、行97〜101、行128
  - 要る材料:2月に止めたときの段取り、11月に諮る理由

## 他の選択肢

- `比べた案` は曜日の決め方と開始の規模だけだ。何もしない案、範囲を変える案、試行の結果を見てから開始を諮る案と比べたか。比べたなら記録は出せるか。
  - 倒れる場所:行10、行52
  - 要る材料:比較の記録
- 行64の時差出勤や休暇の取りやすさの改善は、内勤の柔軟性の問題にも当たるのか。
  - 倒れる場所:行31、行64
  - 要る材料:退職理由の中身

## 覆る条件

- 試行でどんな結果が出たら、4月の開始を止める、または遅らせるのか。
  - 倒れる場所:行113、行114、行116
  - 要る材料:VPN、業務への影響、利用者の声のそれぞれの線
- 離職率と採用の指標がいくつになれば成功で、いくつなら見直すのか。半年で年間の離職率の変化は読めるのか。10月の見直しは縮小や取りやめを含むのか。
  - 倒れる場所:行72、行73、行117
  - 要る材料:基準の値、目標の値、見直しの範囲
- 30名程度の試行で測る接続数の最大値から、180名に広げたときの最大値が言えるのか。
  - 倒れる場所:行88、行113
  - 要る材料:試行部署の接続の記録と、全社に広げるときの考え方

## 利害と実行

- 曜日の割り当て、業務の整理、申請の承認、日の変更は誰がやるのか。上長が日を変えられるとき、利用が少ない部署が出ても効果として測れるのか。
  - 倒れる場所:行46、行50、行92、行117
  - 要る材料:担当の決め方、部署ごとの利用の記録
- 対象外の70名の不公平感が離職として出たとき、全社の離職率はどう読むのか。
  - 倒れる場所:行64、行72、行94
  - 要る材料:内勤と内勤以外に分けた離職の記録
- 人事部が自部門の施策を自部門の数字で評価することを、経営会議はどう受け取るのか。
  - 倒れる場所:行117
  - 要る材料:報告の数字の確認方法

細かいものはほかに 3 件あります(試用期間中の者を除くことの採用上の説明、規程も暫定ルールも未定のまま試行が始まる順番、出社日の変更と曜日の割り当ての関係)。
