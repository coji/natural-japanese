1. 問い:受注検索の改修は、いま本番でどうなっていますか(残している、切り戻した、など)。再起動のあとのメモリ使用量は見ていますか。見ているなら、どの時点までどんな状態で、同じ障害は起きていませんか。この答えが、「今も同じことが起きうるのか」に報告書で答える材料になります。
   答え:改修は切り戻しておらず、本番に残っています。再起動後はメモリ使用量を1時間ごとに見ていて、10月28日の時点で再発はありません。メモリ使用量の具体的な値は分かりません。

2. 問い:この報告書は、部長お二人への共有で終わる文書だと読みました。この読みで合っていますか。お二人に了承や指示をもらいたいことがあるなら、それは何で、どちらの部長に求めるものですか(3つの再発防止策について、今後の確認の進め方について、など)。
   答え:共有で終わる文書ではありません。決めてもらいたいことは2つあります。1つ目は、再発防止の3つの方向でよいかの了承です。2つ目は、改修が原因かどうかの調査に1週間かけてよいかです。防止策の中身・担当・期限は、調査の結果が出てから改めて出したいと考えています。どちらの部長に求めるものかは分かりません。

3. 問い:改修を疑う根拠は「反映と障害の時期が近いこと」だけですが、10月20日の反映より前に、同じサーバーでメモリが問題になったことはありますか。また、前日までに改修のほかに変わったものはありますか。
   答え:半年前に1度、同じサーバーのメモリで通知が出たことがあります。そのときは再起動で収まり、原因は調べていません。前日までに改修のほかに変わったものがあるかは分かりません。
