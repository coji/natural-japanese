1. 問い:疑っている受注検索の改修は、いま本番で動いたままですか、元に戻しましたか。再起動のあと、メモリの使用量はどう動いていますか。
   答え:切り戻していません。改修は本番に残っています。再起動後はメモリ使用量を1時間ごとに見ていて、10月28日の時点で再発はありません。使用量の具体的な数値や推移は分かりません。

2. 問い:入力に失敗した約40件は、全件が入力し直されたことを確かめましたか。文書には「営業が入力した注文」と「顧客に再入力を頼みました」の両方がありますが、この注文をシステムに入力するのは営業と顧客のどちらですか。
   答え:営業が電話で顧客に再入力を頼み、10月22日までに全件入力し直しました。納期の遅れが出ていないことは営業本部に確認しました。この注文をふだんシステムに入力するのが営業と顧客のどちらかは分かりません。

3. 問い:この報告で情報システム部長と営業本部長に求めるのは、「再発防止策の中身は、改修のメモリ使用量を確かめてから決める」という進め方の了承だと読みました。違いますか。ほかに2人に決めてもらうことはありますか。
   答え:少し違います。決めてもらうことは、再発防止の3つの方向でよいかの了承と、改修が原因かどうかの調査に1週間かけてよいかの2つです。防止策の中身・担当・期限は、調査の結果が出てから改めて出します。調査は、検証環境で改修の前後のメモリ使用量を比べる予定で、まだ始めていません。1週間あればできる見込みです。ほかに決めてもらうことはありません。
