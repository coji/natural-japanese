## 案1:頼む中身を小さくする案

- 主張:調査の1週間を先に決めていただき、再発防止の方向は調査の結果と一緒にお願いします
- 骨組み:概要 / 原因の調査 / 影響 / 付録:経緯
- 答える問い:L3、S8
- 倒れる条件:S8(改修が原因でなかったとき、3つの方向のどれが残るか)の答えしだいで、`doc.review.md` 行38のレビュー体制の強化は根拠を失い、元の決裁事項の一方が倒れます
- 元の決裁事項:再発防止の3つの方向でよいか、受注検索の改修が原因かどうかの調査に1週間かけてよいか
- 縮めた決裁事項:受注検索の改修が原因かどうかの調査に1週間かけてよいか
- 弱点:情報システム部長に2回判断してもらうことになります
- この案を選ぶなら、S8 の答えを先に見ます

## 案2:決めることから入る案(選んだ案)

- 主張:決めていただくのは1週間の調査と再発防止の3つの方向で、障害の内容はそのあとに報告します
- 骨組み:概要 / 原因の調査 / 再発防止策 / 障害の内容 / 影響 / 付録:経緯
- 答える問い:S3、L4

## 案3:どこまで片づいたかから入る案

- 主張:影響は片づき再発もなく、確定していないのはメモリが上限に達した理由です
