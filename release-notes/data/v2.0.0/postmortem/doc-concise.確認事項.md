# doc-concise.md の確認事項

端的にする工程では、文書の中の食い違いを直さず、元の文のまま残しています。どちらが正しいかは書き手にしか分からないので、次の点を確かめてください。

- 止まり方:概要は「1時間半ほど応答しなくなりました」と言い切り、影響は「画面が応答しなかった時間帯にも入力できた注文がある」「全面的だったのか断続的だったのかは確認中」と書いています。概要の言い切りは、確認が終わったあとも同じ言い方で書けるものですか。
- 再入力:影響は「営業が入力した注文」が失敗したと書き、再入力は「営業が顧客に頼みました」と書いています。入力するのは営業ですか、顧客ですか。
- 約300件の範囲:影響は「この時間帯」と「画面が応答しなかった時間帯」の2通りで書いています。約300件は、いつからいつまでの件数ですか。
- 直接の原因:原因の節は、改修については時期が近いだけでは原因と言えないとしていますが、メモリの上限到達については、状態の確認と再起動のあとの復旧を根拠に「直接の原因」と言い切っています。再起動から復旧までは約45分あります。上限到達が応答の停止を起こしたことを、順番のほかに何で確かめましたか。
- レビュー体制の強化:付録Bは、レビューの体制が障害につながったかどうかは判断できないと書き、再発防止策の表は「レビュー体制の強化」を挙げています。判断できないものを再発防止策に挙げてよいですか。付録に移したので、本編だけを読む人にはこの断りが見えません。
