判定の作業です。読んでよいのは {DIR} の中だけです。書いてよいのは、そのディレクトリの result.json だけです。

doc_1〜doc_3 の各ディレクトリに、次の4つがあります。
- original.md: {WRITER}が{READER}に宛てた相談資料(直す前)
- flags.json: original.md の中で、読み手が意味を推測し直さなければならないとされた言い回しの一覧(id, line, word, fix)。同じ語が別の行に何度か出る場合は、行ごとに1項目になっている
- A.md と B.md: original.md を、2つの異なる条件で直した文書(どちらがどの条件かは伏せている)

flags.json の各項目について、A.md と B.md のそれぞれで、次のどれかを判定してください。
- fixed: 同じ内容を書いた箇所があり、読み手が推測し直さなくてよい言い方に変わっている(言い換えに加えて、最初に出るところで説明を添えたものも fixed)
- kept: 同じ内容を書いた箇所に、元の言い回し(またはほぼ同じ問題のある言い回し)が残っている。語順や助詞だけ変わったもの、「本番」を「本番環境」に変えただけのように問題の部分が残っているものも kept
- removed: その内容を書いた箇所自体がなくなっている

あわせて、A.md・B.md の中で同じ内容を書いた箇所の文を、本文からそのまま写してください(removed なら空文字)。判定は、original.md の該当行と見比べて行うこと。

結果を result.json に次の形で書き出してください(UTF-8、JSON だけ):
{"doc_1": [{"id": 1, "A": {"status": "fixed", "text": "..."}, "B": {"status": "kept", "text": "..."}}, ...], "doc_2": [...], "doc_3": [...]}

最後に、各文書の A・B それぞれの fixed / kept / removed の件数だけを返してください。
