# 稟議書:議事録作成支援ツール「ミナトノート」の試験導入について

| 項目 | 内容 |
| --- | --- |
| 起案日 | 2026年11月10日 |
| 起案者 | 営業部長 |
| 提出先 | 経営会議 |
| 件名 | 議事録作成支援ツール「ミナトノート」の試験導入(6か月) |

## 1. 申請内容

顧客打ち合わせの議事録作成にかかる時間と残業を減らすため、音声の文字起こしと要約を行うクラウドツール「ミナトノート」を、営業部の営業担当12名で6か月間試験導入したい。

- **期間**:承認後の2026年12月から6か月
- **費用**:月額の上限は10万円、6か月の総額は60万円以内(見込みは594,000円)
- **進め方**:試験期間中に効果と情報管理の状況を測定する。3か月目に中間評価、6か月目に最終評価を行い、本導入・規模縮小・中止のいずれにするかを経営会議で改めて判断する

## 2. 背景と課題

- 営業部では、顧客打ち合わせが週に平均8件(月に約35件)ある。
- 担当者は打ち合わせ後、手書きメモをもとに議事録を作成している。先月ツールを試した担当者の場合、普段は1件あたり約60分かかっている。
- 担当者は議事録の作成に強い不満を持っており、残業の主な原因になっている。
- 手書きメモと記憶をもとに作るため、議事録の正確さは担当者のメモの取り方に左右される。
- 部全体での平均作成時間はまだ測っていない。試験導入の開始前に測定する(8章)。

## 3. 導入するツール

| 項目 | 内容 |
| --- | --- |
| ツール名 | ミナトノート(クラウドサービス) |
| 主な機能 | 打ち合わせ音声の文字起こし、要約 |
| プラン | 1人あたり月額6,600円 |
| 利用者 | 営業部の営業担当12名 |
| 社外の利用例 | 同業のA社(従業員300名)が全社で導入している。知人のB社(個人事業)も使っている |

同業のA社と、業種の違うB社でも導入が進んでおり、この種のツールは業界で標準になりつつある。A社での効果や運用上の注意点については、可能であれば開始前に聞き取りを行い、運用ルールづくりに活かす。

## 4. 期待効果

### 4.1 議事録作成時間の削減

先月、営業2課の担当者1名が無料版を1件の打ち合わせで試したところ、議事録の作成時間が普段の60分から30分に減った。この結果から、部全体でも作成時間は半分になる。

1件あたり30分減った場合の削減時間は、次のとおり。

| 項目 | 値 |
| --- | --- |
| 月あたりの打ち合わせ件数 | 約35件(週8件 × 52週 ÷ 12か月) |
| 1件あたりの削減時間 | 30分(試行時の参考値) |
| 月あたりの削減時間 | 約17時間 |
| 6か月の削減時間 | 約104時間 |

### 4.2 費用対効果の目安

月額費用を月あたりの削減時間で割ると、**削減できる1時間あたりの費用**になる。営業担当者の時間単価(人件費)がこの金額を上回れば、費用は回収できる。

| 1件あたりの削減時間 | 月あたりの削減時間 | 削減1時間あたりの費用 |
| --- | --- | --- |
| 15分 | 約9時間 | 約11,000円 |
| 30分(参考値) | 約17時間 | 約5,800円 |
| 45分 | 約26時間 | 約3,800円 |

当社の営業担当者の時間単価は1時間あたり3,500円であり、30分の削減が出れば費用は回収できる。

### 4.3 金額にしにくい効果

次の効果も見込まれる。

- 発言が記録に残るため、聞き漏らしや顧客との認識違いを後から確認できる
- 議事録が早くできあがり、顧客へのフォローや社内共有を早く始められる
- 担当者が交代するとき、過去の打ち合わせ内容を引き継ぎやすい
- 議事録作成の負担が減ることで、営業担当者の離職は減る

## 5. 費用

| 項目 | 金額 |
| --- | --- |
| 単価 | 6,600円/人・月 |
| 人数 | 15名 |
| 月額(見込み) | 99,000円 |
| 6か月合計(見込み) | 594,000円 |
| **申請する上限** | **月額10万円、6か月合計60万円** |

- 単価6,600円が税込か税抜かは、契約前に確認する。
- 上限と見込みの差額は、税区分や契約条件の確認結果に備えるためのものである。上限を超える支出は行わない。
- 上記以外の費用(機材など)は想定していない。必要になった場合も上限の範囲で対応し、超える場合は改めて申請する。

## 6. 実施体制

| 役割 | 担当 | 主な業務 |
| --- | --- | --- |
| 責任者 | 営業部長 | 全体の管理、中間評価・最終評価の報告 |
| 情報管理担当者 | 営業部内で1名 | 契約条件とデータの扱いの確認、利用ルールの整備と周知、録音データの管理状況の点検 |
| 利用者 | 営業担当12名 | ツールの利用、録音同意の記録、アンケートへの回答 |
| 相談先 | 情報システム部門、法務担当 | セキュリティと契約内容の確認 |

## 7. 情報管理と運用ルール

- 録音の前に、必ず顧客の同意を得る。同意が得られない打ち合わせでは録音せず、従来どおり手書きで議事録を作る。
- 録音データと議事録は、社外に共有しない。
- 顧客から議事録の共有を求められた場合は、情報管理担当者の承認を得たうえで、顧客に共有してよい。
- ツールの出力をそのまま議事録にせず、担当者が確認・修正してから確定する。

## 8. リスクと対策

| リスク | 対策 |
| --- | --- |
| 顧客の同意が得られず、ツールを使える打ち合わせが少ない | 同意を得られた割合を毎月集計する。利用が少ない場合は、中間評価で人数の縮小を検討する |
| クラウドに保存した顧客情報が漏れる | 契約の前に、情報管理担当者がデータの保存場所、AIの学習に使われるかどうか、保存期間と削除の方法を確認する |
| 法務部門 | 契約内容を法務担当に確認する |
| 初月 | 利用者への説明会を開始前に行う |
| 期待した効果が出ない | 3か月目の中間評価で効果を確かめ、見合わない場合は規模縮小か中止を判断する |
| 費用が想定を超える | 月額の上限を設ける。契約期間と中途解約の条件を契約前に確認する |

## 9. 評価の方法

### 9.1 測定の進め方

1. **開始前(2週間)**:現在の議事録作成時間を、担当者ごとに打ち合わせ1件単位で記録し、比較の基準とする。
2. **試験期間中**:月末に、ツールを使った回数と継続して使いたいかを、利用者が自己申告で報告する。
3. **3か月目末**:中間評価を行い、結果を経営会議に報告する。
4. **6か月目末**:最終評価を行い、本導入・規模縮小・中止の判断案を経営会議に提出する。

### 9.2 評価の指標

| 指標 | 測定方法 | 目安 |
| --- | --- | --- |
| ツールの利用回数 | 利用者の自己申告 | 1人あたり月8回以上 |
| 継続の希望 | 利用者アンケート | 対象者の8割以上が継続を希望 |
| 情報管理 | 情報管理担当者による点検 | 情報漏えい・同意なしの録音が0件 |
| 費用 | 請求額 | 月額10万円以内 |

### 9.3 判断の基準

- **本導入へ進む**:利用回数と継続の希望が目安を満たし、情報管理上の問題がない場合
- **規模を縮小して続ける**:継続の希望はあるが、利用回数が目安に届かない場合(ライセンス数を減らすなど)
- **中止する**:利用回数と継続の希望がどちらも目安に届かない場合、または情報管理上の重大な問題が起きた場合(この場合は期間の途中でも利用を止める)

## 10. スケジュール

| 時期 | 内容 |
| --- | --- |
| 承認後〜開始前 | 契約条件とデータの扱いの確認、同意取得の手順づくり、現在の作成時間の測定、利用者への説明会 |
| 1〜3か月目 | 運用開始、利用状況と費用を毎月確認 |
| 3か月目末 | 中間評価、経営会議へ報告 |
| 4〜6か月目 | 運用を続ける(中間評価の結果に応じて見直す) |
| 6か月目末 | 最終評価、判断案を経営会議へ提出 |

## 11. 決裁事項

1. 営業担当12名を対象に、「ミナトノート」を6か月間試験導入すること(上限は月額10万円、6か月合計60万円)
2. 試験期間の終了後、本導入・規模縮小・中止を経営会議で改めて判断すること
